- 현재 폴더 구조를 이곳에 통째로 복제하지 않습니다.
- 단순 구버전은 Git 커밋과 태그로 확인합니다.
- 폐기 이유가 중요한 문서는 `YYYY-MM-DD_제목.md`로 기록합니다.
- Archive 문서는 현재 구현 기준으로 사용하지 않습니다.

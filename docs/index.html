01 / Overview

프로젝트 개요

전략 배치의 깊이와 직접 전투의 긴장감을 하나의 약점 공유 구조로 연결합니다.

ONE-LINE PITCH

새 월드마다 번호 지구를 만들고 기지를 성장시키며, 신화·설화·우화의 법칙이 현실이 된 게이트를 공략하는 설계·생존 액션 게임.

02 / Identity

왜 ERGOSQUARE인가?

UNCONTROLLED SPACE

ERGOSPHERE

게이트와 함께 형성되는 통제 불가능한 왜곡 영역. 인간이 공간의 흐름에 끌려갑니다.

SPACE MOVES YOU
→

DESIGNED SPACE

ERGOSQUARE

설계자가 좌표와 규칙을 부여하는 개인 아공간. 인간이 공간을 직접 움직입니다.

YOU MOVE SPACE
ARCHITECT

인벤토리 게이트를 확장해 에르고스퀘어를 구축하고, 그 내부 구조를 전투 청사진으로 운용할 수 있는 특수 각성자의 코드네임입니다.

03 / Scenario

간략 시나리오

01
WORLD CREATION

번호 지구 생성

새 월드를 만들면 고유 번호와 역사를 가진 플레이어 소유의 지구가 생성됩니다.

02
FIRST INVASION

게이트와 대분기

지구 자아는 외부 침공에 맞서 설계자를 만들고, 가능한 미래를 관측하는 대신 실제 세계들로 분기합니다.

03
ANCHOR

핵심 앵커 장악

플레이어는 일반 게이트에서 좌표를 찾고 핵심 앵커를 자신의 지구에 다시 귀속시킵니다.

04
CANONIZATION

정본화의 선언

여러 승리 중 자신의 결말만이 완전하다고 주장한 번호 지구가 정본을 자칭하고 다른 가능성을 병합합니다.

05
FINAL GATE

번호 지구의 독립

최후의 게이트에서 병합 명령을 막고 플레이어가 살아온 지구를 독립된 현실로 지켜 냅니다.

04 / Terminology

하나의 규칙으로 연결되는 용어

01

게이트

현실과 다른 차원을 잇는 균열이자 사건의 시작점.

02

에르고스피어

공간이 인간을 움직이는 통제 불가능한 왜곡 영역.

03

인벤토리 게이트

개인 아공간과 현실을 연결하는 각성자의 인터페이스.

04

에르고스퀘어

설계자가 격자 좌표로 구축하고 전개하는 개인 아공간.

05

설계자

에르고스퀘어의 구조와 규칙을 전투에 사용하는 특수 각성자.

06

침식체

다른 차원의 법칙으로 현실을 침식하는 적대 생명체.

05 / Core Concept

인벤토리는 가방이 아니다

보이지 않던 UI를 전장 위의 실체이자, 반드시 지켜야 하는 약점으로 바꿉니다.

BLUEPRINT / GUNNER-033 × 3

모듈을 가리켜 역할을 확인하세요.

01

설계한다

전투 전에 코어와 모듈의 크기, 위치, 인접 효과를 고려해 빌드를 구성합니다.

02

전개한다

인벤토리 게이트를 열어 설계한 격자를 실제 전장에 고정합니다.

03

출력한다

설치된 모듈이 자원과 무기, 스킬 사용 조건을 제공합니다.

04

지켜낸다

침식체가 노리는 코어를 보호하고 팀원의 약점을 함께 보완합니다.

06 / Core Loop

설계하고, 드러내고, 다시 고친다

01PREPARE

프레임 선택

팀 조합과 작전 목표를 확인합니다.

02DESIGN

청사진 편성

코어와 모듈을 격자에 배치합니다.

03DEPLOY

공간 전개

전투 위치에 에르고스퀘어를 고정합니다.

04DEFEND

협동 전투

자원을 출력하며 서로의 코어를 지킵니다.

05REVISE

결과 분석

실패 원인을 반영해 설계를 수정합니다.

07 / ErgoSquare System

배치가 곧 전투 능력이다

▦

1m 격자

한 칸을 1m × 1m 좌표로 계산해 전개 거리와 모듈 크기를 명확히 합니다.

⌖

위치 고정

전개된 격자는 플레이어를 따라오지 않습니다. 잘못된 위치 선정은 전투 손실로 이어집니다.

◷

설치 시간

전개 직후 모듈은 홀로그램 상태이며, 설치가 끝나야 기능을 사용할 수 있습니다.

↻

재전개 제약

회수와 재전개에는 시간이 필요해 위험 없이 무한 재배치할 수 없습니다.

RISK / REWARD

강해질수록
약점도 커진다

더 많은 모듈은 더 높은 전투력을 제공하지만, 설치 시간과 방어해야 할 면적도 함께 늘립니다.

출력 능력HIGH
노출 면적HIGH
설치 부담MID
기동성LOW

08 / Tactical Frames

같은 공간, 다른 설계 방식

전술 프레임은 스킬만 바꾸는 직업이 아니라 에르고스퀘어의 형태와 위험을 바꿉니다.

3 × 5 / FRONT

RESOURCE / IMPULSE

뱅가드

전방 방어 · 접근 차단

플레이어 전방에 넓은 청사진을 펼쳐 팀의 방어선을 만듭니다. 강한 구조물을 설치하지만 전개 방향과 느린 설치 속도가 약점입니다.

  • 전방 3×5 격자
  • 높은 구조물 내구도
  • 임펄스 기반 근접 충격 출력

09 / Cooperative Combat

내 전투보다 우리의 약점

VFRONT
GFIRE
RCONTROL
LLINK
SHARED

01

역할보다 관계

프레임은 혼자 완결되지 않습니다. 각자의 전개 방식이 다른 플레이어의 사각을 채웁니다.

02

공유되는 위험

적이 팀원의 핵심 모듈을 공격할 때, 개인 화력과 팀 생존 사이에서 우선순위를 결정합니다.

03

실패가 다음 설계가 된다

먼저 파괴된 모듈과 자원 공백을 분석해 다음 작전의 청사진을 함께 수정합니다.

10 / MVP

먼저 검증할 단 하나의 질문

VALIDATION TARGET

“전투력을 얻기 위해 파괴 가능한 청사진을 노출하고,
팀과 함께 그 약점을 보호하는 구조가 실제로 재미있는가?”

IN SCOPE
  • 싱글 세이브와 1~4인 호스트 동기화
  • 거너·뱅가드 우선 구현
  • 격자 편성과 전장 전개
  • 자원 코어와 모듈 파괴
  • 코어를 노리는 침식체 AI
  • 직접 공격과 결과 분석
EXPANSION
  • 링커 다중 보조 노드
  • 청사진 성장 고도화
  • 보스 침식체와 난이도
  • 부산물 거래소
  • 청사진 라이선스 시장
  • 생성 AI 전술 피드백

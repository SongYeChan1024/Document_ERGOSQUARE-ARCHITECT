# ERGOSQUARE: ARCHITECT

> 공간에 휘말리지 말라. 공간을 설계하라.

플레이어가 자신만의 번호 지구를 만들고 정해진 허브 시설을 강화하며, 지역과 사람의 기억을 읽어 이야기를 투영하는 게이트를 공략하는 1~4인 협동 액션 게임입니다. 혼자 모든 핵심 콘텐츠를 진행할 수 있고, 로컬·호스트 월드에 친구를 초대해 함께 플레이할 수 있습니다.

## 프로젝트 소개

| 항목 | 내용 |
| --- | --- |
| 장르 | 1~4인 협동 샌드박스 / 실시간 액션 / 전략 배치 |
| 플레이 | 싱글 / 로컬·호스트 친구 협동 |
| 플랫폼 | PC Windows 우선 검토 |
| 엔진 | Unity / URP |
| 네트워크 | Photon PUN2 검토 |
| 개발 인원 | 1인 기획·개발 |
| 개발 기간 | 미정 |
| 현재 상태 | 콘셉트 정리 / 프리프로덕션 |

## 한 줄 소개

새로 생성한 번호 지구를 탐험하고, 이야기의 법칙이 현실이 된 게이트에서 퀘스트를 해결하며, 파괴 가능한 전투 청사진을 지키는 설계·생존 액션 게임입니다.

## 핵심 특징

1. 인벤토리 배치 자체가 전투 청사진이 되는 빌드 설계
2. 청사진을 현실 공간에 전개하는 `에르고스퀘어` 시스템
3. 강력하지만 파괴될 수 있는 코어와 모듈을 지키는 위험·보상 구조
4. 새 세이브마다 고유 번호와 상태를 유지하는 플레이어 소유 지구
5. 지역과 사람의 기억을 읽어 신화·설화·우화를 투영하는 퀘스트형 게이트
6. 각성자·현현체의 능력을 모사하고 문화권을 넘어 융합하는 근접·투사·영역 빌드

## 핵심 플레이 루프

```text
월드 생성 → 탐색·허브 시설 강화 → 청사진 편성 → 게이트 진입
→ 퀘스트·전투 → 게이트 폐쇄 → 성장·세계 안정화 → 다음 좌표 추적
```

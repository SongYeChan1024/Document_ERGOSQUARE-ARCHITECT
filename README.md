## 현재 개발 범위

Unity / URP 기반 싱글 튜토리얼을 먼저 만듭니다. 1~4인 협동과 장기 허브·문화권 확장은 후속 범위입니다.

20일 세션 마감 기준 최신 검수는 별도 3인칭 비교 씬과 동굴 미리보기에서 진행합니다. 원본 검 2타·공격 중 마우스 에임 추적, 새 장비·에르고 스퀘어 UI를 확인하며, 전체 튜토리얼의 3인칭 진행 이관은 후속입니다. [최신 개발 일지](04_프로젝트_관리/개발_일지/2026-10-20_검_2단_베기와_공격_중_마우스_에임_추적.md) · [다른 PC에서 시작하기](03_기술_문서/다른_PC에서_프로젝트_열기.md)

9월 7일 기록 기준, 동굴 첫 구간에 빗자루 획득 → 청사진 배치·스킬 할당 → 전투 → 완료 표식의 진행 구조가 있습니다. 이동·G 안내는 일부 확인되었지만 전체 연속 플레이는 재검증이 필요합니다. 실제 코어·주머니 방어, 월도와 게이트 폐쇄까지 완성된 상태는 아닙니다.

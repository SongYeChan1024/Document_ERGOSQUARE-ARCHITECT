# ERGOSQUARE: ARCHITECT

> 공간에 휘말리지 말라. 공간을 설계하라.

플레이어가 인벤토리를 전투 청사진으로 설계하고, 이를 현실 공간에 전개해 동료와 함께 코어를 방어하는 3~4인 협동 PvE 액션 게임입니다.

## 프로젝트 소개

| 항목 | 내용 |
| --- | --- |
| 장르 | 3~4인 협동 PvE / 실시간 액션 / 랜덤 배치 |
| 플랫폼 | PC Windows 우선 검토 |
| 엔진 | Unity / URP |
| 네트워크 | Photon PUN2 검토 |
| 개발 인원 | 1인 기획·개발 |
| 개발 기간 | 미정 |
| 현재 상태 | 콘셉트 정리 / 프리프로덕션 |

## 한 줄 소개

인벤토리 격자에 배치한 코어와 모듈을 전장에 실체화하고, 파괴 가능한 자신의 빌드를 동료와 함께 지키며 싸우는 협동 방어 게임입니다.

## 핵심 특징

1. 인벤토리 배치 자체가 전투 청사진이 되는 빌드 설계
2. 청사진을 현실 공간에 전개하는 `에르고스퀘어` 시스템
3. 강력하지만 파괴될 수 있는 코어와 모듈을 지키는 위험·보상 구조

## 핵심 플레이 루프

```text
준비 → 청사진 편성 → 균열 진입 → 전개 → 협동 전투 → 보상 → 성장 → 재도전
```

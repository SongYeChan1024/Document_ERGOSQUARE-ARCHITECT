# 에르고스퀘어 핵심 시스템

> [!IMPORTANT]
> 이 문서는 원안 수치를 포함한 SSOT 후보 문서입니다.
> 표기된 시간과 범위는 프로토타입 검증 전 기획값이며 확정 밸런스가 아닙니다.

## 에르고스퀘어 편성

플레이어는 전투 전에 격자 위에 자원 코어와 공격·방어·수리·증폭 모듈을 배치한다. 같은 전술 프레임을 선택해도 모듈의 크기와 인접 관계, 코어 보호 방식에 따라 다른 빌드가 만들어진다.

## 전개와 설치

전개와 설치는 서로 다른 단계다.

| 단계 | 설명 |
| --- | --- |
| 전개 | 인벤토리 게이트를 열어 에르고스퀘어의 격자를 현실 공간에 펼친다. |
| 설치 | 배치된 모듈이 홀로그램 상태에서 실체화되고 기능을 활성화한다. |

전개된 청사진은 순간의 위치와 방향에 고정되며 플레이어를 따라다니지 않는다. 위치를 잘못 선택하면 회수와 재전개 과정이 필요하다.

## 기본 시간 규칙

| 행동 | 기획 기준 |
| --- | --- |
| 청사진 전개 | 1초 |
| 전개 후 회수 제한 | 10초 |
| 청사진 회수 | 2초 |
| 회수 후 재전개 대기 | 8초 |

수치는 프로토타입 테스트를 통해 조정한다.

## 위험과 보상

에르고스퀘어는 자원과 전투력을 공급하지만 동시에 파괴 가능한 약점이다.

- 자원 코어가 파괴되면 해당 자원 생산이 중단된다.
- 공격 모듈이 파괴되면 연결된 무기 또는 스킬을 사용할 수 없다.
- 설치 중인 모듈도 공격받을 수 있다.
- 플레이어는 자신의 코어와 팀원의 코어 중 어느 쪽을 우선 보호할지 판단한다.

## 전술 프레임

| 프레임 | 자원 | 전개 방식 | 팀 역할 |
| --- | --- | --- | --- |
| 뱅가드 | 임펄스 | 전방 3×5 | 방어선 형성, 접근 차단 |
| 거너 | 집중 | 자기 중심 3×3 | 원거리 사격, 약점 타격 |
| 리액터 | 위상 에너지 | 2m 이상 원격 전개 | 범위 제어, 원격 화력 |
| 링커 | 동조 | 메인 격자 + 보조 노드 | 수리, 보호막, 연결 지원 |

## 기본 플레이 루프

```text
작전 허브 입장
→ 전술 프레임 선택
→ 에르고스퀘어 편성
→ 균열 봉쇄 구역 진입
→ 청사진 전개 및 설치
→ 자원·무기·스킬 출력
→ 코어를 지키며 협동 전투
→ 결과 분석
→ 청사진 수정 및 성장
→ 재도전
```

## 확장 경제

침식체 부산물로 모듈을 제작하거나 강화하고, 설계한 청사진의 열람권·복제권·개조권을 거래하는 구조를 확장 목표로 둔다.

> 잘 짠 청사진은 하나의 상품이 된다.

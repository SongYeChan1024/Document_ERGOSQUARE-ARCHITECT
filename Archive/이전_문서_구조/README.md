# ERGOSQUARE 문서 루트

이 폴더는 프로젝트의 기획, 개발 전달, 작업 기록과 아카이브를 관리하는 문서 저장소입니다.

## 폴더 체계

| 경로 | 역할 | 신뢰도 |
| --- | --- | --- |
| `01_SSOT_최종_기준문서/` | 현재 프로젝트의 단일 기준 문서 | 가장 높음 |
| `02_개발_전달용/` | 구현 가능한 수준으로 구체화한 P0·P1 명세 | 높음 |
| `03_기획_부록_참고문서/` | 아이디어, 콘셉트 비교, 조사 자료 | 참고 |
| `04_UI_이미지_레퍼런스/` | 화면별 UI 레퍼런스와 요구사항 | 참고 |
| `05_개인_개발일지/` | 일일·주간 작업과 트러블슈팅 | 기록 |
| `06_이미지_작업물/` | 로고, 목업, 다이어그램 산출물 | 결과물 |
| `07_기획서_이미지_자료/` | 문서에 삽입할 최적화 이미지 | 결과물 |
| `08_발표_포트폴리오/` | 발표, 시연, 포트폴리오 자료 | 결과물 |
| `90_Archive_구버전/` | 과거 확정본과 폐기된 버전 | 읽기 전용 |
| `99_Trash_삭제후보/` | 삭제 전 검토가 필요한 중복 자료 | 격리 |

## 승격 흐름

```text
아이디어·조사
→ 03_기획_부록_참고문서
→ 초안 작성 및 검토
→ 01_SSOT_최종_기준문서
→ 02_개발_전달용
→ 구현·QA 증거
→ 08_발표_포트폴리오
```

자세한 규칙은 루트의 `DOCUMENT_RULES.md`를 확인합니다.

## 목표와 문제
첫 전투에서 정신집중으로 에너지를 모은 뒤 스킬을 사용하는 대기가 길었습니다. 청사진과 별개인 착용 장비 슬롯 및 자원 없는 기본 공격을 구현해 전투를 이어갈 수 있게 했습니다.
## 구현한 내용
- 직접 착용 무기 슬롯 1개와 고유 시험 무기 ‘대원의 훈련검’ 보유 상태를 추가했습니다.
- 시작 지점 근처의 무기를 G로 획득하고 Tab → 장비 → 무기 장착으로 사용합니다. 획득 즉시 자동 장착하지 않습니다.
- Tab에 청사진/장비 탭을 분리했습니다. 청사진은 기존 편집·전개, 장비는 장착·해제를 담당합니다.
- 장비 탭에서는 전개 격자·미리보기를 닫고 이동·집중·스킬·상호작용을 차단합니다. Tab 닫기는 유지합니다.
- 평상시 좌클릭은 커서 방향 기본 공격, 청사진 전개 중 좌클릭은 설치, UI 위 클릭은 UI 조작으로 구분했습니다.
- 기본 공격은 코어 자원을 쓰지 않으며 코어 파괴 후에도 가능합니다. 벽 차폐와 중복 콜라이더 타격을 검사합니다.
- 시험 수치: 피해 15, 공격 간격 0.65초, 사거리 2m, 전방 100도. 최종 밸런스가 아닙니다.
- 빗자루 스킬과 기본 공격의 중복 실행을 제한하고 스킬 실행 중 기본 검 표현을 숨깁니다.
- 튜토리얼 목표 문구에 무기 획득·장착과 기본 공격 안내를 연결했습니다.
- 종합 기획서에 구현 규칙·범위·검증 결과를 반영했습니다.

## 제한과 미구현
무기와 획득물은 런타임 생성 임시 메시이고 모션도 임시 표현입니다. 대원 시체, 정식 모델·애니메이션·SFX, 방어구, 다종 무기 교체, 여분 장비의 청사진 수납, 저장/로드는 구현하지 않았습니다. 현재 해제한 훈련검은 고유 무기 보유 상태로 돌아오며 일반 무제한 보관함을 뜻하지 않습니다.

## 문제 해결 상세

장비 화면에서 입력을 모두 차단하면 Tab 닫기까지 막힐 수 있어 장비 메뉴의 닫기 요청은 통과시키되 다른 입력 차단 사유는 해제하지 않도록 구성했습니다. 기존 전개 모드의 닫힘 이벤트를 사용해 격자·편집 화면을 숨기고, 이미 필드에 전개한 파츠는 탭 전환으로 회수하지 않습니다.

좌클릭은 입력 콜백에서 즉시 공격하지 않고 EventSystem 처리 후 LateUpdate에서 메뉴 상태와 UI 포인터 여부를 확인합니다. 기본 공격은 Gameplay에서 판정하고 화면 좌표 해석과 무기 시각 표현은 Presentation에서 처리합니다. 스킬 컨트롤러가 플레이어가 아닌 GameplaySystems에 있다는 기존 구성을 확인하여 명시적으로 연결했습니다.

## 재현 방법

1. Unity의 Tutorial_Stage01_Awakening 씬을 새로 Play합니다.
2. 시작 위치 가까이 생성된 임시 무기에 접근하여 G로 획득합니다.
3. Tab → 장비에서 무기를 장착하고 Tab으로 닫습니다.
4. 기존 빗자루를 획득·편성하고 첫 전투 구역으로 진행합니다.
5. 적 가까이에서 커서 방향을 좌클릭합니다. 코어 자원 감소 없이 기본 공격이 적중해야 합니다.
6. 장비를 해제하면 공격할 수 없고 장비·전개 화면 클릭으로 적에게 피해가 발생하지 않아야 합니다.

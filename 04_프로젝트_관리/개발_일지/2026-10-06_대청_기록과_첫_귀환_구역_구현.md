## 오늘의 목표

보스 처치 뒤의 이야기를 마무리하고 게이트를 나와 실제 플레이 가능한 첫 귀환 구역으로 연결합니다. 기관 본부 전체를 바로 만드는 대신 게이트 밖 임시 통제·구호 구역에서 생환 확인과 사건 보고를 진행하도록 구성합니다.

## 작업 내용

### 대청 기록과 게이트 종료

- 초가집 도트 이미지를 열린 중앙 대청·목재 기둥·마루·기록 소품이 읽히는 구조로 개편했습니다. 기존 초가집 원본은 보존했습니다.
- 실제 상호작용은 이동 가능한 대청 앞과 집 옆 경계에 설치했습니다. 집 전체를 걸어 들어가는 실내로 만든 것은 아닙니다.
- 보스 처치 → G 영혼 해방 → 다시 G 월도 획득 → 대청 기록 G → 명시적 기록 확인 → 집 옆 은빛 출구 G → 귀환 확인 순서를 연결했습니다.
- 기록을 닫는 것만으로는 읽음 처리하지 않고 확인해야 출구가 활성화됩니다. 출구 확인 창에서도 현장에 더 머무를 수 있습니다.
- 기록에는 조사관의 마지막 현장 기록과 팀장의 철수 메모를 넣었습니다. 월도에 사람들의 신호가 검출됐다는 단서를 주되 확정적인 이면 해석은 귀환 뒤 조사실에서 설명합니다.
- 대화 중 이동·공격을 멈추고 기존 전투 HUD·G 안내를 숨겼습니다. 닫기·확인 후 원래 표시 상태를 복원하며 다른 시스템의 입력 차단 토큰은 해제하지 않습니다.
- 해방된 사람의 영혼은 눈 없는 빛 연출로 표현해 아이템 도깨비불과 구분했습니다. 모든 피해자의 즉시 생환을 확정하지 않습니다.

### 첫 귀환 구역

- 신규 씬 `Tutorial_Stage03_ReturnField`를 생성하고 빌드 목록과 보스 출구의 비동기 이동 목적지를 연결했습니다.
- 약 30×48m 현장 구역에 통제선 → 임시 구호소 → 현장 조사실을 배치했습니다. 도로·구역 기반·스폰·별도 장애물·NavMesh를 구성했습니다.
- 구호소 천막·조사실·바리케이드·현장 요원 도트 아틀라스를 생성하고 원본 투명 알파를 유지해 적용했습니다.
- 그림은 카메라를 향하는 2.5D 소품이고, 지면 충돌 기반은 별도입니다. 천막 그림의 지붕 전체를 이동 장애물로 취급하지 않습니다.
- 세 지점의 요원에게 G로 대화하고 확인 버튼으로 한 단계씩 진행합니다. 미래 단계는 잠그고 완료한 대화는 다시 열람할 수 있습니다.
- 통제선은 생환 확인, 구호소는 상태 확인, 조사실은 기록·월도와 게이트 폭주 보고를 담당합니다. 기관 본부 정밀 검사는 후속 안내로만 남겼습니다.
- 안전 구역에서는 기본 공격·전투 스킬을 차단하되 우클릭 이동과 Tab 장비/청사진 편집은 유지합니다.

### 상태 인계와 문서

- 검 장비 소유/장착, 빗자루·코어·월도 파츠 인스턴스, 청사진 배치, 스킬 배정, 체력·정기·남은 내구도를 메모리 스냅샷으로 한 번 인계합니다.
- 구호소는 상태 확인 대화이며 무료 회복·내구도 수리·보상 재지급 기능이 아닙니다. 씬을 직접 열어도 귀환 보상을 임의 지급하지 않습니다.
- 종합 기획서·튜토리얼 콘텐츠 기획·상세 연출 및 구현 명세에 최종 귀환 흐름과 실제 검증 이미지를 보충했습니다.
- 기존 사용자 편집 씬을 덮어쓰지 않고 별도 복제 Unity 프로젝트에서 생성·검증했습니다. 기존 튜토리얼 두 씬의 저장 파일 해시가 유지됐습니다.

## 발생한 문제

1. 생성 아틀라스를 정확히 절반으로 나누면 천막 바깥 밧줄과 요원 머리 일부가 잘렸습니다.
2. 목표 HUD 글자가 보이는 프레임 여백에 맞지 않고 요원 이름표가 몸에 겹쳤습니다.
3. 검증 과정에서 기록 창 초기화가 반복 호출되어 잔여 모달이 생겼습니다.
4. 기존 장비 UI가 Start에서 공격 컴포넌트를 추가하므로 안전 구역의 초기 차단만으로는 충분하지 않았습니다.

## 원인

- 생성 이미지의 실제 배치 여백은 기계적인 50% 격자와 일치하지 않았습니다.
- 기존 HUD의 투명 프레임 여백과 월드 Y 방향을 사용한 이름표 위치가 새 씬의 카메라 투영에 맞지 않았습니다.
- 기록 UI의 초기화가 여러 번 실행될 수 있는 검증 경로에 중복 생성 방지가 없었습니다.
- 플레이어/입력/화면 계층의 초기화 시점이 달라 나중에 생성된 공격기가 안전 구역 정책을 우회할 수 있었습니다.

## 해결

- 실제 투명 여백에 맞춰 가로 54%·세로 53% Sprite 분할을 사용했습니다. PNG 픽셀은 재도색하지 않았습니다.
- 목표 문구를 짧게 정리하고 좌우 패딩을 조정했습니다. 이름표는 월드 Y 대신 카메라의 화면 위 방향으로 띄웠습니다.
- 공통 기록 창을 한 번만 초기화하도록 만들어 반복 호출 시에도 중복 모달을 생성하지 않게 했습니다.
- 안전 구역의 Start와 첫 LateUpdate에서 기본 공격·스킬 사용을 차단하고 이동/Tab 입력은 유지했습니다.
- 검증용 캡처도 같은 초기화 경로를 사용하고 카메라와 대상 지점의 위치를 맞춰 UI·레이블을 확인했습니다.

- 수동 전체 완주, 독립 실행 빌드, 모든 해상도·장시간 반복 QA 완료로 해석하지 않습니다.

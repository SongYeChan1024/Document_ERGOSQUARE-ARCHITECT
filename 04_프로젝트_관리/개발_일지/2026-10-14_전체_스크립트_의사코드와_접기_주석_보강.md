## 작업 내용

### 1. 자체 C# 스크립트 131개 설명

`Assets/_ERGOSQUARE/02.Scripts` 아래 자체 C# 스크립트 131개에 파일의 역할, 호출·참조 관계, 상태 소유 및 저장 경계를 설명하는 헤더를 보강했습니다. 이전에 일부 핵심 파일에 작성한 상세 설명을 바탕으로 전체 자체 스크립트의 읽기 안내를 확장했습니다.

### 2. 핵심 함수 333개 의사코드

핵심 함수 333개의 처리 순서를 한국어 의사코드로 작성했습니다. 주요 함수 9개는 조건 분기와 반복 구조를 더 구체적으로 풀어 썼습니다. 의사코드는 실제 코드를 읽기 위한 설명이며 전투 규칙이나 밸런스를 변경한 작업은 아닙니다.

### 3. 설명과 실제 코드의 접기 구역

파일 안내, 함수 의사코드와 실제 코드에 `#region` 접기 구역을 구성했습니다. 의사코드·실제 코드 쌍 333개를 포함해 여는 구역과 닫는 구역이 각각 806개로 일치합니다.

## 발생한 문제

설명 없이 처리 순서를 이해하기 어렵고, 설명을 늘리면 실제 코드를 찾기 위해 스크롤해야 하는 부담이 커졌습니다.

## 원인

파일 역할·상태 소유·함수 내부 흐름에 대한 안내가 부족했고, 설명과 실행 코드가 한 화면에 길게 펼쳐졌습니다.

## 해결

파일 헤더와 함수별 의사코드를 추가하고 설명·실제 코드를 접기 구역으로 구분했습니다. 기존 주석은 보존하고 실행 토큰을 비교해 주석 정리가 동작 변경으로 이어지지 않았는지 확인했습니다.

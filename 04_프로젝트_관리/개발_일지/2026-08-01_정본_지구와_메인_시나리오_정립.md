# 2026-08-01 개발 일지

## 오늘의 목표

- 번호 지구를 병합하는 정본 지구의 동기와 과거를 정립합니다.
- 게이트와 설계자의 기원을 하나의 역사로 연결합니다.
- 자유로운 샌드박스 플레이 안에서 메인 목표를 명확히 전달할 시나리오 구조를 결정합니다.
- 메인 엔딩과 엔딩 이후의 세계관 확장 범위를 구분합니다.

## 작업 내용

### 정본 지구의 역사

현재의 게이트 침공 이전에 차원 외부 존재가 일으킨 `최초 게이트 전쟁`이 있었다고 설정했습니다. 침공으로 행성이 붕괴할 위기에 놓이자 지구의 자아가 깨어나 일부 인간에게 현실과 공간을 편집하는 설계자 권한을 부여했습니다.

분기 이전의 지구 자아와 최초 설계자는 하나의 현실만으로 반복되는 침입을 막을 수 없다고 판단해 `대분기 계획`을 실행했습니다. 닥쳐올 미래를 관측하는 데 그치지 않고 가능한 지구를 실제로 분기하여, 모든 세계가 각자의 방식으로 침략에 대응하게 했습니다.

여러 번호 지구가 서로 다른 방식으로 외부 침략을 극복했습니다. 그중 한 지구는 자신의 성공만을 완전한 승리로 규정하고 스스로를 `정본 지구`라고 선언했습니다. 다른 지구의 결말을 불완전한 가능성으로 분류해 `정본화 선언`을 내렸습니다.

### 플레이어와 번호 지구의 자아

대분기 때 분기 이전 지구의 자아와 설계자 계보도 각 번호 지구로 함께 나뉘었다고 설정했습니다. 정본화 침공을 받은 플레이어 지구의 자아가 플레이어를 자신의 설계자로 선택합니다.

따라서 플레이어의 능력은 정본 시스템의 우연한 오류가 아니라, 자신의 지구가 스스로를 지키기 위해 부여한 권한입니다.

### 메인 진행 구조

일반 게이트와 메인 진행을 담당하는 앵커 게이트를 분리했습니다.

```text
일반 게이트 공략
→ 공명 기록과 앵커 좌표 확보
→ 핵심 앵커 게이트 장악
→ 앵커를 플레이어 지구에 귀속
→ 최후의 게이트 개방
→ 정본화 관리자 시스템 진입
→ 병합 명령 해제와 번호 지구 독립
```

앵커 게이트는 파괴 대상이 아니라 정본 지구와의 연결을 끊고 플레이어 지구의 현실 고정 장치로 전환하는 목표입니다. 모든 핵심 앵커를 장악하면 관리자 시스템으로 이어지는 최후의 게이트가 열립니다.

### 플레이어가 쓰는 이야기

개발자가 제공하는 고정된 큰 역사는 다음과 같습니다.

- 20XX년 최초 게이트 출현
- 지구 자아와 설계자의 탄생
- 대분기 계획과 봉문전쟁
- 정본화 선언과 현재의 침공
- 핵심 앵커와 최후의 게이트
- 플레이어 지구의 독립

플레이어는 NPC와 세력 중 누구를 신뢰하고 구조하며 협력했는지를 선택합니다. 핵심 엔딩은 지구의 독립으로 유지하되, 최종전 지원, 지역 피해, 생존자와 독립 이후의 사회는 플레이 기록에 따라 달라집니다.

### 후속 확장 여지

다른 번호 지구와 최초 침략자는 메인 엔딩 이후 활용 가능한 소재로 남겼습니다. 구체적인 재침공, 동맹과 차원 개척은 아직 확정하지 않으며 실제 개발 진척 후 별도 기획합니다.

## 발생한 문제

- 기존 설정에서는 정본 지구가 분기 이전의 객관적인 원본이자 처음부터 게이트를 만든 침략자처럼 보였습니다.
- 일반 게이트를 반복해서 닫는 것만으로는 플레이어가 최종 목표와 진행 단계를 파악하기 어려웠습니다.
- 다른 번호 지구와의 교류를 메인 스토리에 포함하면 플레이어 자신의 지구를 지킨다는 감정적 초점이 흐려졌습니다.
- NPC 선택으로 완전히 다른 메인 엔딩을 다수 제작하면 분기와 제작 범위가 과도하게 증가할 수 있었습니다.

## 원인

- 게이트, 설계자, 평행 지구의 기원이 하나의 역사로 연결되지 않았습니다.
- 반복 콘텐츠와 메인 시나리오 목표가 같은 `게이트 폐쇄`라는 표현으로만 묶여 있었습니다.
- 메인 엔딩과 엔딩 이후의 확장 콘텐츠 경계가 명확하지 않았습니다.

## 해결

- 게이트의 기원을 외부 침략자의 최초 게이트와 정본 지구의 정본화 게이트로 구분했습니다.
- 정본 지구를 동등한 분기 중 유일하게 승리한 세계로 설정하고, `정본`을 기원이 아닌 승자의 자기 선언으로 정의했습니다.
- 앵커 게이트를 명시적인 메인 진행 목표로 도입했습니다.
- 핵심 결말은 독립으로 고정하고 NPC 선택은 공략 방식과 후일담을 바꾸도록 설계했습니다.
- 다른 번호 지구와의 직접 협력은 엔딩 이후로 분리했습니다.

## 검증

- 정본 지구가 자신의 성공을 유일한 정답으로 주장하는 명분과 그 오만이 동시에 설명됩니다.
- 플레이어의 설계자 각성이 세계관의 반복 구조와 연결됩니다.
- 일반 게이트, 앵커 게이트와 최후의 게이트의 역할이 서로 구분됩니다.
- 싱글·호스트 월드의 메인 목표는 하나의 번호 지구 독립으로 유지됩니다.
- 다른 번호 지구와 세계관 확장을 위한 여지는 남기되 현재 범위에 포함하지 않았습니다.

## 다음 작업

- 최초 게이트가 열린 정확한 연도와 사건명을 결정합니다.
- 외부 침략자의 정체와 침공 목적을 설계합니다.
- 핵심 앵커의 개수와 각 기능을 확정합니다.
- 주요 NPC·세력과 관계 변수를 작성합니다.
- 첫 앵커 게이트의 개별 시나리오를 제작합니다.
- 정본 지구의 최초 설계자와 반대 세력을 구체화합니다.
- 세계선 사이의 미지 공간 `이면`은 명칭만 유지하고 세부 설정은 보류합니다.

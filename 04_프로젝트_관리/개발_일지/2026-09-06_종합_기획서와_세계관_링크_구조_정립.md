# 2026-09-06 개발 일지

## 오늘의 목표

- 과거 종합 기획서의 형식을 현재 에르고스퀘어 기획에 맞게 다시 구성합니다.
- 저장소와 안티그래비티에서 작성된 최신 데이터를 하나의 문서 흐름으로 통합합니다.
- 세계관 전체 이야기를 읽다가 핵심 용어의 상세 설명으로 이동할 수 있는 링크 구조를 만듭니다.
- 기존 세부 명세의 기준성을 유지하면서 종합 문서의 가독성을 높입니다.

## 작업 내용

### 종합 기획서 재구성

- 과거 `지구-164991: 청사진 각성자 메인 기획서`의 장 구성을 참고했습니다.
- 오래된 시스템 내용은 그대로 복원하지 않고 현재 저장소의 조작, 전투, 파츠, 코어, 실패·철수와 튜토리얼 명세를 우선했습니다.
- 게임 개요, 목표 사용자, 세계관, 핵심 플레이, UI, 맵, 개발 전략과 확장 방향을 한 문서에서 이어 읽을 수 있도록 정리했습니다.
- 메인 시나리오와 TUT-00~08 튜토리얼을 서사 본문과 기획 해설로 분리했습니다.
- 실제 수치와 예외 처리는 연결된 세부 기준 문서를 우선하도록 문서 경계를 명시했습니다.

### 기존·안티그래비티 초안 충돌 판정

| 충돌 항목 | 종합 판정 |
| --- | --- |
| `Space` 공통 회피 | `Space` 정신 집중, 회피·기동은 장비 스킬 |
| 뱅가드·거너 등 고정 직업 | 근접·투사·영역 전개 계통 |
| 월도·어둑시니 복합 보스 | 튜토리얼 보스는 월도 단독 |
| 서울 지하상가 내부 | 대체 도입 후보, 현재 동굴형 게이트 내부와 분리 |
| 5개 앵커와 특정 신화 고정 | 기능·개수·문화권 배치 `TBD` |
| 메타버스 거래·UGC 경제 | 현재 개발 비목표 |

확정되지 않은 새 아이디어를 기존 기준 위에 자동으로 덮지 않고 `후보`, `TBD`와 `비목표`로 구분했습니다.

### 세계관 전체 스토리 작성

- 인간과 이면의 상호 관측에서 이야기를 시작했습니다.
- 최초 게이트 침공, 지구 자아의 각성, 대분기와 번호 지구 탄생을 연결했습니다.
- 정본 지구의 선언과 정본화 위협을 본편 갈등으로 정리했습니다.
- 잠복 게이트 폭주, 토벌팀 희생, 에르고스퀘어 발현과 월도 보스를 튜토리얼 서사로 연결했습니다.
- 설계자 명명 이후 허브 성장, 현현체·각성자 관계, 앵커 귀속과 최후의 게이트까지 이어지는 전체 흐름을 작성했습니다.
- 이면의 정체, 인간화 성공 여부와 공존 가능성은 결말 이후까지 남길 장기 미스터리로 분리했습니다.

### 클릭형 세계관 용어집 구축

- 세계관 전체 스토리에서 주요 단어를 클릭하면 용어집의 해당 항목으로 이동하도록 상대 링크를 적용했습니다.
- 용어집에는 각 개념의 짧은 정의, 공개 시점, 주의 또는 미확정 사항과 상세 기준 문서를 기록했습니다.
- 번호 지구, 지구 자아, 대분기, 정본 지구, 정본화, 이면과 게이트 유형을 정리했습니다.
- 각성자, 설계자, 현현체, 게이트 투영체, 폭주 유출 개체와 영혼 주입형의 분류를 구분했습니다.
- 에르고스퀘어, 청사진, 파츠, 아키텍처, 코어, 주머니, 허브와 철수를 시스템 용어로 연결했습니다.
- 같은 단어를 매번 링크하지 않고 장이나 문단의 첫 등장 위주로 적용했습니다.

### 문서 인덱스와 웹 내비게이션

- 프로젝트 개요와 세계관 인덱스에 종합 기획서, 전체 스토리와 용어집을 연결했습니다.
- MkDocs의 프로젝트 개요 및 세계관·콘텐츠 내비게이션에 새 문서를 추가했습니다.
- 통합 세계관 초안에서 전체 스토리와 용어집으로 이동하는 Quick Links를 추가했습니다.

## 발생한 문제

- 예전 종합 기획서와 현재 세부 명세의 조작·직군·멀티플레이·경제 방향이 서로 달랐습니다.
- 안티그래비티에서 추가된 일부 시나리오가 장소, 보스 명칭과 앵커 개수를 확정값처럼 서술하고 있었습니다.
- 전체 스토리 안의 모든 반복 용어에 링크를 적용하면 문장이 링크로 과밀해지고 읽기 흐름이 끊겼습니다.
- `현현체`와 `각성자`, 자연 발생 도깨비와 폭주 유출 개체처럼 비슷해 보이지만 다른 분류가 여러 문서에 흩어져 있었습니다.
- 로컬 환경에 MkDocs 실행 패키지가 없어 실제 HTML 엄격 빌드를 실행할 수 없었습니다.

## 원인

- 프로젝트 방향이 여러 대화를 거치며 변경됐지만 오래된 상위 문서 일부가 최신 세부 기준을 완전히 따라가지 못했습니다.
- 안티그래비티 초안은 새로운 아이디어를 빠르게 집대성하는 과정에서 확정 방향과 대안을 같은 층위로 작성했습니다.
- 종합 문서, 세계관 사실, 시나리오와 시스템 명세의 역할이 명시적으로 나뉘지 않으면 같은 정의가 반복됩니다.
- Markdown 링크는 쉽게 추가할 수 있지만 반복 빈도와 연결 대상을 정하지 않으면 문서 유지 비용이 증가합니다.

## 해결

- 과거 종합 문서는 `형식`, 현재 세부 명세는 `내용의 기준`으로 사용했습니다.
- 충돌하는 설정을 확정, 후보, TBD와 비목표로 판정하는 표를 종합 기획서에 추가했습니다.
- 문서 구조를 `세계관 전체 스토리 → 세계관 용어집 → 상세 기준 문서`의 3단계로 정했습니다.
- 전체 스토리에서는 각 장 또는 문단의 첫 용어만 링크하고 반복 단어는 일반 텍스트로 유지했습니다.
- 용어집에 공개 시점과 금지 해석을 함께 기록해 스포일러와 설정 혼동을 줄였습니다.
- MkDocs 준비 스크립트를 실행하고 생성 소스의 내비게이션 대상과 모든 로컬 Markdown 링크를 검사했습니다.

## 검증

- 종합 기획서의 로컬 Markdown 링크 26개가 실제 문서를 가리키는지 확인했습니다.
- 세계관 전체 스토리와 용어집의 Markdown 링크 69개가 실제 문서를 가리키는지 확인했습니다.
- 전체 스토리가 사용하는 용어집 앵커 23개와 용어집 제목을 대조했습니다.
- MkDocs 준비 스크립트가 `docs/.generated` 소스를 정상 생성했습니다.
- 생성된 MkDocs 내비게이션의 모든 Markdown 대상이 존재함을 확인했습니다.
- 신규 문서의 작성자를 `송예찬`으로 통일했습니다.
- 기존 안티그래비티 작업 파일을 삭제하거나 덮어쓰지 않았습니다.
- 로컬 MkDocs 패키지가 없어 `mkdocs build --strict` 실제 실행은 후속 검증으로 남았습니다.

## 오늘의 결과

- 프로젝트 전체를 처음 접한 사람이 한 문서에서 핵심 시스템과 시나리오를 파악할 수 있는 종합 기획서가 생겼습니다.
- 세계관의 시작부터 본편 결말과 이후 미스터리까지 하나의 서사로 읽을 수 있게 됐습니다.
- 세계관 용어를 클릭해 정의와 상세 문서로 이동하는 탐색 구조가 마련됐습니다.
- 개발 중 설정이 추가되면 전체 스토리, 용어집과 세부 명세 중 어디를 수정해야 하는지 기준이 생겼습니다.
- 문서를 한 번에 완성하려 하기보다 개발 과정에서 확정된 내용을 누적 갱신할 수 있는 상태가 됐습니다.

## 다음 작업

1. 종합 기획서의 `P0 — 튜토리얼 구현 전` 항목을 순서대로 결정합니다.
2. 첫 장비를 임시 현실 고정봉, 녹슨 검과 낡은 빗자루 중 하나의 지급 흐름으로 통합합니다.
3. 튜토리얼 코어 자원의 정식 명칭, 최대량, 생성량과 스킬 소비량을 정합니다.
4. TUT-00~08 각 장면을 실제 Unity 구현 상태와 완료 조건에 연결합니다.
5. 새 세계관 용어가 생기면 용어집에 정의와 공개 시점을 먼저 추가합니다.
6. MkDocs가 설치된 환경 또는 GitHub Actions에서 실제 웹 빌드를 확인합니다.

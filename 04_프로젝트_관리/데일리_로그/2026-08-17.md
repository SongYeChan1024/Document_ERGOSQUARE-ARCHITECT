# 2026-08-17 데일리 로그

## 오늘 한 일

- 문서 저장소에 MkDocs Material 기반 웹 뷰어와 GitHub Pages 자동 배포를 구성했습니다.
- 주요 README에 Quick Links, 상태 표와 필요한 Mermaid 흐름도를 추가했습니다.
- 문서 구조와 내부 링크를 검토하고 웹 문서 빌드를 검증했습니다.
- 모든 기획 문서의 Revision History 작성자를 `송예찬`으로 통일했습니다.
- 이후에도 AI·도구 이름이 작성자 칸에 들어가지 않도록 문서 규칙을 추가했습니다.
- 튜토리얼 첫 아이템 묶음의 구현 가안을 정리했습니다.
  - 임시 기본 무기 `낡은 부지깽이`
  - 첫 장비형 파츠 `낡은 빗자루`
  - `낡은 정기의 혼 코어 [근접]`
  - 소형 주머니와 낡은 방어판
  - 응급 회복제와 코어 활성제
  - 기억 잔재·도구 파편·영혼 결박 파편·월도 잔해
- 튜토리얼은 정식 드롭 구조를 사용하되 첫 획득 결과는 별도 보정 데이터로 고정하는 방향을 정했습니다.
- Excel 마스터 데이터를 JSON으로 변환하고 Unity에서 검증·로드하는 데이터 파이프라인 방향을 정리했습니다.
- 실제 Unity 프로젝트 상태를 확인하고 첫 구현 목표를 우클릭 이동과 아이소메트릭 카메라가 동작하는 이동 버티컬 슬라이스로 정했습니다.

## 오늘의 결정

- 튜토리얼은 무작위 결과보다 학습의 재현성을 우선하며 첫 코어·무기·필수 드롭은 고정합니다.
- 정식 파밍에서는 같은 아이템 원형에 스킬과 기초 능력치가 무작위로 부여됩니다.
- Excel은 정적 정의와 밸런스 수치, JSON은 Unity 입력 데이터, 세이브 데이터는 개별 아이템 인스턴스를 담당합니다.
- Unity 프리팹·아이콘·VFX 참조는 JSON 경로가 아니라 안정적인 에셋 키와 ScriptableObject 카탈로그로 연결합니다.
- 실제 구현은 아이템 시스템보다 플레이어 이동·카메라·충돌 검증을 먼저 완료합니다.

## 검증 결과

- 문서 웹 빌드 `--strict` 통과
- GitHub Pages 배포 성공 및 공개 URL HTTP 200 확인
- 공개 프로젝트 로드맵에서 `송예찬` 표기 확인
- Markdown Revision History의 `Codex` 작성자 표기 0건 확인
- Unity 프로젝트에서 Input Actions, `GameplayInputReader`, URP 설정과 `TestMap` 존재 확인

1. 현재 Unity 변경분을 에디터에서 컴파일·씬 저장 상태까지 확인합니다.
2. AI Navigation과 테스트 장애물을 준비합니다.
3. 캡슐 플레이어의 우클릭 지점 이동을 구현합니다.
4. 아이소메트릭 추적 카메라를 연결합니다.
5. 이동 버티컬 슬라이스가 안정되면 회피와 상호작용을 추가합니다.

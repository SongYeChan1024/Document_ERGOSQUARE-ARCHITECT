# 2026-08-18 데일리 로그

## 오늘 한 일

- 우클릭을 누르고 있는 동안 커서를 따라 목적지가 갱신되는 플레이어 이동을 구성했습니다.
- 아이소메트릭 Cinemachine 카메라와 테스트 지면·장애물·충돌 기반을 연결했습니다.
- `Space` 정신 집중으로 기존 코어 에너지를 회복하는 흐름을 적용했습니다. 별도 집중 게이지는 두지 않았습니다.
- Canvas 기반 인게임 HUD를 구성하고 해상도 대응용 앵커, `Canvas Scaler`, 레이아웃 그룹과 9-Slice 프레임 기준을 적용했습니다.
- `Tab` 전개 모드에서 필드 전체의 옅은 격자와 근접 직군의 강조된 `3×3` 유효 영역을 표시하도록 구성했습니다.
- 테스트용 `낡은 빗자루`를 `G`로 획득하는 흐름을 만들었습니다.
- 획득 직후 편집 창을 강제로 열지 않고, `Tab → 청사진 편집`으로 진입하도록 변경했습니다.
- 보유 파츠를 좌클릭 선택 후 격자에 배치하거나 드래그 앤 드롭으로 직접 배치할 수 있게 했습니다.
- 배치된 빗자루에 마우스를 올리고 `QWERASDF`를 눌러 액티브 스킬을 할당하는 흐름을 구현했습니다.
- 할당된 스킬을 사용하면 자원과 재사용 대기를 확인하고, 빗자루를 잠시 손에 생성해 내려치기·쓸어치기·찌르기 모션과 피해 판정을 실행한 뒤 회수하도록 구성했습니다.
- 청사진 편집 및 빗자루 스킬 프로토타입 문서와 UI 기준 시안을 추가했습니다.

## 오늘의 결정

- `G`는 획득만 담당하고 청사진 편집은 전개 HUD 안의 버튼에서 명시적으로 시작합니다.
- 근접 직군의 1레벨 청사진은 `3×3`이며 중앙 한 칸은 설계자 위치로 잠급니다.
- 옅은 월드 격자와 강조 격자는 같은 셀 크기를 사용합니다. 큰 파츠는 여러 셀을 합친 점유 영역으로 표현합니다.
- 정신 집중은 코어 에너지의 보조 회복 수단이며 전개 전후 모두 사용할 수 있지만 자동 생성보다 비효율적으로 유지합니다.
- 장비형 파츠는 상시 장착하지 않고 해당 스킬을 사용할 때만 손에 나타나는 연출을 기본 방향으로 둡니다.
- 현재 공격 모션은 기능 검증용이며 최종 캐릭터 애니메이션으로 보지 않습니다.

## 다음 시작점

1. 테스트용 적 프리팹을 배치해 세 빗자루 스킬의 범위·피해·경직을 직접 확인합니다.
2. 캐릭터 Animator와 Animation Event를 연결해 임시 Transform 모션을 교체합니다.
3. 자원 부족·재사용 대기·잘못된 배치·슬롯 중복 피드백을 HUD에 추가합니다.
4. 빗자루의 첫 고정 스킬과 무작위 능력치 범위를 튜토리얼 드롭 데이터에 연결합니다.

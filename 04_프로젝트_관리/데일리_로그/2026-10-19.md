## 오늘 한 일

- 기존 쿼터뷰 데모를 보존하고 별도 `ThirdPerson_Comparison` 연습장 씬을 만들었습니다.
- WASD 이동·마우스 시점·좌클릭 3타, QERTZXCV 스킬 8칸·F 상호작용·1234 소모품으로 입력을 구성했습니다.
- 기존 데모 플레이어·FSM·Animator·전투 데이터를 재사용하고 카메라 기준 이동·공격 방향과 장애물 카메라 대응을 연결했습니다.
- Q 빗자루·E 월도와 독립 코어 2개를 미리 배치한 비교용 Lv.5 구성을 준비했습니다. 1번 회복약·2번 정기약을 지급하고 3·4번은 빈 소모품 슬롯으로 남겼습니다.
- 표적 3개·F 보급대·표적 체력 표시·실제 검 끝 잔상과 스킬 방향 가이드를 추가했습니다. 기존 새 UI에서 장비와 스킬 배정을 편집할 수 있습니다.
- 플레이어 루트의 Agent 높이와 카메라 기준점을 맞추고, NavMesh 경계 이동 시 높이가 흔들리지 않도록 보정했습니다.

## 오늘의 결정

본편을 바로 전환하지 않고 두 조작 방식을 비교합니다. 기존 입력 자산·데모 프리팹·빌드 씬 목록은 유지하며, 직접 이동과 UI 키 재정의는 비교 씬에서 선택해 사용합니다. 카메라·이동 수치와 시험 약품 효과는 가안입니다.

## 검증 결과

- 별도 Unity 6000.3.7f1에서 편집 연결·바인딩 11개, 비교 씬 플레이 45개, 기존 데모 클릭 이동·Animator·전투 회귀 210개를 통과했습니다. 반복 프레임 검사를 포함합니다.
- 실제 3타 연계·피해, 스킬 비용·냉각, 소모품·F 보급·메뉴 차단, 벽 앞 이동·카메라 대응을 확인했습니다.
- 기존 자산 85개의 해시 동일과 전달 파일 30개를 기록했습니다. 자동 기능 검사이며 사용자의 실제 수동 조작감 평가와 전체 튜토리얼 완주는 후속입니다.

## 다음 시작점

1. Unity 메뉴 `Tools → ERGOSQUARE → Comparison → Open Third Person Comparison`에서 열고 재생 전 FSM·Animator 연결을 확인합니다.
2. 실제 플레이로 이동·시점·공격·Q/E 스킬과 장비 드래그를 확인하고, 이동 중 스킬키 접근성을 비교합니다.
3. 쿼터뷰와 비교한 뒤 본편 조작 방식의 전환 여부와 수정 우선순위를 정합니다.

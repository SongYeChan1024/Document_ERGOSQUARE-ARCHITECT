# 2026-08-19 데일리 로그

## 오늘 한 일

- 플레이어 주변의 상호작용 가능 오브젝트를 탐색하고 우선순위와 거리에 따라 현재 대상을 선택하는 공통 상호작용 구조를 만들었습니다.
- 상호작용 대상 위에 `G` 키와 행동 문구가 표시되는 월드 UI를 Canvas HUD에 연결했습니다.
- 기존 `낡은 빗자루` 획득을 공통 상호작용 인터페이스에 편입했습니다.
- 빗자루 스킬의 범위·피해·경직을 확인할 수 있는 체력 60의 테스트용 빗자루 도깨비를 제작하고 `TestMap`에 배치했습니다.
- 내려치기·쓸어치기·찌르기에 서로 다른 피해 배율, 경직 시간과 넉백 거리를 적용했습니다.
- 테스트 적의 체력바, 피격 점멸, 넉백, 처치 연출과 2.5초 후 재생성을 구현했습니다.
- 테스트 적 프리팹과 전용 머티리얼을 현재 프로젝트 폴더 규칙에 맞게 생성했습니다.
- 반복 조립이 가능한 전투 샌드박스 에디터 빌더를 추가했습니다.

## 오늘의 결정

- 모든 획득·조사 오브젝트는 `IInteractable`을 공통 경계로 사용합니다.
- 상호작용 대상 선택과 `G` 입력 처리는 게임플레이 계층이, 키 안내의 위치와 표현은 프레젠테이션 계층이 담당합니다.
- 테스트 적은 AI 완성본이 아니라 스킬 범위·피해·경직·넉백을 빠르게 반복 검증하기 위한 전투 표적입니다.
- 현재 피해·경직·넉백 수치는 밸런스 확정값이 아닌 프로토타입 가안입니다.
- 테스트 적은 처치 후 자동 재생성해 같은 플레이 세션에서 스킬을 반복 비교할 수 있게 합니다.

## 검증 결과

- Unity 스크립트 컴파일과 어셈블리 재로드 통과
- 전투 샌드박스 빌더 재실행과 씬·프리팹 참조 연결 확인
- 플레이 모드에서 테스트 적과 월드 체력바 표시 확인
- 플레이 모드 진입 후 콘솔 오류·경고 0건 확인
- 테스트 적 프리팹의 세 머티리얼 참조와 HUD 상호작용 안내 컴포넌트 연결 확인
- 실제 세 스킬의 손맛과 수치 비교는 후속 플레이테스트 대상으로 유지

## 다음 시작점

1. `G 획득 → 청사진 배치 → 스킬 할당 → 자원 회복 → 적 타격` 전체 흐름을 한 세션에서 반복 검증합니다.
2. 테스트 적에게 플레이어·코어를 구분하는 추적, 공격과 어그로 전환 AI를 추가합니다.
3. 피해량·경직·넉백 수치를 화면에서 비교할 수 있는 디버그 피드백을 보완합니다.
4. 임시 Transform 공격 연출을 Animator와 Animation Event 기반으로 교체합니다.
5. 첫 도깨비 전투 조우의 배치와 완료 조건을 레벨 디자인에 연결합니다.

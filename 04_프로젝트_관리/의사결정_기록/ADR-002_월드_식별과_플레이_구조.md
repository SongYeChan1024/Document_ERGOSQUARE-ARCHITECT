# ADR-002: 월드 식별과 플레이 구조

> [!IMPORTANT]
> 문서 상태: 확정. 번호 형식과 월드 간 캐릭터 이전 세부 규칙은 `TBD`입니다.

## 상황

고정된 `지구-164991`을 배경으로 한 3~4인 온라인 협동 구조는 플레이어가 직접 월드를 생성하고 혼자 또는 친구와 장기간 운영하는 목표와 맞지 않았습니다. 또한 모든 플레이어가 같은 세계의 주민이라는 설정은 로컬 세이브와 호스트 서버를 세계관 안에서 설명하기 어려웠습니다.

## 선택

- 새 로컬 월드를 생성할 때 고유 번호를 가진 지구를 만듭니다.
- 번호는 게임을 실행할 때가 아니라 월드를 생성할 때 한 번 부여하고 세이브 수명 동안 유지합니다.
- 기본 플레이 형태는 싱글 또는 1~4인 로컬·호스트 기반 친구 협동입니다.
- 호스트 월드의 지형, 기지, 게이트와 진행 상태를 권위 있는 월드 기록으로 사용합니다.
- 동등한 분기 중 외부 침략을 막는 데 성공한 한 지구가 자신의 번호를 버리고 `정본 지구`를 자칭합니다. 정본은 객관적 원본이 아니라 승전 세계의 정치적 선언입니다.
- 엔딩 전 게이트는 정본 지구의 강제 병합 통로이며, 엔딩 후 플레이어가 통제 가능한 세계 간 항로로 재설계합니다.

## 세계관과 시스템의 연결

| 게임 기능 | 세계관 의미 |
| --- | --- |
| 새 게임 | 새로운 번호 지구 생성 |
| 월드 세이브 | 해당 지구의 역사와 상태 보존 |
| 엔딩 전 친구 초대 | 호스트 지구의 작전에 참가하는 협동 설계자 |
| 서버 종료 | 연결 종료, 지구 기록은 호스트에 유지 |
| 게이트 공략 | 다른 지구와의 강제 공명 해소 |
| 엔딩 이후 원정 | 통제된 좌표로 게이트 개방 |

지구 번호는 공개 가능한 월드 식별자이며 접속 비밀번호로 사용하지 않습니다. 실제 초대·접속 정보와 내부 저장 ID는 별도로 관리합니다.

## 선택 이유

- 싱글 플레이와 친구 협동을 같은 규칙으로 설명할 수 있습니다.
- 각 세이브가 플레이어 소유의 평행 지구가 되어 장기 월드에 소유감을 제공합니다.
- 새 지구 생성과 친구 월드 방문을 향후 콘텐츠로 확장할 수 있습니다.
- MMORPG의 공용 영구 월드 없이도 세계 간 연결이라는 판타지를 유지할 수 있습니다.

## 결과

- 권장 인원 표기는 `1~4인`으로 통일합니다.
- 필수 전투·건설·게이트 공략은 싱글로 완료할 수 있어야 합니다.
- 협동 프레임은 필수 직업 조합이 아니라 전문화와 역할 확장으로 설계합니다.
- 캐릭터·장비의 다른 지구 반입은 복제와 밸런스 문제를 검증한 뒤 확정합니다.
- 월드 번호 형식, 충돌 방지용 내부 ID와 공유 코드 형식은 기술 설계에서 결정합니다.

## 대안

- 고정된 하나의 지구에서 모든 플레이어가 활동하는 온라인 게임
- 접속할 때마다 새 번호를 발급하는 세션형 세계
- 캐릭터와 장비를 모든 월드에서 완전히 공유하는 계정 귀속 구조

위 대안은 장기 로컬 월드의 지속성, 싱글 밸런스와 서버 간 자원 복제 문제 때문에 기본 방향에서 제외합니다.

# 플레이어 FSM과 Animator 데이터 연동

상태: 초안 · 별도 프로토타입 검수 통과 / 작성자: 송예찬 / 날짜: 2026-10-18

기존 3D 캐릭터는 런타임 클립 샘플링과 수동 뼈 보간을 사용했고, 기본 공격의 실제 판정과 표현의 기준이 분리되어 있었다. 플레이어 요청에 따라 게임플레이 FSM과 실제 AnimatorController를 연결한다.

FSM은 이동·공격·스킬·집중·메뉴·사망의 우선순위와 요청 허용을 관리한다. Animator는 그 상태와 데이터를 받아 표현한다. 피해·자원·쿨타임은 기존 게임플레이 코드가 계속 소유한다. 공격 모션, 실행 길이, 타격 비율을 하나의 데이터 자산에서 읽고 타격 이벤트와 타이머는 동일 판정을 한 번만 소비한다.

초기 평타는 기존 주인공 리깅에 적용한 VARCO `combo_slash`를 연속된 세 구간으로 나눴다. 이후 v0.2–v0.3에서 몸통·팔·하체를 오프라인 IK로 재구성했으나, 사용자가 요청한 원본 동작 보존 범위를 벗어났으므로 현재 기본 공격에서 제외한다. 현재는 보존된 VARCO 원래 3타와 타격 시점을 복원하고 오른쪽 전완·손목의 8개 회전 채널만 보정한다. 나머지 1,626개 float 곡선과 손의 이동 경로는 원본 그대로 유지한다. 실제 Animator가 보정 클립을 재생하며 검 자식만 독립적으로 회전시키거나 런타임에 뼈를 덮어쓰지 않는다. 원본 클립과 시퀀스는 `PlayerAnimatorV2/Originals`에, 원본 FBX는 `04.Graphics/Characters/PlayerAnimatorV2/Models/Varco_combo_slash.fbx`에 보존한다.

이동은 NavMesh에 맡기고 오른손 손가락은 마스크 레이어로 그립을 유지한다. 메뉴/사망은 스킬 코루틴도 취소하며 이미 소비한 쿨타임은 유지한다.

이전 추가 검술 영상 기반의 하체 재구성 및 215개 검사 결과는 `Sword_Footwork_v6_20261018`의 과거 이력으로 보존한다. 해당 생성기는 실험용 메뉴로 옮겼고 정상 재생성 경로는 원본 보존형 궤적 보정기를 사용한다. 실제 이동 거리는 계속 NavMesh가 소유한다.

두 튜토리얼 씬에 플레이어 FSM·장비·공격 컴포넌트와 모델 Animator·Controller·공격 데이터 참조를 편집 모드로 저장한다. 전용 인스펙터에서 재생 전 연결과 원본을 확인하고 그래프를 바로 열 수 있으며, 재생 중에는 실제 FSM 상태·공격 단계·속도·재생 클립을 확인한다. 스크립트 리로드와 씬 열기 시 비어 있는 연결을 복구하되 사용자의 열린 씬은 자동 저장하지 않는다. 기존 사용자 지정 Controller도 덮어쓰지 않는다.

수치와 조작감은 가안이다. 무기별 고유 모션 확대, 경사 발 IK, 수동 튜토리얼 전체 검수는 별도 범위다. 신규 인벤토리 UI와 자유 역할 에르고스퀘어의 기획 방향은 유지한다.

구체적인 상태·데이터·검증 계약은 [플레이어 FSM과 Animator 연동 명세](../../03_기술_문서/시스템별_구현_명세/플레이어_FSM과_Animator_연동_명세.md)를 참조한다.

초기 구현 당시 FSM/Animator 54개, 장착·미리보기 35개, 에르고스퀘어 조합·소환 78개 검사를 통과한 결과는 유지한다. 현재 원본 복원본은 별도 Unity에서 씬 저장·재열기 등 편집 모드 24개, 실제 Animator의 검날/표적 접촉·피해·FSM 등 Play Mode 210개 검사를 통과했다. 반복 프레임 검사가 포함된다. 원본 곡선 보존과 보정 회전의 연속성을 추가 확인했다. 최신 근거는 `Tools/ArtReview/Player_Inspectable_Restored_v7_20261018`에 기록한다. 메인 에디터의 미저장 씬은 보존했으며 화면 직접 확인과 전체 수동 플레이는 이 결과에 포함하지 않는다.

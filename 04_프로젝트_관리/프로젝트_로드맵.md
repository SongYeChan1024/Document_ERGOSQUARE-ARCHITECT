# 프로젝트 로드맵

> [!IMPORTANT]
> 문서 상태: 초안. 일정이 아니라 플레이 가능한 결과를 기준으로 관리합니다.

## P0 — 기술 검증

- 캐릭터 이동과 카메라
- 기본 공격
- 테스트 적
- 격자 배치와 월드 전개

완료 기준: 테스트 공간에서 이동·전투하고 청사진 한 세트를 전개할 수 있습니다.

## P1 — 코어 루프

- 작전 시작
- 청사진 편성
- 전개와 회수
- 모듈 피해와 파괴
- 전투, 결과, 실패 및 재시작

완료 기준: 허브 준비부터 결과 화면까지 한 번 플레이할 수 있습니다.

## P2 — 협동과 콘텐츠

- 최대 4인 접속과 상태 동기화
- 적 종류 추가
- 테스트 스테이지 제작
- 보상과 성장
- UI와 사운드

완료 기준: 10~15분 분량의 협동 플레이가 가능합니다.

## P3 — 폴리싱

- 최적화
- 튜토리얼
- 전투·UI 연출
- 버그 수정
- 빌드 배포

완료 기준: 처음 접한 사용자가 별도 설명 없이 핵심 루프를 완료할 수 있습니다.

## 범위 통제

- 각 단계의 완료 기준을 통과하기 전 다음 단계 기능을 확장하지 않습니다.
- 신규 아이디어는 Issues 또는 아이디어 백로그에 기록하고 즉시 범위에 넣지 않습니다.
- 생성형 AI와 라이브 서비스 경제는 MVP 필수 범위에서 제외합니다.

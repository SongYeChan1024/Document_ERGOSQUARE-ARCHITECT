# 프로젝트 한 장 기획서

> [!IMPORTANT]
> 문서 상태: 초안

## 게임 제목

`ERGOSQUARE: ARCHITECT`
한국어명: `에르고스퀘어: 설계자`

## 한 줄 설명

이 게임은 협동 액션을 선호하는 플레이어가 인벤토리로 전투 공간을 설계하고 동료와 함께 이를 지키는 과정에서 빌드 설계와 위험 관리의 재미를 경험하는 3~4인 협동 PvE 게임이다.

## 장르

3~4인 협동 PvE / 실시간 액션 / 랜덤 배치

## 플랫폼

PC Windows 우선 검토

## 타깃 사용자

- 협동 PvE와 역할 분담을 선호하는 플레이어
- 인벤토리 빌드와 배치 최적화를 즐기는 플레이어
- 15~30분 단위의 반복 플레이를 선호하는 플레이어

예상 연령과 최종 세션 시간은 플레이테스트 후 확정합니다.

## 핵심 경험

- 내가 편성한 인벤토리가 실제 전투 공간으로 펼쳐지는 성취감
- 강한 빌드를 사용하려면 약점인 코어를 지켜야 하는 긴장감
- 서로 다른 설계가 연결되며 생기는 협동과 역할 분담

## 핵심 플레이 루프

```text
작전 준비 → 청사진 편성 → 균열 진입 → 에르고스퀘어 전개
→ 탐색과 협동 전투 → 코어 방어 → 보상 → 성장 → 재도전
```

## 차별화 요소

1. 인벤토리 격자 배치가 전장 배치로 변환됩니다.
2. 빌드의 핵심 기능이 적에게 파괴될 수 있습니다.
3. 팀원의 에르고스퀘어가 전장에서 역할과 약점을 동시에 만듭니다.

## 개발 목표

- Unity에서 격자 기반 청사진 편성과 현실 전개를 연결합니다.
- 파괴 가능한 모듈을 중심으로 협동 전투의 재미를 검증합니다.
- 멀티플레이에서 모듈 배치와 상태를 안정적으로 동기화합니다.

## MVP 범위

- 1개 테스트 전장
- 1~2개 설계자 프레임
- 코어와 최소 모듈 세트
- 청사진 편성·전개·회수
- 기본 전투와 적 1종
- 승리·실패·결과·재시작
- 최대 4인 접속 및 핵심 상태 동기화

## 제외 범위

- 대규모 오픈월드
- 경쟁 PvP
- 다수의 캐릭터와 장비
- 완성형 라이브 서비스 경제
- 생성형 AI가 진행을 막는 필수 기능
- 콘솔·모바일 동시 출시

## 핵심 검증 질문

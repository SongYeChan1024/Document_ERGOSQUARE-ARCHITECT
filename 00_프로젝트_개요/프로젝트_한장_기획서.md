# 프로젝트 한 장 기획서

> [!IMPORTANT]
> 문서 상태: 초안

## 게임 제목

`ERGOSQUARE: ARCHITECT`
한국어명: `에르고스퀘어: 설계자`

## 한 줄 설명

이 게임은 플레이어가 고유 번호를 가진 자신의 지구를 만들고 정해진 허브 시설을 성장시키며, 인류의 기억과 공명해 열린 게이트를 공략하고 살아서 전리품을 반출하는 1~4인 협동 액션 게임이다.

## 장르

1~4인 협동 샌드박스 / 실시간 액션 / 전략 배치 / 퀘스트형 게이트

## 플랫폼

PC Windows 우선 검토

## 타깃 사용자

- 협동 PvE와 역할 분담을 선호하는 플레이어
- 혼자 장기 월드를 만들고 자신의 속도로 성장하는 플레이어
- 친구가 만든 로컬·호스트 월드에 합류해 공동 허브를 운영하는 플레이어
- 인벤토리 빌드와 배치 최적화를 즐기는 플레이어
- 15~30분 단위의 반복 플레이를 선호하는 플레이어

예상 연령과 최종 세션 시간은 플레이테스트 후 확정합니다.

## 핵심 경험

- 내가 편성한 인벤토리가 실제 전투 공간으로 펼쳐지는 성취감
- 새 세이브마다 고유한 번호와 상태를 가진 지구를 성장시키는 소유감
- 신화·설화·우화의 사건을 전투와 퀘스트로 해결하는 탐험감
- 강한 빌드를 사용하려면 약점인 코어를 지켜야 하는 긴장감
- 서로 다른 설계가 연결되며 생기는 협동과 역할 분담

## 핵심 플레이 루프

```text
월드 탐색·허브 시설 강화 → 청사진 편성 → 게이트 발견·분석
→ 게이트 진입 → 퀘스트·전투 → 폐쇄 또는 철수
→ 전리품 반출 → 지구 안정화와 성장 → 다음 게이트
```

## 차별화 요소

1. 인벤토리 격자 배치가 전장 배치로 변환됩니다.
2. 빌드의 핵심 기능이 적에게 파괴될 수 있습니다.
3. 팀원의 에르고스퀘어가 전장에서 역할과 약점을 동시에 만듭니다.
4. 인류의 기억이 연결할 평행 지구를 선택해 게이트마다 다른 이야기와 법칙을 만듭니다.
5. 다른 번호 지구와 이면을 활용한 엔딩 이후 콘텐츠는 후속 확장 후보로만 남기고 현재는 `TBD`로 둡니다.

## 개발 목표

- Unity에서 격자 기반 청사진 편성과 현실 전개를 연결합니다.
- 파괴 가능한 파츠를 중심으로 협동 전투의 재미를 검증합니다.
- 싱글 플레이를 기준으로 모든 필수 기능이 동작하도록 설계합니다.
- 1~4인 호스트 협동에서 월드·파츠 상태를 안정적으로 동기화합니다.

## MVP 범위

- 1개 테스트 전장
- 1~2개 설계자 프레임
- 코어와 최소 파츠 세트
- 청사진 편성·전개·회수
- 기본 전투와 적 1종
- 승리·철수·중상·전멸과 월드 재생성
- 싱글 플레이와 최대 4인 호스트 접속 및 핵심 상태 동기화

## 제외 범위

- 대규모 오픈월드
- 경쟁 PvP
- 다수의 캐릭터와 장비
- 완성형 라이브 서비스 경제
- 생성형 AI가 진행을 막는 필수 기능
- 콘솔·모바일 동시 출시

# 레퍼런스 분석

> [!IMPORTANT]
> 문서 상태: 초안

## 목적

ERGOSQUARE의 핵심 경험을 검증하기 위해 참고 작품의 구조를 분석합니다. 표현을 복제하지 않고 문제 해결 방식과 플레이 감정만 비교합니다.

## 분석 기준

| 기준 | 확인할 질문 |
| --- | --- |
| 협동 | 플레이어가 자연스럽게 역할을 나누는가? |
| 빌드 | 선택이 실제 플레이 방식에 영향을 주는가? |
| 방어 | 지켜야 할 대상이 판단과 이동을 만드는가? |
| 세션 | 준비·전투·보상·재도전의 호흡은 어떤가? |
| UI | 복잡한 정보를 빠르게 이해시키는가? |

## 후보

세부 작품과 분석 내용은 직접 플레이 및 자료 확인 후 추가합니다.

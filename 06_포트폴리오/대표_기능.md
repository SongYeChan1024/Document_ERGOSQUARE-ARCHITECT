# 대표 기능

> [!IMPORTANT]
> 문서 상태: 초안

## 1. 청사진 편성

격자에 코어와 모듈을 배치해 전투 역할과 약점을 설계합니다.

## 2. 에르고스퀘어 전개

저장된 격자 데이터를 실제 전투 공간의 모듈로 변환합니다.

## 3. 파괴 가능한 빌드

전개된 모듈이 공격받으면 기능이 중단되어 전투 판단이 달라집니다.

## 4. 협동 방어

팀원의 서로 다른 청사진과 코어를 지키며 역할을 분담합니다.

현재는 기획 단계이며 구현 증거가 생길 때마다 GIF·영상·코드 설명을 연결합니다.

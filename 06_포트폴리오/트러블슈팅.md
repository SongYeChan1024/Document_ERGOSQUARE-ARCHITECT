# 트러블슈팅

> [!IMPORTANT]
> 문서 상태: 운영

구현 중 해결한 문제를 원인·대안·검증 중심으로 기록합니다.

## 작성 형식

```markdown
## 문제 제목

### 상황
### 재현 방법
### 원인
### 검토한 대안
### 해결
### 검증
### 배운 점
```

현재 프로젝트는 프리프로덕션 단계이므로 등록된 구현 트러블슈팅이 없습니다.

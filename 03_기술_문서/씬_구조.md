# 씬 구조

> [!IMPORTANT]
> 문서 상태: 시작 흐름 프로토타입 구현 완료. 아래 실제 구현과 초기 후보를 구분합니다.

## 현재 구현된 시작 흐름

인트로 → 로비 → 게이트 진입 오프닝 → 동굴 튜토리얼 → 초가집 앞 언월도 보스 구역으로 연결합니다. 각 이동은 공통 비동기 로딩 화면을 통과합니다. 로비는 캐릭터 편성 공간이 아니라 게임 시작·옵션·종료 메뉴입니다.

| 씬 | 역할 |
| --- | --- |
| FrontEnd_Intro | 약 24초의 원화 기반 스토리 영상. 처음 실행할 때 자동 재생 |
| FrontEnd_Lobby | 클릭해서 시작 안내, 게임 시작·옵션·종료·인트로 다시 보기 |
| FrontEnd_Opening | 평범한 시민의 귀갓길, 공간의 이상, 게이트 흡인, 동굴에서의 각성을 네 장면으로 표시 |
| Tutorial_Stage01_Awakening | 대원 기록과 장비 획득·수동 장착, 빗자루 전투와 청사진, 코어 획득 |
| Tutorial_Stage02_Woldo | 초가집 앞 언월도 보스 구역 |

실제 시작 씬 경로는 게임 저장소의 `Assets/_ERGOSQUARE/01.Scenes/FrontEnd/`입니다. Build Settings의 첫 씬은 `FrontEnd_Intro`이며 기존 튜토리얼 씬도 유지합니다.

## 인트로 영상과 시청 기록

현실의 거리와 균열, 갈라진 세계, 낯선 동굴의 원화 세 장을 각각 8초씩 보여주는 MP4를 재생합니다. 완전한 캐릭터 애니메이션 영상이나 음성·효과음이 포함된 최종 시네마틱은 아닙니다. 한글 자막은 영상에 굽지 않고 Canvas로 분리해 해상도에 맞춰 표시합니다.

영상 종료 또는 명시적인 ‘건너뛰기’에서만 `Ergosquare.IntroWatched.v1`을 PlayerPrefs에 저장합니다. 씬 진입이나 영상 준비만으로 시청 완료 처리하지 않습니다. 이후 실행에서는 짧은 타이틀을 거쳐 로비로 넘어갑니다. 로비의 ‘인트로 다시 보기’는 시청 기록과 튜토리얼 보유 상태를 초기화하지 않습니다. 이 기록은 동일한 로컬 사용자·제품 설정 기준이며 클라우드 동기화는 구현하지 않았습니다.

영상 경로는 `Assets/StreamingAssets/FrontEnd/Ergosquare_Intro_v1.mp4`입니다. 재생 오류 또는 준비 시간 초과 시 동일한 원화와 자막을 사용하는 대체 연출로 진행합니다. 문구는 `Assets/_ERGOSQUARE/Resources/FrontEnd/FrontEnd_Story_v1.asset`에서 수정할 수 있습니다. 영상 길이를 바꾸면 자막 구간도 함께 맞춰야 합니다.

## 오프닝과 메뉴 구현 범위

오프닝은 평상복 시민이 아르바이트를 마치고 귀가하다 게이트에 휩쓸리는 현재 종합 기획서의 설정을 따릅니다. ‘다음’ 또는 엔터·스페이스로 진행하거나 건너뛸 수 있습니다. 무기·빗자루·코어를 미리 지급하지 않으며 기존 튜토리얼 획득 흐름을 유지합니다. 새 게임은 남아 있는 포탈 이동용 임시 전달 데이터만 폐기하며 인트로 시청 기록은 유지합니다.

메뉴와 자막은 해상도 대응 Canvas로 제작합니다. 옵션은 전체 음량과 전체 화면 설정을 저장합니다. 전체 화면 전환은 빌드 실행에서 적용하고 에디터 창은 변경하지 않습니다. 종료는 확인·취소를 거치며 이어하기·세이브 슬롯·캐릭터 편성은 아직 구현하지 않았습니다.

# 저장 및 로드

> [!IMPORTANT]
> 문서 상태: 아이디어

## 저장 후보

- 내부 월드 ID, 표시용 지구 번호와 월드 시드
- 지형 변경, 건축물과 소유 정보
- 게이트 발생·폐쇄와 퀘스트 상태
- 차원 좌표, 현실 안정도와 엔딩 진행도
- 청사진 편성
- 해금한 프레임과 모듈
- 옵션
- 진행도와 최근 결과

## 월드와 플레이어 데이터

| 데이터 | 기본 권위 | 설명 |
| --- | --- | --- |
| 월드 상태 | 호스트 세이브 | 지형, 기지, 게이트, 퀘스트와 세계 진행 |
| 월드 내 캐릭터 | 해당 월드 기록 | 위치, 성장, 장비와 개인 청사진 |
| 계정 설정 | 로컬 사용자 | 옵션, 접근성, 외형 후보 |
| 접속 정보 | 세션 | 초대 코드와 임시 연결 정보 |

지구 번호는 공개 가능한 식별자이며 비밀번호나 네트워크 주소로 사용하지 않습니다. 다른 지구에서 캐릭터와 장비를 반입할지는 복제·밸런스와 모드 호환성을 검증한 뒤 결정합니다.

## 원칙

- 스키마 버전을 저장합니다.
- 임시 파일 저장 후 교체해 손상을 줄입니다.
- 저장 실패 시 이전 정상 데이터를 보존합니다.
- 멀티플레이 세션 상태와 영구 저장 데이터를 분리합니다.
- 싱글과 호스트 협동이 같은 월드 저장 형식을 사용하도록 합니다.
- 친구가 접속하지 않아도 호스트가 혼자 월드를 계속 진행할 수 있어야 합니다.
- 내부 월드 ID와 표시 번호를 분리해 번호 중복이 저장 충돌로 이어지지 않게 합니다.

클라우드 저장과 계정 연동은 MVP 제외 범위입니다.

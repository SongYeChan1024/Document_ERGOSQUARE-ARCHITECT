## 상태 사용 원칙

- 코드에서 동작하지 않는 항목은 `구현`으로 올리지 않습니다.
- 기술 후보는 작은 테스트 씬에서 검증한 뒤 확정합니다.
- 기획 변경이 필요한 문제는 기술 문서에서 임의로 덮지 않고 기준 기획서에 되돌려 기록합니다.

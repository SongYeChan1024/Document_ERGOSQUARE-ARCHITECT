# 에르고스퀘어 대표 시스템 명세

> 작성자: 송예찬 · 2026-10-18 v5. 방향은 사용자 합의 반영, 수치·보상·소환 예시는 프로토타입 가안입니다.
> 기준: [종합 기획서 4.4~4.8](../../00_프로젝트_개요/에르고스퀘어_종합_기획서_초안.md#44-에르고스퀘어와-청사진) · [조합·성장 상세](../../01_게임_기획/시스템_상세_부록.md#space-economy)

## 1. 목적

레벨업의 한 줄 확장/새 스퀘어 선택과, 역할이 없는 공간의 무기·코어·보조 파츠 조합을 연결합니다. 편집 작업은 새 3열 UI에서 수행하며 기존 편집창의 표시 경로를 사용하지 않습니다.

## 2. 사용자 흐름

처음 3×3 지급 → 빗자루와 함께 받은 1×1 코어를 같은 공간에 배치 → Q 배정 → 직접 빗자루 스킬 사용 → 레벨업 → 기존 어느 공간의 한 행/열 추가 또는 새 1×1 생성 → 무기 이동·코어·보조 파츠 구성 → 강화 또는 소환 변형.

B와 Tab은 새 장비/에르고 스퀘어 공유 화면으로 진입합니다. 시설 편집도 같은 화면을 엽니다. 창에서 편집 완료·닫기 또는 현재 구성 필드 배치를 선택합니다. 후자는 편집 입력 차단을 해제하고 월드 미리보기로 이동하며 기존 편집창을 열지 않습니다.

## 3. 동작 규칙

- 최초 격자는 3×3, 이후 생성만 1×1. 중앙 예약 없음.
- 레벨마다 성장 선택 1회. 한 행/열에 들어 있는 칸 수와 관계없이 확장 소비는 1회. 생성도 1회.
- 미사용 선택은 보관합니다. 튜토리얼 무료 확장 선택은 없습니다. GrowthPoints와 스냅샷 Points는 이전 호출 호환 이름이며 현재 의미는 성장 선택 횟수입니다.
- TryResize는 제작/명시적 시험 설정 API이고 UI는 TryExpandSelected로 선택을 소비합니다.
- 같은 공간에 복수 코어·무기를 배치할 수 있습니다. 한 공간 한 코어/한 키 제약과 코어 역할 강제 분리는 제거했습니다.
- 실제 무기 하나는 한 공간과 한 키에 연결합니다. 다른 공간으로 이동할 때 키의 공간 ID를 갱신하고 개체·유대·내구·기억한 냉각을 유지합니다.
- 같은 공간의 정상·호환 코어/보조 파츠를 합산해 스킬 피해·범위·형태를 도출합니다. 다른 공간의 효과는 받지 않습니다.
- 직접 타격의 조합 배율은 사용 승인 시 실행 정보에 기록합니다. 소환의 보정은 유지 중 현재 편성을 다시 읽어 파츠 하나의 효과를 여러 소환에 복제하지 않습니다.
- 모든 배치 코어가 자기 생성량과 내구도 비율에 따라 공용 자원을 회복합니다. 로컬 출력원은 해당 공간의 첫 정상 코어입니다. 하나가 파괴되면 남은 정상 코어를 사용할 수 있습니다.
- 최초 발동만 공용 자원 지불. 후속 연계·유지는 로컬 출력, 부족분은 열과 추가 냉각으로 처리합니다.

## 5. 상태와 실행

ErgoSkillComposition은 스퀘어 안의 무기를 기준으로 생성됩니다. 코어·보조 파츠의 CompatibleWeaponId가 비어 있거나 무기 ID와 같고, 해당 파츠가 정상일 때 수치 보정과 형태를 적용합니다. 파손·제거·다른 공간 이동은 효과를 해제합니다. Direct와 Summon은 스퀘어 직군이 아니라 조합 결과입니다.

코어마다 Charge·Heat·ReadyAt을, 무기 개체에는 기억한 냉각 종료 시간을 유지합니다. 키 변경·회수·이동·씬 인계는 이 상태를 초기화하지 않습니다. 현재 계수와 상세 수식은 부록의 가안을 따릅니다.

PrototypeSkillUseController는 직접 공격의 기존 3단 연계를 유지하고 조합 배율을 실제 피해/범위에 적용합니다. 소환 조합이면 같은 키로 짧은 시전을 실행해 PrototypeBroomCompanion을 생성합니다. 원본 무기당 소환 하나이며 NavMesh 경로로 이동하고 유효한 적을 찾아 실제 피해를 줍니다. 벽 관통 공격을 막습니다.

소환 유지 부하는 원본 공간 코어에서 처리합니다. 수명 만료·원본 파손·정상 코어 없음·소환 조합 해제·원본 공간 변경·플레이어 패배·씬 종료 시 소환이 끝나고 부하를 해제합니다. 편집 입력 차단 중에는 적과 마찬가지로 공격·이동을 멈춥니다. 수명·열·냉각의 게임 시간은 계속 흐릅니다. 소환 전용 내구/어그로·원화·모션과 고급 AI는 후속입니다.

## 7. 예외 처리

성장 선택 부족·기술 상한·겹침·경계 초과·잘리는 축소는 거절하며 선택과 기존 배치를 유지합니다. 실패한 무기 이동은 원래 공간과 키를 유지합니다. 냉각 코어를 분리 후 다른 공간에 넣어 재사용을 초기화할 수 없습니다. 무기 이동에도 기억한 대기가 남습니다.

레이아웃을 바꾸면 기존 필드 실물을 회수합니다. 월드 전개는 전체 점유 칸의 바닥·장애물을 검사한 뒤 한 번에 수행하고 실패 시 부분 설치하지 않습니다. 회수와 씬 이동으로 수리하지 않습니다. 지원 파츠도 소유·내구 상태를 보존합니다.

## 8. 새 UI 단일 진입과 피드백

새 화면은 EditorOverlay의 자식이 아닌 별도 ErgoWorkbenchCanvas_v5입니다. 옛 EditorOverlay·DeploymentHUD·EquipmentTabs 편집 화면은 숨깁니다. 기존 카드/버튼을 다시 만드는 Refresh 경로도 새 화면 준비 후 중단합니다. B·Tab·시설 편집, 레벨업 성장 화면과 월드 배치 진입을 모두 이 화면에 연결합니다. 기존 HUD보다 위에 표시해 겹침을 방지합니다.

왼쪽 가방 / 가운데 장비·스퀘어 탭 / 오른쪽 파츠 설명을 유지합니다. 스퀘어 선택·성장 선택 잔량·확장 후 크기·생성·드래그/회전·무기 이동·합성/강화·파츠 해제·키 배정·실제 조합 결과·열/출력/냉각을 표시합니다. 이전/다음으로 대상 공간을 바꾸고 선택한 파츠를 배치하면 이동합니다. 줌·패닝은 용량과 무관합니다.

레벨업이 발생하면 현재 공격·다른 모달이 끝나고 입력이 가능할 때 새 UI의 성장 탭을 열어 선택을 안내합니다. 즉시 쓰지 않고 닫아 보관할 수 있습니다.

## 9. 검증과 완료 판정

저장된 튜토리얼 씬을 별도 복제 Unity 프로젝트에서 실행해 실제 새 UI 버튼·직접 피해·소환 AI·월드 전개·메모리 인계를 검증합니다. 본부 씬으로 실제 이동한 뒤 보유/성장/키 보존과 시설의 새 UI 진입도 확인합니다. 준비한 파츠·XP·시험용 적/넓은 바닥을 쓰는 자동 검증이며 전체 튜토리얼 수동 완주·모든 동굴 위치를 보증하지 않습니다.

증빙은 Unity 저장소 Tools/ArtReview/Ergo_Composition_v5_20261018의 checks.txt·verification.json·code-verification.json·Renders와 [QA 기록](../../05_QA/2026-10-18_성장선택_파츠조합_새UI_검증.md)에 기록합니다. 본 작업용 열린 Unity 창은 조작하지 않습니다.

## 10. 남은 문제

정식 보상·성장 곡선·열/소환 밸런스, 보조 파츠 전용 아트, 소환 전용 모션·내구/어그로, 다른 무기/문화권의 변형 실행기, 가방용 공간과 실제 수납 용량 연결, 개별 공간 월드 위치·전체 회전, 영구 저장·협동 동기화, 전체 튜토리얼 수동 UX 검수는 후속입니다.

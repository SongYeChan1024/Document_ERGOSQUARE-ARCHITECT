# 기술 스택

> [!IMPORTANT]
> 문서 상태: 후보. 기술 검증 후 확정합니다.

| 분야 | 후보 | 용도 |
| --- | --- | --- |
| 게임 엔진 | Unity / URP | 클라이언트와 렌더링 |
| 언어 | C# | 게임 로직 |
| 멀티플레이 | Photon PUN2 | 룸과 상태 동기화 |
| UI | Unity UI / TextMeshPro | 화면과 HUD |
| 정적 데이터 | ScriptableObject | 모듈·적·밸런스 |
| 저장 데이터 | JSON | 로컬 진행 정보 |
| 버전 관리 | Git / GitHub | 코드·문서 이력 |
| 최적화 후보 | Object Pooling / LOD / Occlusion Culling | 반복 생성과 렌더링 비용 관리 |

선택 근거, 버전과 교체 조건은 P0 기술 검증 결과로 보완합니다.

생성형 AI 기반 교관은 확장 후보입니다. 핵심 진행 조건으로 사용하지 않으며, 도입하더라도 규칙 기반 기본 응답을 먼저 제공합니다.

# 이미지

UI 캡처, 콘셉트 이미지와 포트폴리오 정지 이미지를 저장합니다.

## UI·UX 기준 시안

| 이미지 | 용도 | 상태 |
| --- | --- | --- |
| [튜토리얼 동굴 인게임 HUD 기준 시안 v1](./UI_UX/튜토리얼_동굴_인게임_HUD_기준시안_v1.png) | 평상복 플레이어, 동굴·초가집·월도 보스와 인게임 HUD 정보 계층 | 기준 시안 |
| [청사진 편집 기준 시안 v1](./UI_UX/청사진_편집_기준시안_v1.png) | 보유 파츠, 근접 3×3 격자, 파츠 상세와 QWERASDF 스킬 할당 흐름 | 기준 시안 |

기준 시안의 프레임과 아이콘은 Unity용 개별 투명 이미지로 다시 제작합니다. 한글·키·수치·게이지는 이미지에 포함하지 않고 런타임 UI로 조립합니다.

## 시스템 범위 매트릭스

| 전투 | 스킬 2~3개, 도깨비 공용 소형 리그와 월도 보스 | 추가 보스, 상태 이상, 복합 적 조합 |
| 편성 | 고정 프레임에 코어·수납·방벽 배치 | 다수 프레임과 프리셋 |
| 전개 | `Tab` 진입, 격자 투영, 배치 검증, 현실화 | 부분 회수·재전개, 팀 중첩 |
| 모듈 | 코어, 수납 모듈, 방벽 | 공격·지원·생산 모듈 |

| 게이트 | 도깨비 잠복 게이트, 투영형·영혼 주입형 구분, 폐쇄와 복귀 | 다른 신화 규칙, 분기, 앵커 |
| 상호작용 | 조사, 구조, 장치 수리 | NPC 대화, 조건부 퀘스트 |
| 세이브 | 튜토리얼 시작·플롯 체크포인트·종료 | 월드 상태와 호스트 세이브 |

## 튜토리얼 런타임 구성

| 구성 요소 | 튜토리얼 책임 | 필수 상태·출력 |
| --- | --- | --- |
| 플롯·이벤트 관리자 | TUT-00~08 시작·완료·재시도와 중복 실행 방지 | 현재 플롯, 완료 플래그, 체크포인트 |
| 기억 재생기 | 짧은 회상 조각의 재생·건너뛰기·재시도 생략 | 재생 여부, 입력 잠금, 종료 신호 |
| 목표·프롬프트 관리자 | 현재 목표와 상황별 키 안내 표시 | 목표 ID, 입력 바인딩, 노출 우선순위 |
| 상호작용 관리자 | 조사·획득·수리·영혼 안정화·게이트 폐쇄 처리 | 대상 우선순위, 진행도, 중단 사유 |
| 청사진 편성·전개 | 고정 청사진 편집, 배치 검증과 현실화 | 셀, 회전, 유효성, 모듈 인스턴스 |
| 모듈 런타임 | 충돌·내구도·코어 자원·수납 상태 처리 | 정상·손상·파괴·수리 상태 |
| 드롭·획득 관리자 | 일반 드롭, 자동 획득, 보호 슬롯과 월드 잔류 처리 | 출처, 소유 분류, 수납 결과 |
| 기록 보관함 | 토벌팀 기록과 도깨비 조사 기록의 해금·재열람 | 기록 ID, 획득 순서, 열람 상태 |
| 적·위협 관리자 | 플레이어·코어·수납 모듈 표적 평가 | 현재 표적, 위협도, 전환 예고 |
| 보스 단계 관리자 | 월도 단계·패턴·체력 게이트와 실패 복구 | 단계, 사용 패턴, 결박핵 상태 |
| 영혼 안정화 | 영혼 주입형 적 패배 후 구조 상호작용 | 안정화 대상, 진행도, 구조 결과 |
| 게이트 종료 관리자 | 월도 결박 해체, 폐쇄, 결과 요약과 복귀 | 폐쇄 진행도, 보상, 인계 데이터 |

정확한 플롯 트리거는 [플롯별 상세 연출 및 구현 명세](./11_플롯별_상세_연출_및_구현_명세.md), 아이템 데이터는 [아이템 및 드롭 테이블](./12_튜토리얼_아이템_및_드롭_테이블.md), 적·보스 행동은 [몬스터 및 보스 명세](./13_튜토리얼_몬스터_및_보스_명세.md)를 기준으로 합니다.

## 수납 모듈 검증 규칙

수납 모듈은 가방 UI와 전리품 획득 능력을 월드 오브젝트로 현실화한다.

| 상태 | 동작 |
| --- | --- |
| 미전개 | 기본 보유 정보만 확인 가능. 세부 규칙은 `TBD` |
| 정상 | `B`로 가방 열기, 신규 전리품 획득 |
| 손상 | 내구도 경고, 기능은 유지 |
| 파괴 | 가방 접근과 신규 일반 전리품 파밍 차단 |
| 수리 | 봉인된 소지품과 파밍 기능 복구 |
| 작전 종료 | 잔해 회수 성공 시 봉인 소지품 복구 |

### 진행 불가 방지

- 장착 중인 장비와 `1~4` 벨트 소비품은 수납 모듈 파괴 후에도 유지한다.
- 퀘스트 핵심 물품과 현실 고정 권한 데이터는 코어에 보관하여 손실되지 않는다.
- 응급 수리 도구는 별도 비상 슬롯에 보존하는 방안을 우선 검증한다.
- 튜토리얼에서는 수납 모듈 파괴를 방지하거나 파괴 즉시 수리 동선을 제공한다.

## 코어 검증 규칙

- 코어는 전투 자원을 지속적으로 생성한다.
- 월드 충돌과 피격 판정을 가져 플레이어의 방패·엄폐물이 될 수 있다.
- 내구도가 소진되면 신규 자원 생성이 중단된다.
- 튜토리얼에서는 축적 자원 유지 또는 응급 복구 수단을 제공해 진행 불가를 막는다.
- 적이 플레이어·코어·수납 모듈 중 목표를 바꾸는 순간을 명확히 표시한다.

## 예외 처리

- 유효하지 않은 지면에서 전개하면 실패 이유를 표시한다.
- 중요 상호작용 중 시전자가 피격되면 진행을 중단하되 다시 시도할 수 있게 한다.
- 게이트 폐쇄 트리거가 실패하면 마지막 안전 상태로 복구한다.
- 가방이 가득 찬 상태에서 일반 자원을 획득하면 월드에 남기고 사유를 알린다.

# 레벨 및 전투 설계

> [!IMPORTANT]
> 문서 상태: 초안

## 레벨 목적

하나의 게이트 내부 맵에서 `앞으로 전진 → 안전 공간 확보 → 에르고스퀘어 전개 → 모듈 방어 → 구조 → 폐쇄`를 경험하게 한다.

## 공간 구성

| 구역 | 역할 | 핵심 오브젝트 |
| --- | --- | --- |
| A. 기상실 | 이동과 시점 적응 | 플레이어, 소지품, 쓰러진 민간인 |
| B. 기억 회랑 | 조사와 회상 | 기억 흔적 3개, 투영된 도시 잔상 |
| C. 첫 접촉지 | 공격·회피 학습 | 기억 투영형 도깨비 소수, 산개 장애물 |
| D. 고정 광장 | 에르고스퀘어 전개 | 평탄한 격자 공간, 전개 기준점 |
| E. 방어 구역 | 수납 모듈 보호와 파밍 | 복수 진입로, 웨이브 스폰 |
| F. 구조 구역 | 폭주 규칙 조사와 구조 | 영혼 주입형 도깨비, 토벌팀 시체·기록, 안정화 지점 |
| G. 폐쇄실 | 학습한 기능 종합 | 월도 보스, 폐쇄 장치, 복귀 좌표 |

## 격자와 이동

- 레벨은 월드 `XZ` 평면의 정사각 격자를 아이소메트릭 다이아몬드로 투영한다.
- 플레이어와 적은 격자에 묶이지 않고 연속적으로 이동한다.
- 코어, 수납 모듈과 방벽만 셀에 스냅한다.
- 최초 청사진 크기는 `6×6` 또는 `8×8` 가안을 비교한다.
- 전개 광장은 편성 결과와 적 진입로가 한 화면에 읽히게 한다.

## 전투 리듬

1. 첫 전투에서 적 한 마리로 기본 공격과 회피를 학습한다.
2. 전개 후 소규모 웨이브로 코어를 엄폐물로 쓸지 직접 보호할지 선택한다.
3. 코어 피격과 자원 생성 위험을 먼저 학습한 뒤 수납 모듈 방어로 확장한다.
4. 수납 모듈 파괴 시 자원 획득이 막히는 것을 보여주고 응급 수리 동선을 연다.
5. 영혼 주입형 개체와 토벌팀 기록을 통해 정상 투영과 폭주의 차이를 전달한다.
6. 최종 전투에서는 월도의 넓은 베기와 코어·수납 모듈 돌진을 피하며 게이트 폐쇄 조건을 완성한다.

## 소형 도깨비 공용 행동

- 평상시 플레이어를 탐지하고 추적한다.
- 인접한 플레이어 또는 핵심 모듈을 공격한다.
- 수납 모듈의 위협도를 일정 수준 부여하여 방어 판단을 유도한다.
- 공격 전조를 바닥 표시와 모션으로 알린다.
- 폐쇄실에서는 수만 늘리고 새 패턴을 추가하지 않는다.

## 리소스 절약 원칙

- 폭주 이전의 도시는 전체 플레이 맵으로 만들지 않고 회상용 부분 세트로 제작한다.
- 게이트 폭주는 지형을 두 벌 만드는 침식형 바이옴 대신 투영 쉘이더·데칼·음향으로 표현한다.
- 현실 복귀 장면은 기존 도시 자산에 NPC 비활성, 통제선과 조명 상태를 더해 유령도시를 표현한다.

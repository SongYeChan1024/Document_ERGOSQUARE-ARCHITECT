# 테스트 체크리스트

> [!IMPORTANT]
> 문서 상태: 초안

## 기능 테스트

### 조작·전투

- [ ] 우클릭을 누르고 유지하면 경로가 갱신되며 이동한다.
- [ ] 좌클릭 기본 공격이 이동, UI와 충돌하지 않는다.
- [ ] `QWERASDF` 슬롯이 올바른 잠금·활성 상태를 표시한다.
- [ ] `Space` 회피의 방향과 무적·충돌 규칙이 일관되다.
- [ ] 피격, 사망과 체크포인트 재시도가 동작한다.

### 상호작용·아이템

- [ ] `G` 대상 우선순위가 재현 가능하다.
- [ ] `G` 길게 누르기가 피격 또는 범위 이탈 시 의도한 규칙대로 취소된다.
- [ ] 자원이 수납 여유 공간 안에서 자동 획득된다.
- [ ] 가방이 가득 차면 자원이 월드에 남고 사유를 표시한다.
- [ ] 즉시 사용 아이템과 위치 지정 아이템이 구분된다.
- [ ] 위치 지정 중 취소가 우클릭 이동 오입력을 만들지 않는다.

### 에르고스퀘어·모듈

- [ ] `Tab`으로 전개 모드에 진입하고 나올 수 있다.
- [ ] 유효·무효 격자를 색상 이외의 형태로도 구분할 수 있다.
- [ ] 코어, 수납 모듈과 방벽이 저장된 격자 좌표에 전개된다.
- [ ] 모듈이 각자의 내구도와 파괴 상태를 가진다.
- [ ] 코어가 플레이어와 투사체를 막는 엄폐물로 작동한다.
- [ ] 코어 파괴 시 신규 자원 생성이 중단되고 진행 불가 방지 규칙이 작동한다.
- [ ] 수납 모듈 파괴 시 `B` 가방과 신규 일반 파밍이 차단된다.
- [ ] 수납 모듈을 수리하면 봉인된 아이템과 파밍 기능이 복구된다.
- [ ] 장착 장비, 벨트 아이템과 퀘스트 필수품이 수납 파괴로 소실되지 않는다.

### 플롯·저장

- [ ] TUT-00~08이 정해진 성공 조건에 따라 전환된다.
- [ ] 플롯을 건너뛰거나 두 번 시작하지 않는다.
- [ ] 필수 오브젝트가 사라져도 플롯을 재시도할 수 있다.
- [ ] 저장 후 재시작해도 플롯·아이템·모듈 상태가 일관되다.
- [ ] 튜토리얼 완료 상태가 메인 월드 훅으로 정상 인계된다.

## 전달 테스트

테스터에게 설명하지 않고 플레이한 후 다음을 묻는다.

1. 플레이어는 어디에 왔고 왜 탈출해야 했는가?
2. 설계자와 에르고스퀘어는 무엇이었는가?
3. 코어와 수납 모듈을 왜 지켜야 했는가?
4. 수납 모듈이 파괴되면 무엇을 할 수 없었는가?
5. 다음에 해야 할 일은 무엇이라고 느꼈는가?
6. 외부로 나온 도깨비와 내부의 영혼 주입형 도깨비는 무엇이 달랐는가?
7. 선행 토벌팀은 왜 실패했고 기관은 왜 게이트를 미리 발견하지 못했는가?

### 합격 기준 가안

- 핵심 목표와 파괴 위험에 대한 답을 테스터 자신의 말로 설명할 수 있다.
- 자막 문구를 그대로 외우는 것은 합격의 필수 조건이 아니다.
- 틀린 답은 UI, 레벨 동선, 연출 중 어디에서 정보가 실패했는지와 연결해 기록한다.

## 사용성 기록

| 항목 | 기록 방법 |
| --- | --- |
| 완주 시간 | 시작부터 TUT-08 종료까지 |
| 사망·재시도 | 플롯별 횟수가 원인 |
| 조작 오입력 | 입력, 의도, 실제 결과 |
| 헤맨 구간 | 5초 이상 정지한 위치와 질문 |
| UI 미인지 | 놓친 경고·목표·상태 |
| 배치 수정 | 첫 배치와 재배치 이유 |
| 수납 파괴 반응 | 수리, 무시, 이탈 중 선택 |
| 정서 반응 | 각성, 전개, 구조, 복귀 장면의 자유 피드백 |

## 회귀 테스트

- [ ] 조작 매핑 변경 후 모든 튜토리얼 프롬프트가 현재 바인딩을 표시한다.
- [ ] 모듈 크기 변경 후 청사진 저장·전개·회전이 정상이다.
- [ ] 수납 용량 변경 후 획득·가득 찬 상태·봉인·복구가 정상이다.
- [ ] 플롯 순서 변경 후 이전 세이브의 재시작 정책이 의도대로 동작한다.
- [ ] 게이트 폐쇄 후 적·이펙트·상호작용이 남아 진행을 방해하지 않는다.

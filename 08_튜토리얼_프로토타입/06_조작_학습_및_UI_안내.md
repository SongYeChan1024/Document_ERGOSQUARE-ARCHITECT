# 조작 학습 및 UI 안내

> [!IMPORTANT]
> 문서 상태: 초안. 전체 게임의 입력 매핑과 상태는 [조작 시스템](../01_게임_기획/조작_시스템.md)을 기준으로 합니다. 이 문서는 튜토리얼이 그 조작을 어떤 순서와 상황으로 가르칠지만 다룹니다.

## 학습 목표

플레이어가 튜토리얼 종료 시 다음을 자막 없이 반복할 수 있게 합니다.

- 우클릭으로 이동하고 좌클릭으로 기본 공격합니다.
- `QWERASDF` 스킬 슬롯과 `Space` 회피를 사용합니다.
- `G`로 조사·구조·장치 작동을 수행합니다.
- `1~4`로 소비 아이템을 사용합니다.
- `B`로 가방을 확인하고 `Tab`으로 에르고스퀘어를 전개합니다.

## 플롯별 학습 순서

| 플롯 | 상황 | 학습할 조작 | 성공 확인 |
| --- | --- | --- | --- |
| TUT-00 기상 | 돌아다닐 수 있는 안전한 공간 | 우클릭 이동 | 첫 흔적 도달 |
| TUT-01 기억 | 조사할 흔적 노출 | `G` 짧게 누르기 | 흔적 활성화 |
| TUT-02 첫 위협 | 적의 단순한 공격 | 좌클릭 기본 공격, `Space` 회피 | 적 처치 |
| TUT-03 각성 | 시스템 진단 후 격자 투영 | `Tab` 전개 모드 | 전개 화면 진입 |
| TUT-04 첫 전개 | 안전한 광장에 고정 청사진 제공 | 마우스 선택, 좌클릭 확정, 우클릭 취소, `Q/E` 회전 | 코어·수납·방벽 전개 |
| TUT-05 방어 | 소규모 웨이브와 자원 드롭 | 활성 스킬 2~3개, `B` 가방 | 웨이브 처치·자원 확인 |
| TUT-06 조사 | 토벌팀 시체·기록과 안정화 대상 | `G` 짧게·길게 누르기 | 월도 기록·폐쇄 인증 확보 |
| TUT-07 월도 | 보스와 파괴 위험에 놓인 코어 | `1~4` 소비 아이템, 학습한 전투 조작 종합 | 월도 처치 |
| TUT-08 폐쇄 | 해방된 영혼과 폐쇄 장치 | `G` 상호작용, 결과 확인 | 게이트 폐쇄·복귀 |

## 스킬 슬롯 표시

- `QWERASDF` 8칸을 처음부터 같은 위치에 표시합니다.
- 튜토리얼 빌드에서는 2~3개만 활성화하고 나머지는 잠금 상태로 둡니다.
- 잠긴 슬롯은 사용 불가 사유를 표시하되 튜토리얼 종료 즉시 모두 열린다고 암시하지 않습니다.
- 스킬이 처음 활성화되면 슬롯과 캐릭터 효과를 짧게 연결해 위치를 인지시킵니다.

## 프롬프트 규칙

- 조작을 필요로 하는 상황이 나타난 뒤 키를 노출합니다.
- 프롬프트는 `[키] + 행동 동사`를 기본으로 합니다. 예: `[G] 기억 흔적 조사`.
- 입력이 성공하면 안내를 즉시 제거하고 월드의 결과를 강조합니다.
- 동일 조작을 반복해 문장으로 설명하지 않습니다.
- 키 표시는 현재 입력 바인딩을 참조합니다.
- 조작하지 않고 일정 시간 멈춘 경우 첫 알림보다 구체적인 재안내를 표시합니다.

## 보여주기 전 설명하지 않기

| 규칙 | 월드에서 먼저 보여줄 것 | 이후 안내 |
| --- | --- | --- |
| 회피 | 적의 느리고 명확한 공격 전조 | `[Space] 회피` |
| 상호작용 | 빛나는 흔적과 캐릭터의 시선 | `[G] 조사` |
| 전개 | 고정할 수 없는 왜곡 지면과 시스템 진단 | `[Tab] 에르고스퀘어 전개` |
| 가방 | 수납 모듈으로 흡수되는 첫 자원 | `[B] 획득품 확인` |
| 수리 | 수납 모듈 파괴와 파밍 실패 표시 | `[G] 응급 수리` |

## 수납 모듈 학습

1. 정상 상태에서 자원을 자동 획득하고 `B`로 확인합니다.
2. 적이 수납 모듈을 타격하면 월드, HUD와 사운드로 위험을 알립니다.
3. 파괴 후 자원 획득을 시도하면 봉인 상태와 파밍 차단 이유를 표시합니다.
4. `G` 응급 수리 후 가방과 파밍이 복구되는 것을 직접 확인하게 합니다.

파괴 학습을 필수 이벤트로 만들지, 손상 경고와 수리만 가르칠지는 플레이테스트 전 확정합니다.

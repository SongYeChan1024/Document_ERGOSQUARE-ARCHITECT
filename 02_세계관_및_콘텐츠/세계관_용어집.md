## 현실과 역사

<a id="번호-지구"></a>

### 번호 지구

대분기로 갈라진 독립 현실을 관리자 시스템과 세이브가 구분하기 위해 부여한 번호입니다. 주민에게 자신의 세계는 번호가 붙은 복제품이 아니라 단 하나의 지구입니다.

- 공개 시점: 번호는 메타 UI와 후반 관리자 기록에서 확인
- 상세 문서: [세계관 설정](세계관_설정.md), [정본 지구의 역사](정본_지구의_역사.md)
- 관련어: [대분기](#대분기), [정본 지구](#정본-지구), [정본화](#정본화)

<a id="지구-자아"></a>

### 지구 자아

행성의 생명, 기억과 집단 무의식이 결집한 보존 의지입니다. 최초 침공 당시 깨어나 대분기를 일으켰으며 각성자와 현현체 탄생에 영향을 주었습니다.

- 공개 시점: 중후반
- 미확정: 단일 인격인지 거대한 방어 현상인지
- 상세 문서: [세계관 설정](세계관_설정.md), [이면·현현체 심층 설정](이면_및_현현체_심층_설정.md)

<a id="대분기"></a>

### 대분기

최초 게이트 침공에서 인류를 보존하기 위해 지구 자아가 가능한 현실을 실제 독립 세계로 분리한 사건입니다. 미래 예측이나 가상 시뮬레이션이 아닙니다.

- 공개 시점: 본편 중후반
- 상세 문서: [정본 지구의 역사](정본_지구의_역사.md)

<a id="정본-지구"></a>

### 정본 지구

대분기에서 갈라진 세계 중 자신만이 올바른 성공 분기라고 주장하는 지구입니다. `원본 지구`는 인게임 세력의 자기 주장이나 과거 표현으로 사용할 수 있지만, 기준 명칭은 `정본 지구`입니다.

- 공개 시점: 후반
- 주의: 실제 원본임이 확정된 것이 아님
- 상세 문서: [정본 지구의 역사](정본_지구의_역사.md)

<a id="정본화"></a>

### 정본화

정본 지구가 다른 번호 지구를 독립 현실로 인정하지 않고 자신의 현실에 강제 병합하는 과정입니다.

- 공개 시점: 앵커 게이트 발견 이후
- 미확정: 병합된 주민과 기록의 정확한 결과
- 상세 문서: [시나리오 개요](../00_프로젝트_개요/에르고스퀘어_종합_기획서_초안.md#world-story), [정본 지구의 역사](정본_지구의_역사.md)

## 게이트와 이면

<a id="이면"></a>

### 이면

현실 바깥에 존재하며 인간의 개념으로 완전히 이해할 수 없는 심연입니다. 인간이 이면을 관측하자 이면 또한 인간을 관측하고, 인간에게 인식될 수 있는 이야기와 형상을 모방하기 시작했습니다.

- 공개 시점: 본편에서는 단서만, 핵심 설명은 결말 이후 후보
- 금지 해석: 이데아, 단순한 악마 세계, 인간과 동일한 사고를 가진 단일 인격으로 확정
- 상세 문서: [이면·현현체 심층 설정](이면_및_현현체_심층_설정.md)

<a id="게이트"></a>

### 게이트

지역과 지성체에게 축적된 기억, 설화, 공포와 믿음을 읽어 이야기와 공간을 현실에 투영하는 현상입니다. 각 게이트는 섬멸 외에도 조사, 구조, 계약, 의식과 사건 해결 같은 고유 폐쇄 조건을 가집니다.

- 공개 시점: 튜토리얼부터
- 상세 문서: [세계관 설정](세계관_설정.md), [게이트 신화 콘텐츠 조율서](게이트_신화_콘텐츠_조율서.md)

<a id="잠복-게이트"></a>

### 잠복 게이트

기존 전조 관측에 잡히지 않은 채 성장하다 갑자기 전조와 폭주를 일으키는 게이트입니다. 튜토리얼 사건이 최초로 확인된 사례입니다.

- 공개 시점: 튜토리얼 종료
- 상세 문서: [튜토리얼 시나리오](../00_프로젝트_개요/에르고스퀘어_종합_기획서_초안.md#tutorial)

<a id="폭주-게이트"></a>

### 폭주 게이트

현실과 이야기의 경계가 무너져 전승의 상징을 실제 인간의 육체나 영혼으로 대체하는 게이트 상태입니다.

- 공개 시점: 튜토리얼 조사 과정
- 상세 문서: [도깨비 게이트 콘텐츠 기획](../01_게임_기획/04_튜토리얼/콘텐츠/도깨비_게이트_콘텐츠_기획.md)

<a id="앵커-게이트"></a>

### 앵커 게이트

번호 지구의 현실 좌표와 정본화 과정에 직접 연결된 핵심 거점입니다. 파괴하면 지역 현실이 함께 무너질 수 있어 설계자 권한으로 지구에 귀속시키는 방향을 사용합니다.

- 공개 시점: 본편 중반
- 미확정: 최종 개수, 기능과 문화권별 이야기
- 상세 문서: [시나리오 개요](../00_프로젝트_개요/에르고스퀘어_종합_기획서_초안.md#world-story)

<a id="최후의-게이트"></a>

### 최후의 게이트

귀속한 앵커를 이용해 정본화 관리자 시스템으로 진입하는 최종 연결로입니다.

- 공개 시점: 최종장
- 상세 문서: [시나리오 개요](../00_프로젝트_개요/에르고스퀘어_종합_기획서_초안.md#world-story)

## 존재 분류

<a id="각성자"></a>

### 각성자

지구 자아의 각성 이후 초자연적 능력이 발현한 인간의 총칭입니다. 문화와 힘의 계통에 따라 무당, 주술사, 성직자, 무공 사용자 등 서로 다른 방식으로 존재할 수 있습니다.

- 공개 시점: 게임 시작 전부터 사회에 알려진 개념
- 상세 문서: [캐릭터 설정](캐릭터_설정.md)

<a id="설계자"></a>

### 설계자

에르고스퀘어를 운용해 파츠를 청사진으로 구성하고 현실에 전개하는 희귀 각성자의 작전 코드네임이자 플레이어 호칭입니다.

- 공개 시점: 튜토리얼 종료
- 원칙: 모든 설계자는 각성자지만 모든 각성자가 설계자는 아님
- 상세 문서: [설계자 빌드 시스템](../01_게임_기획/시스템_상세_부록.md#deployment)

<a id="현현체"></a>

### 현현체

지구 각성 이후 인간의 전승과 믿음에서 독립된 자아와 실체를 얻어 현실에 태어난 존재입니다. 게이트가 닫혀도 사라지지 않으며 플레이어와 관계, 계약과 갈등을 형성합니다.

- 공개 시점: 본편 초반
- 예시 후보: 자연 발생 도깨비, 신령, 영물, 신화적 존재
- 상세 문서: [이면·현현체 심층 설정](이면_및_현현체_심층_설정.md)

<a id="게이트-투영체"></a>

### 게이트 투영체

게이트가 지역의 기억과 전승을 재료로 일시적으로 구현한 존재입니다. 현실에서 독립된 자아를 가진 현현체와 구분합니다.

- 공개 시점: 튜토리얼 전투·조사
- 상세 문서: [도깨비 게이트 콘텐츠 기획](../01_게임_기획/04_튜토리얼/콘텐츠/도깨비_게이트_콘텐츠_기획.md)

<a id="폭주-유출-개체"></a>

### 폭주 유출 개체

폭주 게이트의 뒤틀린 규칙으로 만들어져 현실 밖으로 유출된 개체입니다. 오랜 시간 사람의 정이 깃들어 태어난 자연 발생 도깨비와 구분합니다.

- 공개 시점: 튜토리얼 회상과 기관 보고
- 상세 문서: [튜토리얼 시나리오](../00_프로젝트_개요/에르고스퀘어_종합_기획서_초안.md#tutorial)

<a id="영혼-주입형"></a>

### 영혼 주입형

폭주 게이트가 실제 인간의 영혼을 물건이나 투영체에 강제로 결박해 만든 개체 분류입니다.

- 공개 시점: 튜토리얼 중반 조사
- 상세 문서: [몬스터 및 보스 명세](../01_게임_기획/04_튜토리얼/콘텐츠/몬스터_및_보스_명세.md)

<a id="월도"></a>

### 월도

튜토리얼의 보스입니다. 게이트가 `많은 생명을 죽인 무기`를 `많은 생명을 담는 그릇`으로 오독하고 시민의 영혼을 월도에 주입해 만든 거대한 병사형 도깨비입니다.

- 공개 시점: 튜토리얼 후반
- 주의: 월도의 특정 전쟁 실사용을 역사적 사실로 단정하지 않음
- 상세 문서: [몬스터 및 보스 명세](../01_게임_기획/04_튜토리얼/콘텐츠/몬스터_및_보스_명세.md)

## 설계자 시스템

<a id="에르고스퀘어"></a>

### 에르고스퀘어

설계자가 개인 좌표계에 구성한 청사진을 현실 공간의 구조물로 전개하는 능력과 시스템입니다.

- 공개 시점: 튜토리얼 각성 장면
- 상세 문서: [에르고스퀘어 인덱스](../01_게임_기획/02_에르고스퀘어/README.md)

<a id="청사진"></a>

### 청사진

코어, 장비, 보조 파츠와 직접 수납 재료를 배치하는 격자입니다. 전개 전 편성 정보이자 전개 후 월드 구조의 원본입니다.

- 공개 시점: 튜토리얼
- 상세 문서: [청사진 성장 및 공간 경제](../01_게임_기획/시스템_상세_부록.md#space-economy)

<a id="파츠"></a>

### 파츠

청사진에 배치되어 전투, 자원, 보호와 수납 기능을 수행하는 아이템입니다. 장비형, 코어형, 보조형과 소비형으로 분류합니다.

- 공개 시점: 튜토리얼
- 상세 문서: [아이템·파츠 시스템](../01_게임_기획/시스템_상세_부록.md#items)

<a id="아키텍처"></a>

### 아키텍처

하나의 청사진에 배치된 파츠의 전체 조합과 그 결과로 완성된 빌드입니다. 개별 아이템의 명칭이 아닙니다.

- 공개 시점: 튜토리얼 이후
- 상세 문서: [아이템·파츠 시스템](../01_게임_기획/시스템_상세_부록.md#items)

<a id="코어"></a>

### 코어

액티브 스킬에 필요한 자원, 현재 전개 계통과 활성 기초 능력치를 제공하는 핵심 파츠입니다. 손상되면 생성 효율이 낮아지고 파괴되면 자원·스킬·활성 효과가 중단됩니다.

- 공개 시점: 튜토리얼
- 상세 문서: [장비·코어·스킬](../01_게임_기획/01_핵심_플레이/장비_코어_스킬/README.md)

<a id="주머니"></a>

### 주머니

여러 재료를 적은 청사진 칸에 압축 수납하는 보조형 파츠입니다. 전개 후 공격받을 수 있고 파괴되면 내부 재료를 반출하지 못합니다.

- 공개 시점: 튜토리얼
- 상세 문서: [청사진 성장 및 공간 경제](../01_게임_기획/시스템_상세_부록.md#space-economy)

## 진행과 거점

<a id="허브"></a>

### 허브

플레이어 번호 지구에 존재하는 고정 거점 시설의 집합입니다. 코어 복구, 파츠 제작·강화, 게이트 분석과 관계 콘텐츠를 담당합니다.

- 공개 시점: 튜토리얼 이후
- 미확정: 시설 종류와 단계별 경제
- 상세 문서: [전체 장기 플레이 루프](../01_게임_기획/시스템_상세_부록.md#long-loop)

<a id="철수"></a>

### 철수

게이트를 폐쇄하지 못했더라도 전멸 전에 확보한 전리품을 가지고 허브로 복귀하려는 행동입니다. 연결 중 피격되면 취소되며 철수 후에도 게이트의 시간과 폭주는 진행됩니다.

- 공개 시점: 튜토리얼 이후 첫 정식 게이트
- 상세 문서: [실패·철수·사망](../01_게임_기획/시스템_상세_부록.md#failure)

- 세계관 정의는 용어집, 시스템 규칙은 연결된 게임 기획 문서에서 관리합니다.
- 새 용어를 추가할 때 `정의`, `공개 시점`, `미확정 또는 주의`, `상세 문서`를 함께 작성합니다.
- MkDocs가 한글 제목으로 생성한 앵커를 사용하되 제목을 바꾸면 연결된 링크도 함께 검사합니다.

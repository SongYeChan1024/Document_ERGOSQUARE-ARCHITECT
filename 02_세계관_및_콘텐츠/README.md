## 작성 원칙

- 신화·설화는 원문, 지역 전승과 현대 창작을 구분합니다.
- 실제 전승과 게임의 이면 해석을 같은 사실처럼 쓰지 않습니다.
- 개발진용 비밀이 튜토리얼 대사나 UI에서 조기에 노출되지 않도록 공개 층위를 확인합니다.

# 게이트 신화 콘텐츠 조율서

> [!IMPORTANT]
> 문서 상태: 운영 초안. 신화·설화·우화 기반 게이트의 후보 선정, 조사, 문화 검토와 제작 승인을 위한 공통 기준입니다.

## 1. 목적

에고스퀘어의 게이트는 특정 문화권을 배경 장식으로 소비하는 전투장이 아니라, 인류가 기억한 이야기의 법칙이 현실이 된 퀘스트 영역입니다.

이 문서는 다음 질문을 팀이 같은 기준으로 판단하도록 돕습니다.

- 어떤 이야기와 문화권을 게이트 후보로 채택할 것인가?
- 원전에서 무엇을 가져오고 무엇을 새로 창작할 것인가?
- 전투 외에 어떤 폐쇄 조건과 플레이 경험을 만들 것인가?
- 저작권, 상표, 출처와 문화적 민감성을 어떻게 검토할 것인가?
- 여러 문화의 유사한 이야기를 어떤 원칙으로 결합할 것인가?

## 2. 핵심 제작 원칙

1. **문화권보다 이야기 구조를 먼저 정합니다.** 같은 신화라도 토벌, 여정, 협상, 의식 등 서로 다른 게임 경험으로 설계할 수 있어야 합니다.
2. **게이트 주민과 침식체를 구분합니다.** 신화 속 존재라는 이유만으로 모두 적이나 전리품으로 만들지 않습니다.
3. **원전의 핵심과 에고스퀘어의 창작을 기록합니다.** 현대 게임·영화·번역의 고유 표현은 복제하지 않습니다.
4. **한 대륙을 하나의 신화로 취급하지 않습니다.** 아프리카, 아메리카, 오세아니아와 아시아 내부의 서로 다른 공동체와 전승을 구분합니다.
5. **살아 있는 종교와 공동체 전승은 강화 검토합니다.** 공개 여부, 신성성, 금기, 명칭과 도상의 사용 맥락을 조사합니다.
6. **혼합 게이트에는 서사적 이유가 필요합니다.** 외형이 비슷하다는 이유로 합치지 않고, 집단 기억의 공명이나 침식에 의한 충돌을 이야기 안에서 설명합니다.

> 숫자는 세계를 식별하고, 이야기는 세계를 연결하며, 게이트의 규칙은 플레이 방식을 결정합니다.

## 3. 게이트 유형 분류

| 유형 | 핵심 경험 | 대표 폐쇄 조건 | 적합한 시스템 |
| --- | --- | --- | --- |
| 토벌형 | 재앙의 근원 추적 | 침식 지휘체 처치, 약점 해제 | 전투, 추적, 보스전 |
| 여정형 | 목적지 도달과 호위 | 대상·물건 운반, 귀환로 확보 | 탐험, 생존, 동료 관리 |
| 시련형 | 자격과 가치 증명 | 과업 완수, 금기 준수 | 선택, 퍼즐, 제한 전투 |
| 비극 개입형 | 정해진 파국에 개입 | 희생 최소화, 진상 규명 | 분기, 시간 압박, 평판 |
| 의식 수행형 | 규칙과 순서 복원 | 봉인·장례·계절 의식 완성 | 수집, 방어, 순서 퍼즐 |
| 계약·협상형 | 세력 간 이해 조율 | 약속 체결, 대가 지급 | 대화, 교환, 장기 결과 |
| 미궁·수수께끼형 | 공간과 서사의 해독 | 중심 도달, 질문 해결 | 공간 퍼즐, 관찰, 기억 |
| 생존·재앙형 | 환경 변화에 대응 | 대피, 거점 유지, 재앙 종료 | 건축, 제작, 자원 관리 |
| 저승·귀환형 | 잃은 존재와 기억 회수 | 영혼 인도, 귀환 조건 충족 | 대가 선택, 잠입, 호위 |
| 창세·재구성형 | 세계 법칙의 선택 | 파손된 질서 재설계 | 대규모 건설, 진영 선택 |

한 게이트는 `주 유형 1개 + 보조 유형 최대 2개`로 제한합니다. 모든 유형에 전투를 넣을 수 있지만, 모든 폐쇄 조건을 보스 처치로 환원하지 않습니다.

## 5. 복합 공명 게이트 원칙

여러 문화에서 반복되는 소재는 하나의 기원을 주장하지 않고 `서로 다른 지구의 기억이 같은 좌표에서 공명했다`고 설명합니다.

| 공통 모티프 | 가능한 구성 | 금지할 접근 |
| --- | --- | --- |
| 대홍수 | 서로 다른 피난 방식이 충돌하는 재앙·건축 게이트 | 여러 전승을 하나의 이야기로 단정 |
| 저승 여행 | 각 구역마다 다른 귀환 조건이 적용되는 여정 | 사후세계를 단순한 지옥 던전으로 통일 |
| 하늘·태양의 손상 | 빛과 계절을 복구하는 세계 재구성 | 신성한 상징을 무의미한 수집품으로 사용 |
| 속임수꾼 | 말과 약속이 물리 법칙이 되는 협상 게이트 | 서로 다른 존재를 외형만 바꾼 동일 캐릭터로 처리 |
| 영웅의 시련 | 플레이 방식과 가치 판단이 달라지는 연속 과업 | 모든 시련을 연속 보스전으로 축소 |

복합 게이트는 참여하는 각 전승을 독립적으로 조사한 뒤 제작합니다. 출처가 불명확하거나 한 문화가 다른 문화의 장식으로만 기능하면 분리합니다.

## 6. 후보 평가표

각 항목을 1~5점으로 평가합니다. `문화 검토 위험`은 5점이 가장 안전하고 1점이 가장 높은 위험을 뜻합니다.

| 평가 항목 | 질문 | 가중치 |
| --- | --- | ---: |
| 세계관 적합성 | 기억 공명과 번호 지구 설정을 강화하는가? | 2 |
| 플레이 차별성 | 기존 게이트와 다른 행동을 요구하는가? | 2 |
| 이야기 명료성 | 원전을 모르는 플레이어도 목표를 이해하는가? | 2 |
| 원전 접근성 | 신뢰할 수 있는 원전·연구 자료를 확보할 수 있는가? | 1 |
| 문화 검토 안전성 | 왜곡과 금기를 검토하고 자문할 수 있는가? | 2 |
| 제작 범위 | 현재 인력과 일정으로 구현 가능한가? | 2 |
| 확장성 | 변형·고난도·후속 게이트로 발전 가능한가? | 1 |

가중 합계가 높아도 강화 검토 항목이 해결되지 않으면 제작 승인으로 이동하지 않습니다.

## 7. 제작 상태와 승인 흐름

```text
후보 → 원전 조사 → 문화·권리 검토 → 콘셉트 승인 → 프로토타입 → 제작 확정
                    └→ 보류 / 분리 / 제외
```

| 상태 | 완료 조건 |
| --- | --- |
| 후보 | 소재와 예상 게이트 유형을 한 문장으로 정의 |
| 원전 조사 | 최소 2개 이상의 신뢰 가능한 출처와 판본 차이 기록 |
| 문화·권리 검토 | 저작권·상표·에셋 이용조건과 문화 위험 기록 |
| 콘셉트 승인 | 폐쇄 조건, 주민·침식체 구분과 플레이 차별성 합의 |
| 프로토타입 | 핵심 규칙을 임시 에셋으로 플레이 가능하게 구현 |
| 제작 확정 | 범위, 담당, 일정, 필요 에셋 승인 |
| 보류 | 필요한 조사·자문·기술이 준비될 때까지 중단 |
| 제외 | 제외 사유와 재검토 조건 기록 |

## 9. 1차 프로토타입 후보

서로 다른 플레이 유형을 검증하기 위해 첫 후보는 문화권의 유명도보다 시스템 차이를 우선합니다.

| 후보 | 주 유형 | 검증할 게임 경험 | 현재 결정 |
| --- | --- | --- | --- |
| 트로이 목마 | 비극 개입·침투 | 적의 계획을 발견하고 방어 또는 역이용 | 후보 |
| 바리공주 모티프 | 저승·여정 | 전투보다 대가와 귀환 조건이 중요한 장기 퀘스트 | 후보 |
| 아난시 모티프 | 계약·수수께끼 | 말, 약속과 속임수가 공간 규칙이 되는 퀘스트 | 조사 필요 |
| 여와의 하늘 복구 모티프 | 창세·재구성 | 수집과 대규모 건설로 환경 법칙 복구 | 조사 필요 |
| 고전 우화 변형 | 시련 | 10~20분 안에 규칙을 파악하는 소형 게이트 | MVP 우선 후보 |

MVP 첫 게이트는 작은 범위에서 `이야기 규칙을 이해해야 닫을 수 있다`는 차별점을 증명해야 합니다. 최종 선정은 개별 기획서와 평가표 작성 후 결정합니다.

## 10. 미결정 사항

- 첫 번째 정식 게이트의 문화권과 원전
- 문화 자문을 의무화할 위험 등급과 예산
- 실제 역사와 신화가 섞인 인물의 사용 기준
- 현존 종교의 신격을 직접 등장시키는 범위
- 복합 공명 게이트의 해금 시점
- 게이트별 출처를 게임 안에서 공개하는 방식

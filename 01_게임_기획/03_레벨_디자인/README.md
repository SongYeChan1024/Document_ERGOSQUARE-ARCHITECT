## MVP 테스트 전장 목적

- 청사진 전개 위치 선택을 비교할 수 있어야 합니다.
- 넓은 공간과 좁은 길목을 모두 포함해야 합니다.
- 플레이어와 코어가 동시에 압박받는 동선을 제공해야 합니다.

## 필수 구역

- 안전한 시작 지점
- 전개 후보 지점 2개 이상
- 적 생성 지점
- 전투 목표 지점
- 결과 전환 지점

## 공간 구성 후보

| 구역 | 목적 | MVP 처리 |
| --- | --- | --- |
| 작전 허브 | 룸·팀 구성, 작전 선택, 준비 | 메뉴 또는 소형 공간 |
| 청사진 편성 구역 | 파츠 배치와 전개 범위 확인 | 전용 UI 우선 |
| 균열 봉쇄 구역 | 전개, 전투, 코어 방어 | 테스트 전장 1개 |
| 결과 분석 구역 | 손실·자원·보상 확인과 재편성 | 결과 화면 우선 |

원안의 훈련 시설 전체를 먼저 제작하지 않고, 핵심 루프 검증에 필요한 화면과 전장부터 구현합니다.

## 테스트 전장 배치 원칙

- 중앙 또는 주요 목표 주변에 균열과 적 생성 방향을 명확히 표시합니다.
- 1~4인이 서로의 에르고스퀘어를 확인하고 지원할 수 있으며, 혼자서도 방어 동선을 읽을 수 있는 밀도를 유지합니다.
- 전방 방어에 유리한 좁은 통로와 사방 압박을 받는 열린 구역을 함께 둡니다.
- 원격 전개 후보 지점과 링크 유지 거리를 시험할 여유 공간을 둡니다.
- 엄폐물은 플레이어만 보호하고 코어에는 불리한 위치 등 상충하는 선택을 만듭니다.

## 시각 방향

- 허브·훈련 공간: 청색·백색 조명, 금속 패널, 홀로그램 UI
- 균열 구역: 보라·적색·청록 에너지, 뒤틀린 지형과 파편화된 공간
- 설치 중 파츠: 반투명 홀로그램
- 설치 완료 파츠: 발광과 실체화 피드백

## 검증 질문

- 가장 안전한 위치가 항상 가장 강한 선택이 되는가?
- 팀원이 흩어져도 현재 위험을 파악할 수 있는가?
- 파츠 크기와 지형이 의미 있는 선택을 만드는가?

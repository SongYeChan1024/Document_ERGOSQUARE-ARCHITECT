## 한 문장 목표

> 잠복 게이트에 흡인된 평범한 생존자가 에르고스퀘어를 처음 전개해 민간인을 구조하고 게이트를 닫은 뒤, 설계자로 판명되는 과정을 하나의 플레이 가능한 튜토리얼로 만든다.

## 검증할 핵심 가설

1. 우클릭 이동과 `QWERASDF` 스킬이 아이소메트릭 실시간 전투에 잘 맞는가?
2. `Tab`으로 청사진을 전장에 펼치는 행위가 직관적이고 전술적인가?
3. 수납 파츠를 포함한 파괴 가능한 인벤토리가 위치 선정과 방어 판단을 만드는가?
4. 잠복 게이트 생환 서사가 플레이어에게 게이트를 닫아야 하는 이유를 전달하는가?
5. 이 튜토리얼의 시스템과 자산을 다음 게이트 콘텐츠에 재사용할 수 있는가?

## 플레이 흐름

```mermaid
flowchart LR
    A[TUT-00<br/>시민 흡인] --> B[TUT-01~02<br/>기상·기본 조작]
    B --> C[TUT-03~04<br/>청사진 복구·첫 전개]
    C --> D[TUT-05<br/>코어 방어]
    D --> E[TUT-06<br/>토벌팀 조사]
    E --> F[TUT-07<br/>월도 보스]
    F --> G[TUT-08<br/>영혼 해방·폐쇄]
```

## 현재 판정

- 튜토리얼은 첫 프로토타입이자 첫 버티컬 슬라이스다.
- 싱글 플레이 완주를 먼저 검증하고 협동은 후속 범위로 둔다.
- 수치는 플레이테스트 전까지 `가안`으로 표기한다.
- 이 폴더에서 확정된 사항을 전체 게임에 적용할 때는 해당 `00~03` 전용 문서로 옮긴다.

## 주머니·직접 수납 검증 규칙

주머니는 여러 재료를 압축 수납하고, 직접 수납은 재료 하나마다 청사진 한 칸을 사용합니다. 주머니는 전장에 실체화되어 파괴될 수 있습니다.

| 상태 | 동작 |
| --- | --- |
| 미전개 | 주머니 신규 수납 불가, 빈 칸 직접 수납만 가능 |
| 정상 | `B`로 내용 확인, 용량 안에서 재료 압축 수납 |
| 손상 | 내구도와 예상 반출 손실 경고, 기능은 유지 가안 |
| 파괴 | 내부 재료 전체 반출 불가, 해당 주머니 신규 수납 불가 |
| 작전 종료 | 정상 주머니와 직접 수납 재료만 허브로 반출 |

### 진행 불가 방지

- 장착 중인 장비와 `1~2` 벨트 소비품은 주머니 파괴 후에도 유지한다.
- 퀘스트 핵심 물품과 현실 고정 권한 데이터는 코어에 보관하여 손실되지 않는다.
- 초기 소비 아이템인 응급 회복제와 코어 활성제는 주머니 파괴 후에도 벨트 슬롯에 유지한다.
- 튜토리얼에서도 파괴된 주머니의 내용물은 복구하지 않으며, 빈 직접 수납 칸을 이용한 파밍 지속 가능성을 안내한다.

## 코어 검증 규칙

- 코어는 전투 자원을 지속적으로 생성한다.
- Space 정신 집중은 전개 전후 초당 `10`을 회복하며 집중 중 행동을 제한하고 받는 피해를 증가시킨다.
- 정신 집중으로 회복한 자원은 코어를 전개할 때 초기화되지 않는다.
- 월드 충돌과 피격 판정을 가져 플레이어의 방패·엄폐물이 될 수 있다.
- 내구도가 소진되면 신규 자원 생성이 중단된다.
- 코어 파괴 시 축적 자원, 스킬과 활성 장비 능력이 꺼지고 게이트 내부에서는 완전 복구할 수 없다.
- 코어가 파괴되면 기본 행동으로 안전 철수를 시도하도록 안내한다.
- 적이 플레이어·코어·수납 파츠 중 목표를 바꾸는 순간을 명확히 표시한다.

## 예외 처리

- 유효하지 않은 지면에서 전개하면 실패 이유를 표시한다.
- 중요 상호작용 중 시전자가 피격되면 진행을 중단하되 다시 시도할 수 있게 한다.
- 게이트 폐쇄 트리거가 실패하면 마지막 안전 상태로 복구한다.
- 가방이 가득 찬 상태에서 일반 자원을 획득하면 월드에 남기고 사유를 알린다.

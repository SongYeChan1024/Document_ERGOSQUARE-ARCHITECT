# 레벨 및 전투 설계

> [!IMPORTANT]
> 문서 상태: 초안

## 레벨 목적

하나의 게이트 내부 맵에서 `앞으로 전진 → 안전 공간 확보 → 에르고스퀘어 전개 → 파츠 방어 → 구조 → 폐쇄`를 경험하게 한다.

## 공간 구성

### 2026-10-04 현재 프로토타입 적용 기준

아래 A~G는 확장 기획 초안입니다. 현재 구현은 `Tutorial_Stage01_Awakening`의 진입·장비·빗자루·코어 학습이며, A~G 전체나 초가집 보스가 완성된 상태는 아닙니다. 이후의 옛 셀 수 가안보다 현재 프로토타입의 `3×3` 전개 기준을 우선합니다.

- 진입부는 좁은 굴곡 통로로 구성하고, 시작점에서 쓰러진 대원이 직접 보이지 않도록 암벽과 방향 전환으로 시야를 막습니다.
- 오른쪽으로 굽은 대원 발견 포켓에서 기록을 읽고 검을 획득·장착한 뒤 전투 구간이 열립니다.
- 첫 빗자루 도깨비 전투는 왼쪽으로 넓어진 비대칭 공동에서 진행합니다. 전투·우클릭 이동과 최소 3×3 청사진을 위한 평탄 바닥을 확보합니다.
- 처치/빗자루 획득·편성 후 푸른 표식을 거쳐 다시 좁아진 통로와 코어 공동으로 진행합니다.
- 실제 바닥 MeshCollider·암벽 Collider·NavMesh·도트 암벽은 같은 동굴 경계를 따릅니다. 장식으로 직사각 바닥을 숨기는 방식이 아닙니다.
- 맵 루트의 사용자 설정 1.5배 배율을 유지하고 스폰·보상·상호작용 앵커를 같은 좌표 기준으로 배치합니다.
- 코어 이후 기존 전개 연습과 두 번째 훈련 적은 유지합니다. 향후 구조는 `진입 튜토리얼존(코어 획득까지)`과 `초가집 앞 언월도 보스존`의 별도 맵이며, 이번 레벨 패스는 보스맵/전환을 새로 구현하지 않습니다.

검증 프로젝트에서 지형/시야/배율, 구간별 이동 경로, 3×3 바닥과 기록·장비·빗자루·코어 진행 API 등 54개 자동 검사 통과. 수동 완주와 통로 폭/가림/전투 여유의 체감 조정은 다음 플레이테스트에서 확인합니다.

### 확장 구역 가안

| 구역 | 역할 | 핵심 오브젝트 |
| --- | --- | --- |
| A. 기상실 | 이동과 시점 적응 | 플레이어, 소지품, 쓰러진 민간인 |
| B. 기억 회랑 | 조사와 회상 | 기억 흔적 3개, 투영된 도시 잔상 |
| C. 첫 접촉지 | 공격·이동 회피 학습 | 기억 투영형 도깨비 소수, 산개 장애물 |
| D. 고정 광장 | 에르고스퀘어 전개 | 평탄한 격자 공간, 전개 기준점 |
| E. 방어 구역 | 수납 파츠 보호와 파밍 | 복수 진입로, 웨이브 스폰 |
| F. 구조 구역 | 폭주 규칙 조사와 구조 | 영혼 주입형 도깨비, 토벌팀 시체·기록, 안정화 지점 |
| G. 초가집 폐쇄실 | 학습한 기능 종합 | 동굴 끝 초가집, 월도 보스, 폐쇄 장치, 복귀 좌표 |

```text
A 기상실 → B 기억 회랑 → C 첫 접촉지 → D 고정 광장
                                      ↓
G 폐쇄실 ← F-5 팀장 ← F-4 조사관 ← F-3 기술요원 ← F-2 전투대원 ← F-1 정찰대원 ← E 방어 구역
                                      ↓
                                 현실 복귀 장면
```

## 구역별 그레이박스 요구사항

| 구역 | 공간 요구 | 전투·상호작용 | 체크포인트 |
| --- | --- | --- | --- |
| A | 한 방향 출구가 보이는 좁은 안전실 | 이동과 카메라만 허용 | 튜토리얼 시작 |
| B | 주 동선에 세 개의 짧은 기억 포켓 | 흔적 조사마다 회상 1개 | 세 번째 회상 완료 |
| C | 산개 엄폐물이 있는 소형 원형 또는 사각 전장 | 투영형 도깨비 1마리로 공격·이동 회피 | 첫 적 처치 |
| D | 적 진입 전 한 화면에 읽히는 평탄 지면 | `6×6` 가안 청사진 배치 | 유효 전개 완료 |
| E | 서로 다른 방향의 진입로 3개와 파츠 방어 공간 | 웨이브, 코어·수납 피격, 활성제 사용 | 방어 웨이브 종료 |
| F-1~5 | 하강하거나 깊어지는 단방향 조사 동선 | 역할별 시체·기록·장비, 영혼 주입형 조우 | 폐쇄 인증 획득 |
| G | 동굴 끝의 초가집을 랜드마크로 삼고 월도 사거리와 전개물을 함께 읽는 폐쇄 전장 | 초가집 앞 3단계 보스, 결박핵 해체, 영혼 안정화 | 월도 처치 직전·폐쇄 직전 |
| 복귀 | 기존 도시 세트의 통제 구역 재사용 | 기관 요원 대화와 결과 요약 | 튜토리얼 완료 |

그레이박스의 셀 수, 통로 폭, 카메라 높이와 전투 거리는 플레이테스트 전까지 `TBD`로 남깁니다. 먼저 D·E·G가 같은 카메라 규칙에서 파츠, 적 전조와 퇴로를 동시에 읽을 수 있는지 검증합니다.

## 격자와 이동

- 레벨은 월드 `XZ` 평면의 정사각 격자를 아이소메트릭 다이아몬드로 투영한다.
- 플레이어와 적은 격자에 묶이지 않고 연속적으로 이동한다.
- 코어, 수납 파츠와 방벽만 셀에 스냅한다.
- 최초 청사진 크기는 `6×6` 또는 `8×8` 가안을 비교한다.
- 전개 광장은 편성 결과와 적 진입로가 한 화면에 읽히게 한다.

## 전투 리듬

1. 첫 전투에서 적 한 마리로 기본 공격과 우클릭 이동 회피를 학습한다.
2. 첫 장비 스킬을 편성한 뒤 `Space` 정신 집중으로 자원을 회복하고 기동·방어 스킬을 한 번 사용한다.
3. 코어를 전개할 때 정신 집중으로 모은 자원이 유지되는 것을 보여준다.
4. 전개 후 소규모 웨이브로 코어를 엄폐물로 쓸지 직접 보호할지 선택한다.
5. 코어 피격과 자원 생성 위험을 먼저 학습한 뒤 수납 파츠 방어로 확장한다.
6. 정신 집중보다 즉시 충전이 필요한 압박 상황에서 코어 활성제를 사용한다.
7. 영혼 주입형 개체와 토벌팀 기록을 통해 정상 투영과 폭주의 차이를 전달한다.
8. 최종 전투에서는 월도의 넓은 베기와 코어·수납 파츠 돌진을 피하며 게이트 폐쇄 조건을 완성한다.

## 소형 도깨비 공용 행동

- 평상시 플레이어를 탐지하고 추적한다.
- 인접한 플레이어 또는 핵심 파츠를 공격한다.
- 수납 파츠의 위협도를 일정 수준 부여하여 방어 판단을 유도한다.
- 공격 전조를 바닥 표시와 모션으로 알린다.
- 폐쇄실에서는 수만 늘리고 새 패턴을 추가하지 않는다.

## 리소스 절약 원칙

- 폭주 이전의 도시는 전체 플레이 맵으로 만들지 않고 회상용 부분 세트로 제작한다.
- 게이트 폭주는 지형을 두 벌 만드는 침식형 바이옴 대신 투영 쉘이더·데칼·음향으로 표현한다.
- 현실 복귀 장면은 기존 도시 자산에 NPC 비활성, 통제선과 조명 상태를 더해 유령도시를 표현한다.

## 공간 연출 진행

- A~G의 기본 환경은 자연 동굴이며, 깊이에 따라 습기·뿌리·생활 도구의 기억 잔상이 증가합니다.
- A~B는 저채도 조명과 먼 흡인음으로 장소의 불확실성을 강조합니다.
- C~E는 투영 흔적과 격자 UI의 명도를 높여 시스템 학습을 우선합니다.
- F는 시체의 역할 장비와 기록 위치로 토벌팀의 전진·붕괴 순서를 말합니다.
- G의 초가집은 정상적인 마을 건물이 아니라 이면이 인간의 기억을 잘못 재현한 비현실적 구조물로 보이게 합니다.
- G는 동굴 진입부부터 초가집과 월도 병사의 실루엣을 목적지로 보여주고, 월도의 공격 전조·코어 상태·결박핵을 같은 색으로 겹치지 않게 분리합니다.
- 폐쇄 뒤에는 사람의 목소리와 도시 환경음을 되돌려 구조 결과를 체감시킵니다.

장면별 배치와 트리거는 [플롯별 상세 연출 및 구현 명세](../시나리오/플롯별_상세_연출_및_구현_명세.md), 적 수와 패턴은 [몬스터 및 보스 명세](../콘텐츠/몬스터_및_보스_명세.md)를 따릅니다.

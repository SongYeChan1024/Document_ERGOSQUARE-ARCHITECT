# 조작 학습 및 UI 안내

> [!IMPORTANT]
> 문서 상태: 초안. 전체 게임의 입력 매핑과 상태는 [조작](../../시스템_상세_부록.md#controls)을 기준으로 합니다. 이 문서는 튜토리얼이 그 조작을 어떤 순서와 상황으로 가르칠지만 다룹니다.

## 학습 목표

플레이어가 튜토리얼 종료 시 다음을 자막 없이 반복할 수 있게 합니다.

- 우클릭으로 이동하고 좌클릭으로 기본 공격합니다.
- `QWERASDF`에 편성한 공격·기동·방어 스킬을 사용합니다.
- `Space` 정신 집중으로 느리게 자원을 회복하고 코어 전개 뒤에도 보유량을 유지합니다.
- `G`로 조사·구조·장치 작동을 수행합니다.
- `1~4`로 소비 아이템을 사용합니다.
- `B`로 가방을 확인하고 `Tab`으로 에르고스퀘어를 전개합니다.

| 플롯 | 상황 | 학습할 조작 | 성공 확인 |
| --- | --- | --- | --- |
| TUT-00 기상 | 돌아다닐 수 있는 안전한 공간 | 우클릭 이동 | 첫 흔적 도달 |
| TUT-01 기억 | 조사할 흔적 노출 | `G` 짧게 누르기 | 흔적 활성화 |
| TUT-02 첫 위협 | 적의 단순한 공격 | 좌클릭 기본 공격, 우클릭 이동 회피 | 적 처치 |
| TUT-03 각성 | 시스템 진단·첫 장비 스킬과 격자 투영 | `QWERASDF` 편성, `Space` 정신 집중, `Tab` 전개 모드 | 자원 회복·전개 화면 진입 |
| TUT-04 첫 전개 | 안전한 광장에 고정 청사진 제공 | 마우스 선택, 좌클릭 확정, 우클릭 취소, `Q/E` 회전 | 코어·수납·방벽 전개 |

| TUT-06 조사 | 토벌팀 시체·기록과 안정화 대상 | `G` 짧게·길게 누르기 | 월도 기록·폐쇄 인증 확보 |
| TUT-07 월도 | 보스와 파괴 위험에 놓인 코어 | `1~2` 소비 아이템, 학습한 전투 조작 종합 | 월도 처치 |
| TUT-08 폐쇄 | 해방된 영혼과 폐쇄 장치 | `G` 상호작용, 결과 확인 | 게이트 폐쇄·복귀 |

## 스킬 슬롯 표시

- `QWERASDF` 8칸을 처음부터 같은 위치에 표시합니다.
- 튜토리얼 빌드에서는 2~3개만 활성화하고 나머지는 잠금 상태로 둡니다.
- 잠긴 슬롯은 사용 불가 사유를 표시하되 튜토리얼 종료 즉시 모두 열린다고 암시하지 않습니다.
- 스킬이 처음 활성화되면 슬롯과 캐릭터 효과를 짧게 연결해 위치를 인지시킵니다.

## 프롬프트 규칙

- 조작을 필요로 하는 상황이 나타난 뒤 키를 노출합니다.
- 프롬프트는 `[키] + 행동 동사`를 기본으로 합니다. 예: `[G] 기억 흔적 조사`.
- 입력이 성공하면 안내를 즉시 제거하고 월드의 결과를 강조합니다.
- 동일 조작을 반복해 문장으로 설명하지 않습니다.
- 키 표시는 현재 입력 바인딩을 참조합니다.
- 조작하지 않고 일정 시간 멈춘 경우 첫 알림보다 구체적인 재안내를 표시합니다.

## 보여주기 전 설명하지 않기

| 규칙 | 월드에서 먼저 보여줄 것 | 이후 안내 |
| --- | --- | --- |
| 기동·방어 스킬 | 적의 느리고 명확한 공격 전조와 보장 스킬 | `[편성 키] 기동·방어 스킬` |
| 정신 집중 | 자원이 부족한 스킬 슬롯과 안전한 짧은 공백 | `[Space 유지] 정신 집중` |
| 상호작용 | 빛나는 흔적과 캐릭터의 시선 | `[G] 조사` |
| 전개 | 고정할 수 없는 왜곡 지면과 시스템 진단 | `[Tab] 에르고스퀘어 전개` |
| 가방 | 직접 수납 칸과 소형 주머니에 들어가는 재료 | `[B] 획득품 확인` |
| 코어 활성제 | 정신 집중보다 즉시 충전이 필요한 압박 상황 | `[2] 코어 활성제` |

## 주머니·직접 수납 학습

1. 정상 상태에서 자원을 자동 획득하고 `B`로 확인합니다.
2. 첫 재료는 빈 칸에 직접 수납하고 다음 재료는 소형 주머니에 압축 수납해 차이를 보여줍니다.
3. 적이 주머니를 타격하면 월드, HUD와 사운드로 예상 반출 손실을 알립니다.
4. 파괴 후에는 내부 재료가 반출 불가임을 표시하고, 빈 칸이 있으면 직접 수납은 계속 허용합니다.
5. `[2]` 코어 활성제 사용 후 자원이 즉시 충전되고 스킬이 활성화되는 것을 직접 확인하게 합니다.

주머니 파괴를 필수 이벤트로 보여줄지 손상과 예상 손실 경고까지만 가르칠지는 플레이테스트 전 확정합니다.

## UI 완료 조건

- [ ] 튜토리얼 종료 전에 필수 조작을 각각 한 번 이상 사용합니다.
- [ ] 프롬프트 없이도 같은 조작을 다음 구간에서 반복할 수 있습니다.
- [ ] 가방과 에르고스퀘어 전개의 차이를 행동으로 구분합니다.
- [ ] 주머니 파괴가 내부 재료 반출 실패로 이어지며 직접 수납은 별도라는 것을 이해합니다.
- [ ] 색상만으로 유효·무효, 손상·파괴를 구분하지 않습니다.

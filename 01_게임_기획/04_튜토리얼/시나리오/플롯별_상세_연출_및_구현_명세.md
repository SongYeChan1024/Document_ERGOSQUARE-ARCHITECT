## 이번 검토의 범위

> **2026-09-27 구현 상태 보완 · 송예찬:** 아래 R 장면들은 연출 후보이며 구현 완료 목록이 아닙니다. 현재 서사 표현은 쓰러진 대원의 기록 창(현장 묘사·일지 초안)과 목표 안내뿐입니다. 사용자 승인으로 적용된 기능 순서는 **대원 조사·무기 획득·직접 장착 → 기본 공격으로 첫 도깨비 처치 → 빗자루 획득 → 청사진 배치·스킬 할당 → 코어 획득 구간**입니다. 이 순서가 아래 과거 검토안의 상충하는 순서보다 우선합니다. 기상·발견 반응·도깨비 유대·각성·코어 발견의 이야기 연출은 아직 없습니다.
>
> 대원 위치는 시작점에서 약 14m 안쪽으로 변경했고 기록 창을 열면 G 안내를 숨깁니다. 최종 발견 거리감은 실제 카메라에서 확인해야 합니다. 모션 개선은 보류하며, 구조물 투명화는 다음 작업 후보이지 현재 적용 기능이 아닙니다.

기존 TUT-00~08 이야기를 유지하면서 현재의 획득·편집·스킬·코어·회수 기능을 자연스럽게 학습시킵니다. 아래 R 번호는 **검토용 장면 번호**이며 기존 TUT 번호나 코드의 Phase를 대체하지 않습니다. 기존 상세 수치와 중복 원문은 문서 하단에 보존하되 현재 구현 지시로 사용하지 않습니다.

| 구분 | 현재 기반 / 제안 |
| --- | --- |
| 구현 기반 | 우클릭 이동, G 파츠 획득, Tab HUD와 편집, 배치·스킬 할당, 빗자루 스킬, Space 정신집중, 코어 전개·회복, 수동·거리 회수, 두 훈련 적과 확장 통로 |
| 이번에 설계 | 기상·기억 흔적·도깨비와의 첫 관계·기능을 배우는 동기·다음 공간 유도 |
| 이후 제작 | 실제 적 공격과 코어 방어, 토벌팀 조사, 영혼 안정화, 초가집·월도전, 게이트 폐쇄·현실 복귀 |
| 별도 검토 | 주머니·플레이트·소비품 학습을 이번 최소 완성 구간에 포함할지. 기존 전체 기획에서 삭제하는 것은 아님 |

**경험의 흐름:** 낯선 동굴에서 생존 → 작은 도깨비와 동행 → 자신의 힘 이해 → 남겨진 사람들의 흔적 → 월도와 대면 → 영혼 해방과 설계자 명명.

### 공통 연출 원칙

- 플레이어는 평상복을 입은 생존자입니다. 기관 명은 알고 있지만 정확히 어떤걸 하는지 몰라야 합니다.
- 평상형 도깨비는 큰 눈을 가진 작은 **푸른 도깨비불 + 본체 물건**입니다. 귀여운 몸짓으로 관계를 만들되 인간의 영혼과 동일한 존재로 설명하지 않습니다.
- 첫 구현은 자막·조명·오브젝트 동작으로 성립시킵니다. SFX와 음성은 제작 후보이며 준비된 에셋으로 간주하지 않습니다.
- 중요한 단서는 색뿐 아니라 형태·움직임·목표 문구를 함께 사용합니다. 전투 중 긴 기록창이나 강제 카메라 전환은 피합니다.
- 한 단계의 필수 학습은 하나씩 안내합니다. G 획득으로 편집창을 자동으로 열지 않습니다. F는 스킬이며 전개 확정 키가 아닙니다.
- Space는 기존 코어 에너지를 회복하는 정신집중입니다. 별도 게이지나 기본 회피 입력을 만들지 않습니다.
- 진행 완료는 버튼 입력이 아니라 실제 상태 변화로 판정합니다. 연출 종료만으로 아이템 획득·적 처치·코어 전개를 대신하지 않습니다.

## 구간별 시나리오·연출 검토안

### R-00. 차가운 바닥 — TUT-00

- **시작:** 튜토리얼 씬과 플레이어 조작 준비 완료.
- **이야기·대사 가안:** 짧은 암전이 걷히며 동굴 바닥의 플레이어가 보입니다. “……여긴 어디지?”
- **행동:** 우클릭으로 빛이 새어 들어오는 통로까지 이동합니다.
- **연출·길 안내:** 기상 지점은 안전하게, 통로는 더 밝게 구성합니다. 평상복과 흙 위의 현실 물건으로 일상에서 떨어져 나왔음을 보여줍니다. 카메라는 우선 기존 아이소메트릭 시점을 유지합니다.
- **완료:** 실제 플레이어가 출구 유도 영역에 진입.
- **막힘 처리:** 일정 시간 이동이 없으면 우클릭 안내를 다시 표시합니다. 안내 대기 시간은 가안 10초. 낙사나 전투는 넣지 않습니다.

### R-01. 주인 없는 물건 — TUT-01

- **시작:** 기상 통로를 벗어남.
- **이야기·대사 가안:** 휴대전화의 깨진 화면과 작업용 명찰이 보입니다. “집에 가던 길이었는데…… 사람들도 같이 휩쓸렸어.”
- **행동:** 가까운 흔적에 G를 눌러 짧은 기록을 읽습니다.
- **연출·길 안내:** 필수 흔적 한 개를 주 동선에, 추가 두 개를 짧은 곁길에 두는 축소안을 제안합니다. 회상 영상 대신 1~2줄 문구와 순간적인 조명 변화부터 만듭니다.
- **완료:** 지정된 필수 흔적의 조사 완료 상태가 기록됨. 선택 흔적은 진행을 막지 않음.
- **막힘 처리:** 재조사는 전문 열람만 수행하고 완료 이벤트·보상을 중복 지급하지 않습니다. 범위 밖에서는 G를 숨깁니다.
- **기존안과 차이:** 세 흔적을 모두 조사하는 원안에서 필수 한 개로 줄이는 제안이며 승인 필요.

### R-02. 빗자루 곁의 작은 불 — TUT-02 연결 제안

- **시작:** 필수 기억 흔적 조사 완료.
- **이야기·대사 가안:** 도깨비불이 빗자루 뒤로 숨었다 눈만 내밀고, 플레이어가 멈추면 다시 다가옵니다. “너도 여기 갇힌 거야?”
- **행동:** 낡은 빗자루를 G로 획득합니다.
- **연출·길 안내:** 빗자루와 불꽃이 함께 반응하게 합니다. 획득은 도깨비를 죽이거나 별개 장비로 떼어내는 표현이 아니라 함께 이동하는 첫 접점으로 연출합니다. 실제 유대 수치 시스템을 여기서 추가하지는 않습니다.
- **완료:** 인벤토리에 빗자루 파츠가 존재함.
- **막힘 처리:** 보유 상태를 먼저 확인해 중복 생성하지 않습니다. 필수 파츠가 생성되지 않았다면 진행 차단 이유를 표시하고 개발 로그를 남깁니다.
- **승인 필요:** 원안은 적대 빗자루와 먼저 전투합니다. 현재 프로토타입처럼 먼저 획득하려면 이 개체와 첫 적을 다른 개체로 구분해야 합니다.

### R-03. 보이지 않던 격자 — TUT-03

- **시작:** 빗자루 획득 완료, 아직 전투가 시작되지 않은 안전한 작은 공터.
- **이야기·대사 가안:** 빗자루가 반응하며 바닥의 격자가 잠깐 나타납니다. “어디에 놓을지…… 보이는 것 같아.” 시스템 문구 후보는 “현실 고정 인터페이스 확인”.
- **행동:** Tab → 청사진 편집 → 빗자루 배치 → 파츠 위에서 원하는 QWERASDF 키로 스킬 할당.
- **연출·길 안내:** 편집 버튼, 빈 셀, 할당 안내를 순차적으로 강조합니다. 중앙은 근접 전개 원점이며 파츠 배치 불가임을 짧게 표시합니다.
- **완료:** 빗자루가 유효 셀에 배치되고 같은 파츠가 스킬 슬롯에 연결됨. 창을 열었다 닫는 것만으로 완료되지 않습니다.
- **막힘 처리:** 배치만 했다면 할당 안내, 할당만 했다면 배치 안내를 표시합니다. 편집 중 이동·전투 입력을 섞지 않습니다.

### R-04. 힘을 모아 첫 반격 — 첫 전투 학습

- **시작:** 편집·할당 완료 후 첫 전투 공터 진입.
- **이야기·대사 가안:** 앞쪽의 다른 빗자루 개체가 길을 막습니다. 자원이 부족할 때 “잠깐…… 힘을 모으면 움직일 수 있겠어.”
- **행동:** Space 정신집중으로 자원 확보 → 할당한 스킬로 첫 적 처치.
- **연출·길 안내:** 실제 스킬 비용 이상 모였을 때 해당 슬롯을 강조합니다. 스킬 사용 순간만 빗자루를 들고 휘두르는 기존 표현을 사용합니다. 집중 별도 게이지는 없습니다.
- **완료:** 연결된 첫 적의 처치 상태 확인. 코어 설치는 아직 요구하지 않습니다.
- **막힘 처리:** 자원 부족·미할당·유효 표적 없음 안내를 구분합니다. 적 공격을 추가할 때에는 넓은 이동 공간과 명확한 전조부터 구현합니다.
- **현재와 차이:** 현재 정지형 훈련 적은 실제 추격·공격 학습을 대신하지 못합니다. 좌클릭 기본 공격을 필수 통과 조건으로 넣는 것은 별도 구현·검토 후 결정합니다.

### R-05. 스스로 힘을 만드는 혼 — TUT-04

- **시작:** 첫 전투 완료 → 푸른 표식을 지나 코어 획득 통로로 이동.
- **이야기·대사 가안:** 앞쪽에서 규칙적으로 밝아지는 작은 혼이 보입니다. “이걸 놓아두면, 내가 계속 집중하지 않아도 되겠어.”
- **행동:** G 코어 획득 → 편집에서 빗자루와 다른 셀에 배치 → Tab 전개 화면에서 좌클릭으로 실제 설치.
- **연출·길 안내:** 코어의 밝기 변화, 설치 외곽선, ‘전개 완료’ 문구, 같은 자원 바의 증가를 함께 보여줍니다. 획득처는 우선 기존 구체를 사용하며 토벌팀 유품인지 자연 발생인지 확정하지 않습니다.
- **완료:** 코어 설치 성공 후 실제 자동 회복량 발생. 자원이 가득 차면 스킬을 사용한 뒤 증가를 확인하도록 안내합니다.
- **막힘 처리:** 충돌·바닥 없음·편성 누락은 이유를 표시합니다. 중간 회수 시 재전개 안내로 돌아가며 현재 자원을 초기화하지 않습니다.

### R-06. 두고 갈 것인가, 가져갈 것인가 — TUT-05의 최소 학습

- **시작:** 자동 회복 확인 후 두 번째 전투.
- **이야기·대사 가안:** “계속 놓아둘 수만은 없겠네. 앞으로 가져가자.”
- **행동:** 코어 회복을 활용해 두 번째 적 처치 → Tab의 청사진 회수 버튼 → 다음 공터에서 재전개.
- **연출·길 안내:** 회수 시 설치물·외곽선이 사라지고 ‘회수 완료’를 표시합니다. 수동 회수 학습 후에는 거리 표시를 통해 자동 회수를 안내합니다. 자동 회수를 일부러 반복하도록 강요하지 않습니다.
- **완료 가안:** 두 번째 적 처치와 실제 회수 1회. 수동을 건너뛰고 거리 자동 회수가 발생해도 다음 진행은 막지 않습니다.
- **막힘 처리:** 파츠·편성·스킬·자원·내구도는 유지합니다. 회수는 수리가 아니며 파괴 코어를 정상화하지 않습니다.
- **현재와 차이:** 회수 기능은 구현 기반에 있지만 회수 학습 완료 판정은 추가 필요합니다. 12m는 임시 수치이고 높이를 제외한 설치 원점 거리입니다. 실제 코어 방어·주머니 보호는 별도 후속 전투로 남깁니다.

### R-07. 먼저 들어온 사람들 — TUT-06

- **시작:** 현재 두 번째 전투 이후 끝 표식 너머에 새 조사 통로를 제작한 뒤 연결.
- **이야기:** 정찰 기록으로 외부 토벌과 내부 진입을, 기술 기록으로 도구 안의 인간 생존 신호를, 팀장 기록으로 월도의 위험과 폐쇄 인증을 전달합니다.
- **대사 가안:** 기술 기록 “물건 안에서…… 사람의 반응이 잡힌다.” 플레이어 “부수는 것만으로 끝나는 게 아니었어.”
- **행동:** G 기록 조사 → 영혼 주입형 적 처치 → 남은 영혼 안정화 → 폐쇄 인증 확보.
- **연출·길 안내:** 시체를 한곳에 모으지 않고 퇴각 흔적을 따라 배치합니다. 긴 전문은 선택 열람으로 둡니다. 도깨비불과 결박된 인간 영혼은 형태·문구로 구분합니다.
- **완료 가안:** 필수 정보 확인 + 영혼 안정화 + 폐쇄 인증 확보. 기록의 최종 수량과 G 홀드 시간은 미정입니다.
- **막힘 처리:** 적 처치만으로 영혼 구조를 완료 처리하지 않습니다. 필수 상호작용은 재시도 가능하게 하되 보상은 중복 지급하지 않습니다.
- **범위:** 조사·영혼 안정화·인증 모두 제작 대상이며 구현 완료가 아닙니다.

### R-08. 동굴 끝의 초가집 — TUT-07 도입

- **시작:** 토벌팀 구간 완료 후 마지막 굽이를 돌아 시야가 열림.
- **이야기·대사 가안:** 동굴 안쪽에 어울리지 않는 초가집과 월도를 든 병사 실루엣이 보입니다. “저 안에도…… 사람들이 있는 건가?”
- **행동:** 안전한 관찰 공간에서 편성·자원 확인 후 전장에 진입합니다.
- **연출·길 안내:** 초가집 → 월도의 긴 날 → 가슴 결박선 순으로 시선이 가도록 배치합니다. 외형은 기존 월도 원화를 참고하되 얼굴 없는 병사라는 본문 묘사와 최종 모델 해석은 검토합니다.
- **완료:** 준비 구역을 벗어나 보스 전투 영역에 진입.
- **막힘 처리:** 등장 연출 동안 피격시키지 않습니다. 강제 카메라 사용 여부는 가안이며 종료 후 반드시 기존 추적 시점과 입력을 복구합니다.

### R-09. 월도와 결박핵 — TUT-07 전투

- **시작:** 보스 조우 확정.
- **행동:** 이동으로 전조 회피, 스킬과 자원 관리, 코어 위치 선정으로 월도를 처치합니다.
- **연출:** 최초 검증은 횡베기·내려찍기 두 패턴부터 제안합니다. 원안의 3페이즈·코어 돌진·주머니 압박은 선행 기능 완성 후 추가하며 삭제 확정이 아닙니다.
- **완료:** 월도 체력 0 → 적 공격 중지 → 결박핵 상호작용 가능 상태. 게이트는 아직 열려 있습니다.
- **막힘 처리:** 사망을 자동 부활로 바꾸지 않습니다. 코어 파괴 시 철수·복구 경로가 없는 현재 프로토타입을 그대로 정식 보스전에 사용하지 않습니다.
- **선행 결정:** 근접 코어의 자동 회수 거리와 보스 전장 크기를 함께 검증합니다. 회수를 이용한 코어 표적 공격 무효화, 추적 표적 소실 처리도 적 AI 명세에 추가해야 합니다.

### R-10. 밖으로 이어지는 빛 — TUT-08

- **시작:** 월도 처치와 결박핵 노출.
- **행동:** G 영혼 해방 → 폐쇄 인증을 이용한 폐쇄 상호작용 → 현실 복귀.
- **연출·대사 가안:** 결박선이 하나씩 풀리고 빈 월도가 남습니다. 현실 통제선에서 조사관이 “현장 자체를 설계한 것에 가깝습니다.”라고 말한 뒤 ‘신규 각성 분류 — 설계자’를 표시합니다.
- **완료:** 해방 완료·폐쇄 완료·복귀 완료를 각각 기록하고 결과 화면은 한 번만 표시합니다.
- **막힘 처리:** 해방 중 취소하면 재시도 가능, 완료 후 재입력은 중복 보상 없음. 로딩 실패 시 완료된 보상을 다시 지급하지 않는 복구 정책이 필요합니다.
- **정보 제한:** 월도의 ‘많은 생명을 담는 그릇’ 해석은 기관 분석에서 공개합니다. 이면의 최종 정체와 정본 지구의 진실은 설명하지 않습니다.

## 3. 공통 플롯 규칙

- 한 플롯에서는 신규 핵심 조작을 최대 2개까지만 요구합니다.
- 조작 프롬프트는 필요한 상황이 나타난 뒤 노출합니다.
- 필수 기록은 짧은 요약을 자동 표시하고 전문은 선택 열람으로 둡니다.
- 중요 아이템은 획득 실패·가방 파괴로 소실되지 않습니다.
- 정식 플레이에서 사망하면 해당 번호 지구가 게임오버되며 체크포인트에서 부활하지 않습니다.
- 개발·QA 빌드에서는 긴 회상·명명 연출을 생략하고 플롯 안전 상태를 불러오는 디버그 기능을 제공합니다.
- 적과 필수 오브젝트가 사라지거나 끼면 사망 처리하지 않고 해당 플롯의 안전 상태로 복구합니다.

## 9. TUT-05 — 전개물 방어

### 서사와 플레이

- **플레이어 목표:** 2~3회의 짧은 웨이브를 막고 필요한 자원을 획득합니다.
- **학습 목표:** 코어와 파츠가 방패이자 파괴 가능한 전투 자산임을 이해합니다.

### 웨이브 가안

| 웨이브 | 적 | 의도 |
| --- | --- | --- |
| 1 | 투영형 2마리, 정면 | 방벽과 코어 엄폐 경험 |
| 2 | 투영형 2+1마리, 양쪽 | 플레이어·코어 표적 전환 확인 |
| 3 | 투영형 3마리, 수납 우선 개체 1 포함 | 수납 피격·가방 차단과 코어 보호 경험 |

수량은 난이도 가안이며 공용 소형 도깨비 리그 하나를 사용합니다.

### 기능·피드백

- 코어 피격 시 자원 UI, 월드 균열과 경고음을 함께 표시합니다.
- 코어가 파괴되면 축적 자원과 신규 생성이 사라지고 스킬·활성 장비 능력이 비활성화됩니다.
- 소형 주머니가 파괴되면 내부 재료는 반출 불가가 되고 해당 주머니의 신규 수납이 차단됩니다. 빈 직접 수납 칸이 있으면 재료를 한 칸씩 계속 획득할 수 있습니다.
- 게이트 내부에서는 코어를 완전히 수리할 수 없으며 코어 활성제도 사용할 수 없습니다. 튜토리얼에서 코어가 파괴되면 안전 철수 경로를 안내하는 방향을 검증합니다.

### 완료 조건

- 마지막 웨이브 처치, 코어 상태 확인, 첫 일반 드롭을 `B`에서 확인하면 완료합니다.
- 전방에서 토벌팀의 신호음이 들리며 TUT-06으로 이동합니다.

## 10. TUT-06 — 남겨진 토벌팀

### 서사와 플레이

- **플레이어 목표:** 토벌팀 시체와 기록을 따라 월도의 위치와 폐쇄 방법을 알아냅니다.
- **감정 목표:** 전투 자신감에서 인간이 재료로 쓰였다는 충격으로 전환합니다.

### 조사 순서

| 순서 | 대상 | 기록 | 획득품 | 새로 알게 되는 사실 |
| --- | --- | --- | --- | --- |
| 1 | 정찰대원 | 외부 토벌 완료 | 내부 지도 | 기관은 외부 위협을 제압하고 진입함 |
| 2 | 전투대원 | 내부 개체 상이 | 응급 회복제 | 내부 적은 기존 투영체와 다름 |
| 3 | 기술요원 | 인간 생존 신호 | 코어 활성제 | 실제 영혼이 물건에 결박됨 |
| 4 | 조사관 | 월도 유물 조사 | 분석 기록 | 보스의 형상과 지역 구전 |
| 5 | 팀장 | 철수 경고 | 폐쇄 인증 | 월도를 넘어야 게이트를 닫을 수 있음 |

### 영혼 주입형 첫 등장

- 기술요원 기록 직후 같은 공용 리그의 영혼 주입형 도깨비가 등장합니다.
- 처치 시 물건이 무너지고 사람의 목소리와 영혼 파편이 빠져나옵니다.
- 플레이어는 `G` 길게 누르기로 영혼을 안정화합니다.
- 영혼 결박 파편은 퀘스트 보호 슬롯으로 들어갑니다.

### 연출

- 정찰대원 구간까지는 전투 음악을 유지하고, 기술요원 이후 음악을 줄여 인간의 목소리를 강조합니다.
- 기록 전문을 읽는 동안 게임 정지 여부는 `TBD`이며, 필수 정보는 짧은 음성·자막으로 전달합니다.
- 시체 모델은 2~3종을 재사용하고 장비·자세·조명으로 역할을 구분합니다.

### 완료 조건

- 필수 기록 3개 이상, 월도 기록과 폐쇄 인증을 확보하면 보스 문이 열립니다.
- 선택 기록을 놓쳐도 보스 진입이 막히지 않게 합니다.

## 11. TUT-07 — 사람을 죽인 도깨비 — 월도

### 전투 목적

- 지금까지 배운 이동, 회피, 공격, 스킬, 소비품과 코어 방어를 종합합니다.
- 월도는 플레이어뿐 아니라 코어와 수납 파츠를 공격해 게임의 핵심 판단을 유지합니다.

### 페이즈 가안

| 페이즈 | 체력 조건 가안 | 주요 패턴 | 학습 검증 |
| --- | ---: | --- | --- |
| 1 | 100~70% | 횡베기, 내려찍기 | 전조 판독·회피 |
| 2 | 70~35% | 영혼 결박, 코어 돌진 | 표적 전환·구조물 방어 |
| 3 | 35~0% | 군진 행진, 연속 공격, 수납 압박 | 자원·철수 판단·소비품 종합 |

### 연출

- 문이 열리기 전 월도 날이 바닥을 긁는 소리와 여러 명의 발걸음을 들려줍니다.
- 갑옷 틈의 얼굴과 손은 클로즈업보다 공격 중 짧게 드러내 과도한 연출 비용을 줄입니다.
- 페이즈 전환 시 흡수된 영혼의 목소리가 겹치고 월도 크기 또는 결박선이 증가합니다.
- 최종 타격 후 즉시 폭발시키지 않고 결박선이 하나씩 끊어지는 시간을 둡니다.

### 실패·철수·개발용 재현

- 정식 플레이에서 사망하면 월드 게임오버이며 보스방 앞에서 부활하지 않습니다.
- 전멸 전에 철수하면 허브에서 재정비한 뒤 아직 열린 게이트에 재도전할 수 있습니다.
- 개발·QA 빌드에서만 보스방 진입 직전 상태 스냅샷과 필수 아이템 복원 기능을 사용합니다.
- 디버그 재현에서는 이미 읽은 기록 전문과 긴 등장 연출을 생략할 수 있습니다.

### 완료 조건

- 월도의 체력이 0이 되고 다중 영혼 결박핵이 노출되면 TUT-08로 전환합니다.

## 12. TUT-08 — 해방, 폐쇄와 복귀

### 영혼 해방

- 플레이어는 월도 잔해의 결박핵에 `G` 길게 누르기를 사용합니다.
- 수집한 영혼 결박 파편과 안정화 기록이 시각적으로 결박핵에 연결됩니다.
- 해방된 영혼은 개별 인물로 완전히 복원하기보다 빛과 짧은 목소리로 표현합니다.

### 게이트 폐쇄

- 토벌팀장의 폐쇄 인증을 장치에 사용합니다.
- 폐쇄 진행 중 새 웨이브를 추가하지 않고 공간 붕괴와 상호작용 유지에 집중합니다.
- 성공하면 모든 소리가 잠시 사라진 뒤 현실 도시의 바람·경보음으로 전환합니다.

### 현실 복귀

- 기존 도시 세트에 시민 비활성, 통제선, 기관 차량과 조사 조명을 추가해 유령도시를 표현합니다.
- 기관 각성자 요원과 조사관이 플레이어의 전개 흔적을 확인합니다.

```text
"등록된 각성 유형과 일치하지 않습니다."
"현장 자체를 설계한 것에 가깝습니다."

[신규 각성 분류 등록]
[ARCHITECT]
[코드네임: 설계자]
```

### 결과와 다음 훅

- 결과 화면에 구조한 영혼, 회수 기록, 파괴·수리한 파츠와 월도 보상 후보를 표시합니다.
- `다음 게이트를 닫아야 한다`는 목표와 기관 조사 연락을 남깁니다.
- 정본 지구, 이면의 진짜 형상과 관리자 시스템은 공개하지 않습니다.

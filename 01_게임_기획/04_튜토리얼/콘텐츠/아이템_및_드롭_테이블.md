# 튜토리얼 아이템 및 드롭 테이블

> [!IMPORTANT]
> 문서 상태: 초안. 튜토리얼에서 실제로 등장하는 아이템, 획득 위치, 기능과 보호 규칙을 정의합니다. 장비·코어·소비 아이템 공통 규칙은 [장비·코어·스킬](../../01_핵심_플레이/장비_코어_스킬/README.md)을 따릅니다.

## 1. 목적

- 새 아이템은 조작 또는 시스템 학습 직전에 제공합니다.
- 서사 기록과 기능 보상을 같은 탐색 지점에 배치합니다.
- 퀘스트 필수품은 가방 파괴로 소실되지 않게 합니다.
- 튜토리얼에서 사용하지 않는 희귀도·경제·제작 체계는 도입하지 않습니다.

## 2. 아이템 분류

| 분류 | 저장 위치 | 가방 파괴 영향 | 예시 |
| --- | --- | --- | --- |
| 장착 장비 | 장착 슬롯 | 유지 | 임시 현실 고정 무기 |
| 벨트 소비품 | `1~2` | 유지 | 응급 회복제, 코어 활성제 |
| 일반 전리품 | 직접 청사진 칸 또는 주머니 | 주머니 내용물 반출 불가, 빈 칸 직접 수납 가능 | 기억 잔재, 도구 파편 |
| 퀘스트 아이템 | 보호 슬롯·코어 데이터 | 유지 | 폐쇄 인증, 영혼 결박 파편 |
| 조사 기록 | 기록 보관함 | 유지 | 작전 기록, 유물 조사 기록 |
| 보스 보상 | 결과 보관 | 작전 종료 시 판정 | 월도 잔해, 구전 기록 |

## 3. 플레이어 시작 상태

- 일반 아이템 없음
- 퀘스트 데이터 없음
- 가방 기능 잠금
- 임시 현실 고정 권한만 잠재 상태

### 첫 무기 가안

| 항목 | 내용 |
| --- | --- |
| 이름 | 임시 현실 고정봉 |
| 원본 | 게이트 내부의 부지깽이 또는 금속 막대 |
| 획득 | TUT-02 첫 회피 성공 후 시스템이 좌표 고정 |
| 역할 | 좌클릭 기본 공격 학습 |
| 보존 | 장착 슬롯이므로 수납 모듈 파괴와 무관 |
| 종료 | 튜토리얼 종료 시 회수·폐기·정식 무기 전환 중 `TBD` |

대안은 정찰대원의 지급 무기를 시작부에 배치하는 방식입니다. 임시 현실 고정봉은 설계자 능력을 먼저 보여주고, 지급 무기는 기관과 선행 토벌팀을 먼저 암시한다는 차이가 있습니다.

## 4. 몬스터 드롭

### 기억 투영형 도깨비

| 아이템 | 분류 | 드롭 규칙 가안 | 용도 |
| --- | --- | --- | --- |
| 기억 잔재 | 일반 전리품 | 기본 적 1개 확정 | 코어 운용·튜토리얼 자원 |
| 낡은 생활 도구 파편 | 일반 전리품 | 낮은 확률 또는 정해진 1회 | 후속 제작 재료 후보 |

기억 투영형은 인간 영혼 반응과 영혼 결박 파편을 드롭하지 않습니다.

### 영혼 주입형 도깨비

| 아이템 | 분류 | 드롭 규칙 가안 | 용도 |
| --- | --- | --- | --- |
| 영혼 결박 파편 | 퀘스트 아이템 | 개체당 1개 확정 | 영혼 안정화와 월도 결박핵 해체 |
| 뒤틀린 도구 파편 | 일반 전리품 | 개체당 0~1개 | 폭주 분석·후속 제작 후보 |
| 기억 잔재 | 일반 전리품 | 개체당 1개 가안 | 코어 운용 자원 |

영혼 결박 파편은 자동으로 보호 슬롯에 들어갑니다. 주머니가 파괴되어도 획득할 수 있어야 하며, 일반 자동 획득과 다른 이펙트·사운드를 사용합니다.

### 월도

| 아이템 | 분류 | 획득 시점 | 용도 |
| --- | --- | --- | --- |
| 다중 영혼 결박핵 | 퀘스트 아이템 | 보스 체력 0 | TUT-08 영혼 해방 대상 |
| 월도 잔해 | 보스 보상 | 영혼 해방 후 | 정화·봉인·무기화 후보 |
| 월도 구전 기록 | 조사 기록 | 결과 화면 | 지역 전승 공개 |
| 폭주 게이트 좌표 기록 | 퀘스트 데이터 | 폐쇄 후 | 기관 분석과 메인 월드 훅 |

월도를 즉시 장착 가능한 무기로 지급할지, 기관에서 정화·분석한 뒤 첫 정식 설계로 해금할지는 `TBD`입니다. 프로토타입에서는 결과 화면 보상으로만 기록해 추가 무기 구현을 피합니다.

## 5. 토벌팀 획득품

| 소유자 | 기능 아이템 | 기록 | 플롯 | 필수 여부 |
| --- | --- | --- | --- | --- |
| 정찰대원 | 내부 지도 데이터 | 외부 토벌 완료 | TUT-06 초입 | 기록 요약 필수 |
| 전투대원 | 응급 회복제 1개 가안 | 내부 개체 상이 | TUT-03~05 | 소비 아이템 학습 |
| 기술요원 | 코어 활성제 1개 가안 | 인간 생존 신호·결박 반응 | TUT-05 | 코어 0자원 시동 학습 |
| 조사관 | 월도 분석 데이터 | 유물 조사 기록 | TUT-06 후반 | 필수 |
| 팀장 | 게이트 폐쇄 인증 | 철수 경고 | 보스방 앞 | 필수 |

필수 아이템은 상호작용 완료 즉시 보호 슬롯으로 이동합니다. 시체가 물리적으로 사라져도 플롯 복구 지점에서 다시 생성합니다.

## 6. 소비 아이템

### 응급 회복제

| 항목 | 가안 |
| --- | --- |
| 입력 | `1` |
| 역할 | 플레이어 체력 즉시 회복 |

| 사용 불가 | 체력 최대, 사망 상태 |

### 코어 활성제

| 항목 | 가안 |
| --- | --- |
| 입력 | `2` |
| 역할 | 현재 전개된 코어 자원을 정해진 수치만큼 즉시 충전 |
| 획득 | 기술요원 시체 또는 첫 코어 전개 직전 보장 지급 |
| 튜토리얼 지급량 | 1개 이상 `TBD` |
| 사용 불가 | 코어 미전개·파괴, 자원 최대 |

코어 활성제는 현재 코어의 자원을 충전할 뿐 자원 각인이 다른 장비 스킬을 활성화하지 않습니다. 초기 소비 아이템은 이 두 종류만 사용하고 `3~4` 슬롯과 투척물·수리 도구는 후속 범위로 둡니다.

## 8. 드롭·획득 연출

- 직접 수납: 빈 청사진 칸으로 연결되는 단일 셀 표시를 사용합니다.
- 주머니 수납: 정상 주머니 방향으로 입자가 빨려 들어갑니다.
- 주머니 파괴 상태: 내부 재료에 붉은 반출 불가 아이콘을 표시하고, 새 아이템은 빈 직접 수납 칸이나 다른 정상 주머니가 없으면 월드에 남깁니다.
- 퀘스트 아이템: 코어 또는 보호 슬롯으로 청록색 연결선이 이동합니다.
- 영혼 결박 파편: 사람의 목소리, 따뜻한 색의 빛과 안정화 진행을 사용합니다.
- 조사 기록: 아이콘보다 시체 장비의 불빛과 무전 잡음으로 먼저 유도합니다.
- 보스 보상: 전투 중 즉시 흩뿌리지 않고 영혼 해방 후 결과로 분리합니다.

## 10. 진행 불가 방지

- 폐쇄 인증, 영혼 결박 파편과 기록 데이터는 버릴 수 없습니다.
- 필수 시체를 조사하지 않고 보스방에 도달하면 폐쇄 인증 위치를 목표 UI로 강조합니다.
- 플레이어용 사망 체크포인트는 제공하지 않습니다. 개발·QA용 상태 스냅샷에서만 필수 소비 아이템을 복원할 수 있습니다.
- 가방이 가득 차도 퀘스트 아이템은 보호 슬롯으로 획득합니다.
- 월드 드롭이 지형 밖으로 떨어지면 최근 유효 위치 또는 획득 가능 지점으로 이동합니다.

- 영혼 결박 파편의 수집 수와 놓친 영혼 처리
- 월도의 정식 보상 형태

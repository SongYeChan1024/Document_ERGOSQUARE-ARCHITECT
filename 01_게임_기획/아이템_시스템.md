# 아이템 시스템

> [!IMPORTANT]
> 문서 상태: 아이디어

## 후보 분류

| 분류 | 역할 |
| --- | --- |
| 자원 코어 | 모듈 운용에 필요한 자원 생산 |
| 공격 모듈 | 무기 또는 공격 기능 제공 |
| 방어 모듈 | 장벽·엄폐·피해 완화 |
| 지원 모듈 | 회복·버프·탐지 |
| 설계 데이터 | 신규 선택지 또는 연구 해금 |

## 공통 데이터 후보

`ItemId`, `Category`, `GridSize`, `ConnectRule`, `Cost`, `Durability`, `EffectId`

아이템 희귀도와 드롭 테이블은 MVP 이후 결정합니다.

## 격자와 크기 규칙

원안 메인 기획서의 수치를 현재 대표 시스템 명세와 연결한 가안입니다.

- 격자 한 칸은 월드 기준 `1m × 1m`입니다.
- 모듈 크기는 `1×1`, `1×2`, `2×1`, `2×2`를 우선 사용합니다.
- 직사각형 모듈은 회전 배치를 지원하는 방향으로 검토합니다.
- 큰 모듈은 효과와 내구도가 높은 대신 배치 공간, 피격 면적과 설치 부담이 커집니다.
- 최종 크기와 회전 규칙은 편성 UI 프로토타입에서 검증합니다.

## MVP 모듈 후보

| 모듈 | 크기 가안 | 역할 | 파괴 시 영향 |
| --- | ---: | --- | --- |
| 앵커 코어 | 2×2 | 청사진 기준점·핵심 자원 생산 | 신규 자원 생산 중단 |
| 소형 자원 코어 | 1×1 | 좁은 프레임의 보조 자원 생산 | 해당 자원 생산 중단 |
| 공격 모듈 | 1×2 | 직접 공격 또는 스킬 조건 제공 | 연결된 공격 기능 사용 불가 |
| 방어 플레이트 | 2×1 | 인접 모듈 피해 감소 | 피해 감소 효과 해제 |
| 리페어 키트 | 1×1 | 주변 손상 모듈 회복 | 회복 기능 중단 |
| 위상 증폭기 | 1×1 | 인접 코어 생산량 증폭 | 생산 보너스 제거 |
| 링크 노드 | 1×1 | 원격 전개물 또는 보조 노드 연결 | 연결된 지원 기능 정지 |

MVP는 앵커 코어, 공격 모듈, 방어 플레이트와 리페어 키트를 우선 검증합니다. 프레임 전용 모듈과 링크 노드는 확장 후보입니다.

## 설치 시간 가안

| 크기 | 기본 설치 시간 |
| --- | ---: |
| 1×1 | 1.5초 |
| 1×2 / 2×1 | 2초 |
| 2×2 | 3초 |

설치 중인 모듈은 홀로그램 상태이며 기능하지 않지만 공격과 파괴의 대상이 됩니다. 시간은 모듈 종류와 프레임 보정 전 기준이며 플레이테스트 전 가안입니다.

## 연결과 인접 효과 후보

- 자원 코어 + 증폭기: 자원 생산량 증가
- 자원 코어 + 방어 플레이트: 코어 피해 감소
- 공격 모듈 + 탐지 모듈: 탐지 또는 약점 공격 효율 증가
- 수리 모듈 + 방어 모듈: 방어 구조 유지력 증가
- 링크 노드 + 보조 노드: 원격 지원 기능 활성화

인접 효과는 강제 정답 배치를 만들지 않도록 효율, 노출 위험과 공간 비용을 함께 조정합니다.

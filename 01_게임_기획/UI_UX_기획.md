# UI·UX 기획

> [!IMPORTANT]
> 문서 상태: 초안

## 주요 화면

- 작전 허브
- 청사진 편성
- 전투 HUD
- 전개 프리뷰
- 결과 분석

## 우선 정보

1. 코어와 핵심 모듈의 위험 상태
2. 전개 가능 여부와 실패 이유
3. 팀원의 위치와 역할
4. 작전 목표와 진행도
5. 획득 보상

색상만으로 상태를 구분하지 않으며 아이콘·텍스트·소리를 함께 사용합니다.

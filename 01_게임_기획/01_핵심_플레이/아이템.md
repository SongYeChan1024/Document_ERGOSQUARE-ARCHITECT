# 아이템 시스템

> [!IMPORTANT]
> 문서 상태: 아이디어

## 후보 분류

장비, 부여 스킬과 자원 코어의 연결 규칙은 [장비·코어·스킬](./장비_코어_스킬/README.md)을 기준으로 합니다. 전체 청사진 크기, 레벨 확장과 수납 공간 경쟁은 [청사진 성장 및 공간 경제](../02_에르고스퀘어/청사진_성장_및_공간_경제.md)를 따릅니다. 이 문서는 개별 아이템·모듈의 분류와 격자 크기를 관리합니다.

| 분류 | 역할 |
| --- | --- |
| 자원 코어 | 모듈 운용에 필요한 자원 생산 |
| 공격 모듈 | 무기 또는 공격 기능 제공 |
| 방어 모듈 | 장벽·엄폐·피해 완화 |
| 지원 모듈 | 회복·버프·탐지 |
| 장착 장비 | 기본 능력치·행동과 편성 가능한 스킬 제공 |
| 패시브 아이템 | 조건부 효과와 빌드 규칙 제공 |
| 코어 강화 부품 | 자원 생성·내구도·영역 변경 |
| 스킬 변형 부품 | 기존 스킬의 범위·형태·조건 변경 |
| 주머니 | 여러 재료를 압축 수납하고 반출 |
| 직접 수납 재료 | 재료 하나당 청사진 한 칸 점유 |
| 설계 데이터 | 신규 선택지 또는 연구 해금 |

## 공통 데이터 후보

`ItemId`, `Category`, `GridSize`, `ConnectRule`, `Cost`, `Durability`, `EffectId`

아이템 희귀도와 드롭 테이블은 MVP 이후 결정합니다.

## 격자와 크기 규칙

원안 메인 기획서의 수치를 현재 대표 시스템 명세와 연결한 가안입니다.

- 격자 한 칸은 월드 기준 `1m × 1m`입니다.
- 모듈 크기는 `1×1`, `1×2`, `2×1`, `2×2`를 우선 사용합니다.
- 직사각형 모듈은 회전 배치를 지원하는 방향으로 검토합니다.
- 큰 모듈은 효과와 내구도가 높은 대신 배치 공간, 피격 면적과 설치 부담이 커집니다.
- 최종 크기와 회전 규칙은 편성 UI 프로토타입에서 검증합니다.

## MVP 모듈 후보

| 모듈 | 크기 가안 | 역할 | 파괴 시 영향 |
| --- | ---: | --- | --- |
| 앵커 코어 | 2×2 | 청사진 기준점·핵심 자원 생산 | 신규 자원 생산 중단 |
| 소형 자원 코어 | 1×1 | 좁은 프레임의 보조 자원 생산 | 해당 자원 생산 중단 |
| 공격 모듈 | 1×2 | 직접 공격 또는 스킬 조건 제공 | 연결된 공격 기능 사용 불가 |
| 방어 플레이트 | 2×1 | 인접 모듈 피해 감소 | 피해 감소 효과 해제 |
| 소형 주머니 | 1×1 | 여러 재료의 압축 수납 가안 | 내용물 반출 불가 |
| 위상 증폭기 | 1×1 | 인접 코어 생산량 증폭 | 생산 보너스 제거 |
| 링크 노드 | 1×1 | 원격 전개물 또는 보조 노드 연결 | 연결된 지원 기능 정지 |

튜토리얼 MVP는 앵커 코어, 공격 모듈, 소형 주머니와 방어 플레이트를 우선 검증합니다. 프레임 전용 모듈과 링크 노드는 확장 후보입니다.

## 설치 시간 가안

| 크기 | 기본 설치 시간 |
| --- | ---: |
| 1×1 | 1.5초 |
| 1×2 / 2×1 | 2초 |
| 2×2 | 3초 |

설치 중인 모듈은 홀로그램 상태이며 기능하지 않지만 공격과 파괴의 대상이 됩니다. 시간은 모듈 종류와 프레임 보정 전 기준이며 플레이테스트 전 가안입니다.

## 연결과 인접 효과 후보

- 자원 코어 + 증폭기: 자원 생산량 증가
- 자원 코어 + 방어 플레이트: 코어 피해 감소
- 공격 모듈 + 탐지 모듈: 탐지 또는 약점 공격 효율 증가
- 주머니 + 방어 플레이트: 재료 반출 위험 감소
- 링크 노드 + 보조 노드: 원격 지원 기능 활성화

인접 효과는 강제 정답 배치를 만들지 않도록 효율, 노출 위험과 공간 비용을 함께 조정합니다.

## 공통 능력치(Stat) 및 태그(Tag) 규격 가안

아이템(장비 및 모듈)에 부여되는 옵션과 능력치의 표준 분류 및 태그 규칙입니다.

### 1. 능력치 표현 방식
*   **고정 수치 (Flat):** 극초반 및 기본 수치에 적용 (예: 공격력 +5, 내구도 +10)
*   **비율 수치 (Percent):** 후반 성장 및 시너지 옵션에 적용 (예: 공격력 +5%, 이동속도 +3%)
*   **특수 매커니즘:** 주기적 발동 또는 특정 상태 조건부 발동 (예: 5초마다 체력 2 회복, 코어 인접 시 방어력 증가)

### 2. 표준 능력치 분류 목록
| 분류 | 능력치 항목 | 비고 |
| --- | --- | --- |
| **기본/생존** | 공격력, 방어력, 내구도, 체력/치유력, 치유효과 증가 | 기본 전투 수치 |
| **속도/기동** | 공격속도, 이동속도, 이동속도 증가/감소 효과 | 전투 기동성 관련 |
| **전투 유틸** | 치명타 확률, 치명타 피해량, 회피율 | 확률성 공격/방어 수치 |
| **제어/저항** | 기절 확률, 기절 저항 | CC(상태이상) 제어 |
| **피해 분류** | 근접 피해 증가/감소, 원거리 피해 증가/감소 | 전개 계통별 맞춤 옵션 |
| **스킬/코어** | 스킬 효과 증가/감소, 코어 자원 생성 효율 | 에르고스퀘어 특화 수치 |

### 3. 태그(Tag) 시스템
장비 및 스킬 간 시너지 계산을 위해 아이템에 키워드 태그를 부여합니다.
*   **계통 태그:** `[도깨비]`, `[무당]`, `[수호]` 등 (국가/문화별 힘의 근원)
*   **전투 계통 태그:** `[근접]`, `[투사]`, `[영역]` 등
*   **재질/형상 태그:** `[둔기]`, `[날검]`, `[의식도구]`, `[목재]` 등

# 국가별 장비·코어·스킬 인덱스

> [!IMPORTANT]
> 문서 상태: 한국 초안, 나머지 국가 템플릿. 조사되지 않은 설정은 만들지 않습니다.

국가 분류는 문서 탐색을 위한 상위 탭입니다. 실제 메커니즘은 국가 전체가 아니라 그 아래의 전승, 신앙, 기술과 힘의 계보별로 정의합니다.

| 문서 | 상태 |
| --- | --- |
| [한국](./한국/한국.md) | 도깨비·무당·터전 수호 계통 및 직군·원화 재분류 초안 |
| [중국](./중국/중국.md) | 무협·내공 및 강시 방향만 기록한 검토 초안 |
| [일본](./일본/일본.md) | 입력 대기 템플릿 |
| [미국](./미국/미국.md) | 입력 대기 템플릿 |

## 공통 작성 항목

1. 지역·시대·공동체와 조사 출처
2. 힘의 계보와 핵심 메커니즘
3. 코어 및 전투 자원
4. 장비 형상과 기본 행동
5. 부여 스킬 후보군
6. 성장 대상과 성장 조건
7. 근접·투사·영역 표현
8. 다른 계통으로 재제작할 때 보존·소실되는 성질
9. UI·시각·음향 표현
10. 문화·역사 검토 사항

## 목적

장비 획득, 액티브 스킬 편성, 코어 자원 운용, 해체와 재제작을 하나의 빌드 순환으로 연결합니다. 플레이어는 전리품을 그대로 사용하는 데서 끝나지 않고 장비의 형상·스킬·자원·성질을 다시 설계해 자신의 빌드를 만듭니다.

국가·문화권별 세부 규칙은 [국가별 인덱스](국가별/README.md) 아래에서 관리합니다.
코어 인스턴스의 획득·전개 계통·기초 능력치 규칙은 [코어 획득 및 능력치](../../시스템_상세_부록.md#core-drop)를 기준으로 합니다.

## 아이템 용어 적용

- 무기와 방어구는 `장비형 파츠`입니다.
- 자원을 생성하고 고유 운용 규칙을 결정하는 코어는 `코어형 파츠`입니다.
- 패시브, 코어 강화, 스킬 변형, 수납과 방호 기능은 `보조형 파츠`로 구성합니다.
- 응급 회복제와 코어 활성제처럼 청사진 소비 슬롯에 편성하는 아이템은 `소비형 파츠`입니다.
- 파츠의 제작·강화·복구와 허브 시설 업그레이드에 소비하는 비장착 아이템은 모두 `재료`입니다.
- 아키텍트가 청사진에 구성한 파츠의 전체 조합을 `아키텍처`라고 부릅니다.

상위 명칭과 데이터 경계는 [아이템·파츠 시스템](../../시스템_상세_부록.md#items)을 따릅니다.

## 사용자 흐름과 공통 원칙

현재 공통 규칙은 [종합 기획서 4.4~4.8](../../../00_프로젝트_개요/에르고스퀘어_종합_기획서_초안.md#44-에르고스퀘어와-청사진)을 따릅니다. 파츠 획득 → 독립 스퀘어 생성/확장 → 스킬 코어·파츠 배치 → 키 배정 → 공용 자원으로 최초 발동 → 로컬 출력·과부하·냉각 순서입니다. 코어로 직군을 결정하던 규칙과 단일 코어 파괴 시 전 스킬 정지는 2026-10-18에 대체했습니다.

## 장비 구성 층

| 구성 요소 | 결정하는 것 |
| --- | --- |
| 장비 형상 | 검, 빗자루, 월도, 방울, 방어구 등의 기본 행동과 장착 부위 |
| 기원 계통 | 도깨비·무당·수호 등 장비가 유래한 힘의 계보 |
| 자원 각인 | 정기·신력·수호력 등 액티브 스킬이 소비할 자원 |
| 부여 스킬 | `QWERASDF`에 편성할 액티브 스킬 |
| 성장 성질 | 유대 성장, 한 축적, 영역 안정화 등 장기 변화 규칙 |
| 능력치 | 공격력, 공격 속도, 내구도와 계통별 보정값 |

## 장비 획득과 통제된 무작위

- 몬스터와 아이템 원형마다 등장 가능한 능력치, 스킬과 성장 성질 후보군을 가집니다.
- 같은 종류의 장비라도 드롭될 때 후보군 안에서 결과가 무작위로 결정됩니다.
- 모든 스킬을 모든 장비에 붙이지 않고 형상·기원·희귀도 태그로 후보를 제한합니다.
- 원하는 조합을 반복해서 찾는 파밍 욕구를 제공하되, 필요 없는 결과도 해체 재료와 제작 진척으로 남깁니다.
- 튜토리얼의 첫 필수 드롭은 현재 코어로 사용할 수 있는 스킬 하나를 보장하고 보조 결과만 무작위화합니다.

## 스킬 편성

- 장착한 무기·방어구·도구가 제공한 액티브 스킬을 편성 후보로 표시합니다.
- 플레이어는 후보 중 여덟 개를 `QWERASDF`에 자유롭게 배치합니다.
- 입력 슬롯은 장비에 고정되지 않으며 플레이어가 변경할 수 있습니다.
- 장착 해제, 전투 중 교체와 중복 스킬 처리 규칙은 `TBD`입니다.
- 장비 스킬은 현재 코어가 생성하는 자원과 호환될 때 활성화됩니다.

## 코어와 자원

역할·데이터는 [코어 상세](../../시스템_상세_부록.md#core-drop), 성장 비용·과부하 계산·예외는 [공간 경제 상세](../../시스템_상세_부록.md#space-economy)를 참조합니다. 같은 공간의 코어는 공용 최초 발동 자원 생성과 무기의 후속 연계·유지·추가 출력을 지원합니다. 코어 역할을 강제로 분리하지 않습니다. Space는 공용 자원 보조 회복이며 개별 코어의 열을 초기화하지 않습니다. 파괴 시 담당 기능만 중단하고 이동·기본 공격·상호작용은 유지합니다.

## 자원 호환

- 획득 당시 장비에는 사용할 자원 계통이 각인됩니다.
- 현재 코어와 장비의 자원 각인이 다르면 기본 행동은 가능하지만 액티브 스킬은 비활성화됩니다.
- 자원 변환은 자동으로 일어나지 않습니다.
- 플레이어는 코어를 교체하거나 장비를 해체해 현재 코어에 맞게 재제작해야 합니다.

## 초기 소비 아이템

초기 프로토타입의 소비 아이템은 체력 회복과 코어 시동 보조의 두 종류만 사용합니다.

| 슬롯 | 아이템 가칭 | 대상 | 기능 | 사용 불가 조건 |
| --- | --- | --- | --- | --- |
| `1` | 응급 회복제 | 플레이어 | 체력을 정해진 수치만큼 회복 | 체력 최대, 사망·중상 상태 |
| `2` | 코어 활성제 | 현재 전개된 코어 | 현재 코어 자원을 정해진 수치만큼 즉시 충전 | 코어 미전개·파괴, 자원 최대 |

- 두 아이템 모두 최대치를 넘는 회복·충전량은 소멸합니다.
- 코어 활성제는 특정 문화권 자원을 직접 공급하지 않고 현재 코어의 생성을 촉진합니다.
- 따라서 도깨비·무당·수호 등 어떤 빌드에서도 사용할 수 있지만 장비와 코어의 자원 불일치를 우회하지는 못합니다.
- 정신 집중으로 천천히 회복할지 활성제를 사용해 즉시 첫 스킬을 확보할지 선택하게 합니다.
- 초기에는 `3~4` 소비 아이템 슬롯을 비워 두고 상태 해제·투척물 등은 후속 범위로 둡니다.

## 해체와 재제작

### 해체 산출물 후보

- 장비 형상과 일반 제작 재료
- 자원 계통별 매개체
- 부여 스킬 각인 또는 설계도
- 성장 성질을 보존한 특수 재료
- 기억·유대·원혼 등 희귀 서사 재료

### 제작 선택

| 선택 | 결과 | 대가 |
| --- | --- | --- |
| 원래 계통 유지 | 기원·자원·성장 효율을 보존하고 전문화 | 다른 코어와의 호환성이 낮음 |
| 다른 코어로 재제작 | 현재 코어 자원으로 스킬 사용 가능 | 원래 성장 성질 일부 소실 가능 |
| 혼합 계통으로 제작 | 두 계통의 일부 특성과 스킬을 함께 보존 | 효율·용량·소모량·성장 속도 중 하나 이상 불리 |

혼합 장비는 순수 계통의 상위 호환이 아닙니다. 순수 계통은 높은 효율과 전문성을, 혼합 계통은 높은 유연성과 새로운 상호작용을 제공합니다.

| 항목 | 첫 검증안 |

| 코어 | `낡은 정기의 혼 코어 [근접]`, 1×1, 고정 능력치 결과 |
| 자원 생성 | Space 정신 집중 초당 `10`, 전개 후 보유량 유지·지속 생성 |

| 코어 파괴 | 그 코어의 기능 중단, 다른 정상 코어는 유지 |

녹슨 검의 시스템 검증 스킬 후보는 종베기, 횡베기와 찌르기입니다. 도깨비 튜토리얼 장비 후보는 [한국 장비·코어·스킬](국가별/한국/한국.md)에서 관리합니다.

## 결정된 사항

- 장비가 제공한 스킬로 `QWERASDF` 여덟 칸을 구성합니다.
- 능력치와 부여 스킬은 아이템별 후보군 안에서 무작위로 결정합니다.
- 코어 전개와 보호가 액티브 스킬 자원에 연결됩니다.
- 코어가 파괴되어도 이동과 기본 공격은 유지됩니다.
- 장비와 코어의 자원이 다르면 기본 행동은 유지하되 액티브 스킬을 제한합니다.
- 장비 해체와 재제작으로 서로 다른 코어 계통을 조합할 수 있습니다.
- 혼합 제작에는 순수 계통 대비 명확한 비용을 둡니다.
- 코어 전개 전에 정신 집중으로 회복한 자원은 전개 후에도 유지됩니다.
- Space 정신 집중은 전개 전후 모두 가능하지만 느리고 위험한 보조 회복 수단입니다.
- 초기 소비 아이템은 응급 회복제와 코어 활성제 두 종류만 사용합니다.
- 코어 파괴의 영향 범위는 생성기 또는 해당 스킬 스퀘어로 분리합니다. 수리는 후속 시설 규칙입니다.
- 직군을 고정하지 않고 각 스퀘어의 코어·파츠·스킬 배정으로 역할을 구성합니다.

## 열린 질문

- 장비 하나에 붙는 스킬 수와 희귀도에 따른 변화
- 해체 시 스킬 각인과 성장 성질을 어느 단위로 보존할지
- 전투 중 장비 및 스킬 슬롯 교체를 허용할지
- 코어 손상과 생성 효율의 관계를 연속형 또는 구간형 중 무엇으로 표현할지
- 혼합 제작의 효율·용량·소모량·성장 속도 비용 기준
- 협동 플레이에서 개인별 또는 팀 공용 코어·자원을 사용할지
- 응급 회복제와 코어 활성제의 회복량, 사용 시간과 재사용 제한

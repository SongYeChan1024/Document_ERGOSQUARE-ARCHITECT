# 에르고스퀘어

> [!IMPORTANT]
> 문서 상태: 구조 초안

## 문서 역할

설계자가 청사진을 전장에 전개하고, 코어·모듈과 다른 능력의 모사를 조합해 빌드를 구성하는 규칙을 관리합니다.

## 현재 문서

- [설계자 빌드](./설계자_빌드.md): 전개 계통, 코어 보호와 융합 빌드 기준
- [청사진 성장 및 공간 경제](./청사진_성장_및_공간_경제.md): 레벨별 격자 확장, 수납·전투·방어 공간 배분
- [장비·코어·스킬](../01_핵심_플레이/장비_코어_스킬/README.md): 코어 자원 생성·소비·파괴와 장비 호환 규칙
- [아이템](../01_핵심_플레이/아이템.md): 모듈 분류, 격자 크기와 인접 효과
- [대표 시스템 기술 명세](../../03_기술_문서/시스템별_구현_명세/에르고스퀘어_대표_시스템_명세.md): 구현 관점의 상태와 데이터

새 문서는 실제 독립 규칙이 생겼을 때만 추가합니다. 빈 청사진·코어·모듈 문서를 미리 만들지 않습니다.

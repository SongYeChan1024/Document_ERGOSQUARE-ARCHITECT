# 밸런스 테이블

> [!IMPORTANT]
> 문서 상태: 운영

밸런스 원본은 추후 CSV 또는 스프레드시트로 관리합니다.

## 예정 데이터

- 플레이어 능력치
- 무기 피해와 재사용 시간
- 모듈 비용·내구도·효과
- 적 체력·공격력·표적 가중치
- 보상과 드롭 확률

모든 수치는 버전과 테스트 근거를 함께 기록합니다.

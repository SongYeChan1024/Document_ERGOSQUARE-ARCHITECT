## 예정 데이터

- 플레이어 능력치
- 무기 피해와 재사용 시간
- 파츠 비용·내구도·효과
- 적 체력·공격력·표적 가중치
- 보상과 드롭 확률

모든 수치는 버전과 테스트 근거를 함께 기록합니다.

## 데이터 상태

| 데이터 | 상태 | 선행 조건 |
| --- | --- | --- |
| 플레이어·코어 능력치 | 입력 대기 | 기초 능력치 목록 확정 |
| 빗자루 연계·조합·강화 수치 | 플레이테스트 가안 입력 및 JSON 연결 | 조작감·난이도 시험 후 수치 수정 |
| 다른 무기·스킬 수치 | 입력 대기 | 해당 스킬 명세 확정 |
| 적·보스 수치 | 입력 대기 | 전투 블록아웃 완성 |
| 드롭 확률 | 입력 대기 | 코어·장비 드롭 풀 확정 |
